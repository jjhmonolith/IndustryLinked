"내 수업에서 실제로 쓸 도구 하나가, 처음부터 끝까지 동작한다."

말로 만드는 도구

  • AI에게 한국어로 말하면 앱이 만들어진다 — "이런 도구 만들어줘"
  • 바꾸고 싶으면 다시 말한다 — "채점 결과를 표로 보여줘"
  • 만든 앱은 짓다가 바로 호스팅 — 링크 하나로 공유
  • AI 모델로 Solar를 붙일 수 있다
설치 없음로그인 없음명령어 없음브라우저만

파이썬 자동채점 + AI 튜터

채점 → 힌트 → 해설, 하나의 흐름으로

세 기능이 이어집니다

1

자동 채점

정답 비교로 통과/실패를 정확히 가른다

2

AI 힌트

막힌 학생에게 수준에 맞는 힌트

3

코드 해설 튜터

틀린 부분과 이유를 학생 눈높이로

채점은 정확히, 힌트·해설은 Solar가.

채점은 판단이 필요 없으니 정답 비교로 정확히. AI는 힌트·해설처럼 판단이 필요한 곳에만.

정답을 대신 주지 않는다

원칙

정답 코드를 통째로 주면 학생은 생각을 멈춥니다. 튜터의 역할은 스스로 고치게 만드는 것.

  • 어느 줄의 무엇이 왜 문제인지 한 문장으로
  • 다음 시도를 위한 질문 하나를 던진다
이게 이 연수 트랙 A의 핵심 철학. 짓다에 요청할 때 이 규칙을 반드시 못박게 한다.

짓다 AI 채팅에 이렇게 요청하세요

파이썬 문제 하나를 풀게 하고, 학생이 제출한 코드를
미리 정한 테스트케이스로 자동 채점하는 웹앱을 만들어줘.

규칙: 틀리면 정답 코드는 절대 보여주지 말고,
"어느 줄이 왜 틀렸는지" 한 문장 힌트와
다음 시도를 위한 질문 하나만 보여줘.
힌트·해설 문구는 Solar로 생성해줘.
해볼 것
  1. 테스트케이스 3개 이상 넣고, 일부러 틀린 코드로 실패가 뜨는지 확인
  2. 힌트에 정답 코드가 새어 나오면 규칙을 더 강하게 다시 요청
  3. 채점 → 힌트 → 해설이 한 흐름으로 돌면 v1 완성
짓다가 코드를 쓰되, '무엇을·어떤 규칙으로'는 교사가 정한다. 정답 유출 여부는 반드시 눈으로 확인.

자료 기반 AI 학습 챗봇

내 수업자료 안에서만 답하는 챗봇

자료가 챗봇의 지식이 된다

단계하는 일
① 구조화수업자료를 Document Parse로 구조화
② 핵심 추출Information Extract로 핵심 학습 항목만 뽑기
③ 지식 베이스뽑은 항목이 챗봇의 지식이 됨
④ 응답지식 베이스 범위 안에서만 답변
어제 day1_04·05에서 만든 구조화·추출 결과가 오늘 챗봇의 입력. 표·수식 많은 자료는 깔끔한 단원부터.

자료 밖은 정직하게 거절

원칙

챗봇이 자료에 없는 걸 지어내면 도구 전체의 신뢰가 무너집니다. 신뢰는 "모른다"고 말하는 정직함에서 나옵니다.

너는 아래 <학습자료>에만 근거해 답하는 챗봇이다.
규칙
1) 답은 반드시 자료 안 내용으로만 구성한다.
2) 자료에 없으면 지어내지 말고 "이번 수업자료 범위에 없어요"라고 거절한다.
3) 답 끝에 근거가 된 자료 항목을 표시한다.
거절 규칙은 챗봇 시스템 프롬프트에 못박는다. 짓다에 이 규칙을 그대로 요청.

짓다 AI 채팅에 이렇게 요청하세요

내가 올린 수업자료 범위 안에서만 답하는
학습 보조 챗봇 웹앱을 만들어줘. 모델은 Solar.

- 자료에 있는 질문엔 답하고 근거 항목을 표시
- 자료에 없는 질문은 지어내지 말고 정중히 거절
- 학생은 닉네임만으로 사용, 교사는 대화 로그 확인
해볼 것
  1. 지식 베이스는 오늘 1개 단원으로 범위를 좁힌다
  2. 자료 안 질문 → 근거 표시되는지 확인
  3. 자료 밖 질문 → 지어내지 않고 거절하는지 확인
거절이 안 되고 지어내면 규칙을 더 강하게 다시 요청. 오늘은 범위를 넓히지 말 것.
