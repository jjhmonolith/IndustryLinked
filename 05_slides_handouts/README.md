# 05_slides_handouts — 수업자료 슬라이드 (16:9 HTML)

상세 진행안([`../07_delivery_scripts/`](../07_delivery_scripts/)) 기반 강의용 슬라이드 덱. **팀모노리스 진행 차시**만 제작.

## 여는 법

- `index.html`을 브라우저로 열면 전체 덱 목록에서 선택.
- 각 덱: **←/→**(또는 Space) 이동 · **F** 전체화면 · **N** 발표자 노트 · **Home/End** 처음/끝 · 화면 좌/우 클릭·스와이프.
- 로컬 파일로 바로 열려도 되고, 폴더째 옮겨도 `assets/`만 함께 있으면 동작.

## 구성

```
05_slides_handouts/
├── index.html              # 덱 런처
├── assets/

│   └── slides.js           # 내비게이션·진행바·발표자 노트
├── day1_02.html  day1_06.html  day1_07.html
├── day2_01.html  day2_02.html  day2_03.html
└── bonseon_01.html  bonseon_02.html  bonseon_03.html
```

## 설계 규약

- **16:9 고정**: `.deck`이 뷰포트 안 최대 16:9 박스로 렌더(레터박스). 폰트는 컨테이너 쿼리 단위(cqh)로 해상도 독립 스케일.
- **한 슬라이드 = 한 메시지**: 스크립트 문단을 그대로 붙이지 않고 핵심만. 강사 멘트 요지는 `N`(발표자 노트)로.
- **2일차 도구 제작은 짓다**: 선생님이 직접 바이브코딩하는 day2는 팀모노리스 **짓다** 플랫폼 사용(AI 채팅→라이브 미리보기→갤러리). 1일차 개념·실습은 Colab·Solar·Document AI 기준.
- 새 덱 추가 시 `day2_01.html`을 템플릿으로 복제하고 `assets/`의 클래스만 사용.
