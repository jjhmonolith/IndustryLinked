한국과학창의재단 / 팀모노리스(주관) · 한국컴퓨터교육학회 · 업스테이지 컨소시엄

## 핵심 전제

- 1차시 = 50분 / 1박 2일 = Day 1 8차시 + Day 2 7차시
- 참여 교원 100명
- 분반 구조: 1~8차시 단일 트랙(콘텐츠 공통), 9~15차시 2트랙 분반(각 50명)
- 트랙 선택: 사전 조사 1차 응답 + 8차시 종료 시점 최종 확정(코들 퀴즈)
- 트랙 A: Python 자동 채점 및 오류 도우미
- 트랙 B: 소크룸 및 RAG(교과 범위 내 대화)
- 사용 도구: 짓다(AI 보조 코딩 플랫폼), Solar API(트랙별 공용 키), 코들(연수 운영 및 참고 에듀테크)
- 최종 목표: 연수 종료 후 바이브톤 참여 가능 수준 도달
