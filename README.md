## 핵심 전제

- 1차시 = 50분 / 1박2일 = Day1 8차시 + Day2 7차시
- 참여 교원 100명
- **분반 구조**: 1~8차시 = 단일 트랙(콘텐츠 공통), 9~15차시 = 2트랙 분기 (각 50명)
- **트랙 선택**: 사전조사 1차 + **8차시 종료 시 최종 확정** (코들 퀴즈)
- 트랙 A: Python 자동채점 + 오류 도우미
- 트랙 B: 소크룸 + RAG (교과범위 내 대화)
- 도구: 짓다(바이브코딩), Solar API(트랙별 공용 키), 코들(연수 운영 + 참고 에듀테크)
- 최종 목표: 연수 후 **바이브톤** 참여 가능 수준
