## 핵심 전제 (확정)

- **총 200명 (100명 × 2기)**. 1차시 = 60분.
- **23차시 = 집합연수 15차시(1박2일) + 본선 8차시(별도 1일, 10월)**.
  - 집합 1일차 = 8차시 공통 / 2일차 = 7차시 트랙 분반.
- 트랙 A(파이썬 자동채점 + AI 튜터, 30명×1반) / 트랙 B(자료 기반 AI 학습 챗봇, 35명×2반).
- 1기 서울(08.03–04) / 본선 10.17, 2기 부산(08.13–14) / 본선 10.24.
- 사용 도구: 코들(운영), 짓다 갤러리(전시·평가), Solar LLM API(모델), Document Parse + Information Extract(자료 처리), 실습용 생성형 AI.
- 최종 목표: 정보교사가 자기 학교 문제를 해결하는 AI 응용 도구를 직접 설계·제작.
