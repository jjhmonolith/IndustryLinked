# 공통 강의 가이드라인 — 모든 차시 강사 공통

> 원천: [`../00_연수운영계획_확정.md`](../00_연수운영계획_확정.md) · 차시 운영안: [`../03_session_plans/`](../03_session_plans/)
> 대상: 전 차시 주강사·보조강사·멘토. 각 차시 상세 진행안(`day1_*`, `day2_*`, `bonseon_*`)과 함께 사용한다.

---

## 1. 연수 철학 (모든 멘트의 바탕)

1. **"사용자가 아니라 제작자"** — 참가 교사는 연수가 끝나면 AI 도구를 *쓰는* 사람이 아니라 *만드는* 사람이 된다. 모든 차시가 이 한 문장으로 수렴한다.
2. **직접 만들기 > 이론·시연** — 시연·이론은 각 차시의 1/3 이내. 나머지는 교사가 직접 손을 움직인다.
3. **내 학교 문제에서 출발** — 추상적 예시보다 "선생님 학교에서 실제로 겪는 문제"로 항상 되돌린다.
4. **정직한 AI** — 정답을 대신 주지 않고 힌트를, 모르면 "모른다"를. 안전장치는 기능이 아니라 신뢰의 문제로 가르친다.
5. **검증된 것만 라이브** — 검증 안 된 기능은 라이브로 시연하지 않는다(실패는 학습 동기를 꺾는다). 사전 녹화·스크린샷으로 대체.

## 2. 강사 공통 행동 원칙

- **실습 우선 배분**: 설명은 짧게 끊고 곧바로 "직접 해보세요"로 넘긴다. 한 번에 5분 이상 일방 강의 지양.
- **제품 홍보 편향 금지**: 특정 도구·모델 자랑(벤치마크 수치 나열 등) 금지. "이 도구로 무엇을 할 수 있는가"만 보여준다.
- **비전공·저경험 배려**: 코딩·AI 경험이 적은 교사가 있다는 전제. 용어는 처음 나올 때 1줄로 풀고, 화면을 크게·천천히.
- **한 명도 막히지 않게**: 보조강사·멘토가 상시 순회. 코들 학습분석/기상캐스터로 정체 팀을 식별해 먼저 다가간다.
- **결과물은 코들·짓다 갤러리에 남긴다**: 모든 차시 끝에 산출물·회고를 플랫폼에 기록해 다음 차시·본선으로 이어지게 한다.

## 3. 스크립트 표기 규약 (상세 진행안 공통)

| 표기 | 의미 |
|------|------|
| `[강사 멘트]` | 강사가 그대로 읽거나 거의 그대로 말하는 near-verbatim 대사 |
| `(talking point)` | 요점만 — 강사가 자기 말로 풀어서 전달 |
| `[진행]` | 강사의 행동(거수 요청, 조 나누기, 시간 안내 등) |
| `[화면]` | 이 시점에 띄울 슬라이드·데모·QR·코들 화면 |
| `[실습]` | 학습자가 직접 하는 활동과 지시문 |
| `[전환]` | 다음 구간으로 넘기는 연결 멘트 |
| `[체크]` | 강사가 확인할 성취/진도 신호 |

## 4. 시간 관리

- **버퍼 원칙**: 각 구간은 계획 시간의 90%로 설계하고 10%를 버퍼로 둔다. 실습은 항상 예상보다 길어진다.
- **시간 카드**: 발표·시연에는 "2분 전 / 종료" 카드를 운영. 강사 발표도 예외 없음.
- **지연 대응 우선순위**: (1) 실습 시간은 지킨다 → (2) 부가 설명·심화를 먼저 줄인다 → (3) 공유·발표 인원을 줄인다. 실습을 희생하지 않는다.
- **일찍 끝난 팀**: "심화 미션" 1줄을 항상 준비(예: 안전장치 하나 더, 다른 학년용으로 변형).

## 5. 실습 지원 · 공통 트러블슈팅

| 상황 | 즉시 대응 |
|------|-----------|
| Solar API 키 오류·호출 실패 | 키 재확인 → 공용 예비 키 안내 → 실패 시 사용자용 안내 메시지로 폴백 시연 |
| Colab 접속·런타임 문제 | 사전 배포 노트북 사본 재발급, 런타임 재시작 안내, 보조강사 1:1 |
| 코들 입장 지연 | 초대 코드/QR 재안내. 1일차 도입에 5분 여유 확보 |
| Document Parse가 표·수식 자료를 잘 못 잡음 | 텍스트 깔끔한 단원부터 시작, 파싱 결과 육안 검수 후 진행 |
| 공용 키 레이트 리밋(다수 동시 호출) | 호출 시점 분산 — 강사 시연 → 조별 순차 실습 |
| 플랫폼 전면 장애 | 종이 양식 백업 1세트로 회고·기록 지속, 데모는 사전 녹화 재생 |

## 6. 난처한 질문·Q&A 대응 원칙

- **"이거 우리 학교에서 진짜 써도 되나요(개인정보·저작권)?"** → 실습 데이터는 비식별·공개자료 사용 원칙 안내. 실제 학생 데이터는 학교 규정·동의 필요. 본선/사례집 수록은 별도 동의.
- **"AI가 틀린 답 주면 책임은?"** → 그래서 이 연수가 안전장치를 배운다. 도구는 보조이며 최종 확인은 교사. 대시보드로 사후 점검.
- **"코딩을 잘 못하는데 따라갈 수 있나요?"** → 오늘 목표는 완벽한 코드가 아니라 "작동하는 하나". 보조강사가 옆에 있다.
- **범위 밖 기술 심화 질문** → "좋은 질문입니다. 교재/후속 자료로 안내드릴게요"로 흐름 보호. 전체 시간을 특정 1인에게 뺏기지 않는다.

## 7. 기수·트랙 운영 유의

- **2개 기수**: 1기 서울(호텔 스카이파크, 08.03–04) / 2기 부산(벡스코, 08.13–14). 장소·동선 멘트만 기수별로 교체, 콘텐츠는 동일.
- **트랙 인원**: 트랙 A 30명×1반 / 트랙 B 35명×2반. 트랙 B는 2개 반이 동시에 돌아가므로 강사·보조 배치·자료 2세트 확인.
- **본선**: 집합연수 약 2~2.5개월 후 별도 1일. 5분반(40명/반), 반별 전담 멘토. 트랙 구분 없이 통합 운영.
- **이수기준**: 총 900분 중 720분(80%) 이상. QR 출석(시작 전/후). 강사는 각 차시 출석 체크 협조.
