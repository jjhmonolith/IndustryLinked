# 07_delivery_scripts — 실제 수업 진행용 상세 설계 (팀모노리스 담당 차시)

각 차시를 **분 단위 진행표 + 강사 스크립트 + 강의 가이드라인**으로 확장한 실전 진행 문서.
운영안(`../03_session_plans/`)이 "무엇을"이라면, 여기는 "어떻게 말하고 진행하는가"이다.

> **범위**: 본 폴더는 **팀모노리스가 진행(주강사/담당)하는 차시**의 진행안만 둔다. 업스테이지·학회가 주강사인 차시(day1_01·03·04·05, day2_04, bonseon_04)는 각 기관이 준비하므로 제외. 전체 23차시 구조는 [`../03_session_plans/`](../03_session_plans/)에 그대로 보존.
> 원천: [`../00_연수운영계획_확정.md`](../00_연수운영계획_확정.md) · 공통 가이드라인: [`00_공통_강의_가이드라인.md`](00_공통_강의_가이드라인.md)

## 표준 템플릿 (모든 차시 진행안 공통)

```
# [블록 · N차시] 제목 — 상세 진행안

> 운영안: ../03_session_plans/<파일>.md · 공통: 00_공통_강의_가이드라인.md
> 시간: HH:MM–HH:MM (시수) / 주강사: 이름(소속) [보조] / 분반: ...

## 0. 이 차시 한눈에
- 목표(1줄) / 산출물 / 앞 차시 연결 / 다음 차시 연결

## 1. 사전 준비 (강사 체크리스트)
- [ ] 장비·계정·자료·API 키·코들 활동 사전 등록 등

## 2. 분 단위 진행표
| 시각 | 구간 | 강사 행동 | 학습자 행동 | 화면/도구 |
|------|------|-----------|-------------|-----------|
(3~7분 단위. 합계 = 세션 길이)

## 3. 강사 스크립트 (핵심 순간 대본)
### 오프닝
[강사 멘트] "..."   ← near-verbatim
### [핵심 개념/시연]
[강사 멘트] "..." / (talking point)
### [실습 지시]
[실습] ... 지시문
### [전환] / ### 마무리
[강사 멘트] "..."

## 4. 강의 가이드라인 (이 차시 특화)
- 강조점 / 피해야 할 것 / 톤 / 시간 관리 포인트

## 5. 실습 지원 · 트러블슈팅   (실습 차시)
| 상황 | 대응 |

## 6. 예상 질문 · 답변
| 질문 | 답변 |

## 7. 다음 차시 연결 멘트
[강사 멘트] "..."
```

## 스크립트 표기 규약

`[강사 멘트]`=그대로 읽는 대사 / `(talking point)`=요점만 / `[진행]`=강사 행동 / `[화면]`=띄울 자료 / `[실습]`=학습자 활동 / `[전환]`=연결 멘트 / `[체크]`=확인 신호. 상세: `00_공통_강의_가이드라인.md §3`.

## 트랙 분반 차시(day2)

`day2_*`는 트랙 A / 트랙 B 진행표·스크립트를 각각 둔다(공통 오프닝·마무리는 공유).
