# 코들 플랫폼의 연수 운영 활용 — 기능 분석 및 차시 매핑

> 작성일: 2026-06-02
> 목적: 외부 도구(구글 문서·패들릿) 대신 코들 자체 기능을 운영에 활용한다. 부가 효과 — (a) 기록·공유·피드백 도구 일원화, (b) 교원이 학생 시점에서 코들을 직접 체험.

## 1. 코들 활동 — 연수 적합성

| 활동 | 기능 | 적합성 | 대체 대상 |
|------|------|--------|-----------|
| 보드 | 자유 의견 카드·댓글, 5초 실시간 갱신, 이미지·파일, 참여도 분석 | 상 | 패들릿, 외부 회고 도구 |
| 활동지 | 정형 양식 입력(텍스트·표·체크), 1GB 업로드, 이미지 | 상 | 외부 양식 도구 |
| 퀴즈 | 객관식·서술형, AI 자동 생성, 답안 빠른 확인 | 중 | 투표·확인 도구 |
| 공부방 | 오답 반복 학습 | 부적합 | — |
| 코답 | 데이터 분석·시각화 | 본 연수 외 | — |
| 코드(파이썬) | 자동 채점·AI 튜터 | 체험 대상 | — |
| 동영상 | 인솔 모드 | 일부 활용 | — |
| 학습 분석·기상캐스터 | 진행도·정체·접속 실시간 | 강사 운영 | 출석·진도 점검 |

### 결론

- 보드: 패들릿 대체. 자유 토론·피드백·갤러리에 적합.
- 활동지: 외부 양식 대체. 정형 양식(워크시트·기획서·체크리스트)에 적합.
- 퀴즈: 가벼운 투표·확인 도구. 모델 선택·우수 사례 추천·만족도.
- 기상캐스터: 강사 운영 도구. 정체 팀 식별.

## 2. 활용 원칙

1. 부가 효과로서의 학생 시점 체험 — 교원이 학생으로 코들을 사용하면 11~13차시 도구 4요소 구현 양식을 자연 체득.
2. 짓다 갤러리 역할 분리 — 짓다 결과물은 갤러리, 텍스트 회고·피드백은 코들.
3. 동시 사용 제한 — 단일 차시에 보드·활동지·퀴즈 동시 운영 X. 1~2건으로 제한.
4. 사전 등록 — 강사가 연수 개시 전 각 차시 활동을 등록.

## 3. 차시별 매핑

| 차시 | 활동 | 코들 종류 | 비고 |
|------|------|-----------|------|
| 1 | 회고 1줄 | 보드 | 동료 글 실시간 노출, 동기 형성 |
| 2 | 두 도구 강점·한계·개선 희망 | 보드(3색 카드) | 패들릿 대체 지점 |
| 3 | Solar로 만들 도구 1줄 | 보드 | 합반 보드에서 교류 |
| 4 | 선택 기준·1차 모델 | 활동지 + 퀴즈 | 활동지(우선순위) + 퀴즈(객관식) |
| 5 | 4요소 × 2도구 표 | 활동지 | 정형 양식의 핵심 차시 |
| 6 | 가드레일 프롬프트·우회 결과 | 활동지 | 텍스트 작성 중심 |
| 7 | 도구 구조도·지원 요청 | 보드 | 이미지 첨부, 동료 작품 관람 |
| 8 | 받은 피드백·옵션 비교·트랙 확정 | 보드 + 활동지 + 퀴즈 | 차시 종료 시 트랙 확정 |
| 9 | 한계·다음 결정 | 활동지 | 간결 입력 |
| 10 | MVP v0.5 구성 | 활동지 | 11차시 입력 자료 |
| 11 | 기획서 1쪽 | 활동지 | 9개 항목 |
| 12 | 지원 요청·회고 | 보드 | 멘토 실시간 순회 |
| 13 | 시연 시나리오 | 활동지 | — |
| 14 | 받은 피드백·우수 사례 추천 | 보드 + 퀴즈 | 패들릿 대체 지점 |
| 15 | 회고 5항목·만족도 | 활동지 + 퀴즈 | 사후 보고 자료 |

## 4. 사전 준비 체크리스트

- [ ] 공통 교실 1건(1~8차시) + 트랙별 교실 2건(9~15차시 A·B). 총 3개 교실
- [ ] 입장 링크·코드 사전 안내 — 공통 교실은 1차시 직전, 트랙 교실은 8차시 종료 후
- [ ] 차시별 활동 사전 등록 — 약 20~25건
  - 보드: 약 6~7건
  - 활동지: 약 8~9건
  - 퀴즈: 약 3건
- [ ] 활동지 양식 설계(최대 비중): 5·6·7·10·11·13·15차시
- [ ] 보드 카드 색상 통일(강점=초록, 한계=황색, 개선 희망=적색)
- [ ] 실시간 분석·기상캐스터 — 유료 플랜 사전 확보
- [ ] 학습 분석을 강사 보조 화면으로 운영(별도 노트북 1대)

## 5. 부가 효과 — 학생 시점 체험을 통한 학습 연계

| 코들 체험 | 11~13차시 연결 |
|-----------|----------------|
| 보드 글 게시·댓글 | 트랙 B 학생 챗봇 화면 설계 사용성 감각 |
| 활동지 정형 양식 입력 | 트랙 A 문제 화면 설계 입력 양식 감각 |
| 퀴즈 응답 | 본인 도구의 평가 형식 결정 |
| 기상캐스터 진도 가시화 | 트랙 공통 교사 대시보드 설계 영감 |

5차시(에듀테크 프레임워크)에서 코들 자체를 4요소로 분해하면 학습 효과 극대화.

## 6. 효과·위험

### 효과

- 도구 일원화 — 외부 링크 관리·접근 권한 문제 해소
- 체험과 학습의 일치 — 학생 시점 직접 사용
- 실시간성 — 강사가 진도·정체 즉시 파악
- 자료 보존 — 교실 단위로 회고·산출물 통합, 사후 보고·바이브톤 활용

### 위험

- 사전 등록 부담 — 약 20~25건을 연수 1~2주 전 등록
- 시스템 장애 — 코들 장애 시 회고·기록 중단. 종이 양식 1세트 백업 권장
- 입장 지연 — 1차시 도입 5분 추가. 사전 안내문에 초대 코드 사전 입장 강화
