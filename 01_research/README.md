## 후속 리서치 필요 항목

- **짓다 플랫폼 가용 기능 확인** (특히 RAG/임베딩/벡터DB, 브라우저 Python 실행)
- **업스테이지 Solar/Document AI/Embeddings API** 실제 명세와 가격·레이트 리밋
- **유사 교사 연수 운영 사례** (KDAI·서울 정보교사 연구회 코들 연수, 한국컴퓨터교육학회 기존 연수)
- **1박2일 핸즈온 워크숍 운영 노하우** (50인 규모, 멘토 비율 등 — 단, 운영은 본 작업 범위 밖이므로 콘텐츠 흐름 설계 참고용)
