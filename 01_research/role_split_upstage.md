# 컨소시엄 역할 분담 — 업스테이지 운영 차시 권장

> 작성일: 2026-06-01 / 최종 갱신: 2026-06-02
> 전제: 팀모노리스 = 코들·짓다 운영사 / 업스테이지 = Solar·독파모·Document AI 개발사 / 학회 = 1차시 환영사·기조 발표 일부

## 분담 판단 기준

1. 독자 지식 우위 — 특정 회사만이 보유한 내부 정보·기술 자산이 있는가
2. 연수 목표 직결성 — "독파모 개발 목적·의의 인식" 및 "LLM 모델 특성 이해" 목표에 직접 기여하는가
3. 신뢰 효과 — 개발사 직접 설명이 참여 교원의 학습 동기 및 신뢰 형성에 기여하는가(특히 3·4·6차시)
4. 균형 — 업스테이지 단독 운영 차시가 과다할 경우 제품 홍보 편향 위험이 있어 적정 분량 유지 필요

## 업스테이지 담당 분량 요약

- 단독 운영: 3·4·6차시(3차시 = 150분)
- 공동 운영: 1차시(일부), 7차시, 9~10차시(트랙별 분반)
- 게스트: 14·15차시 심사 코멘트
- 합계: 약 4~5차시 분량(전체 15차시 중 약 30%)

## 분량 적정성 검토

- 업스테이지 단독 3·4·6차시는 Day 1 중반 블록으로, "Solar 소개 및 안전" 학습 단위를 형성한다.
- 5차시(에듀테크 프레임워크)가 3·4차시와 6차시 사이에 위치하여 강의·실습 리듬 유지에 기여한다(연속 3차시 운영의 부담 완화).

## 업스테이지에 전달할 콘텐츠 가이드

연수 원칙(지양 사항)을 사전 공유한다.

- 지양:
  - 목적 없는 상세 프롬프트 엔지니어링
  - Document AI를 트랙 적용 없이 시연만 진행
  - Solar 단독 자랑(벤치마크 수치 나열 등)
  - 이론 슬라이드 다수 운영

- 권장:
  - "교실 시나리오 → Solar의 처리 방식" 기반 구성
  - "타 모델 시연 → Solar 시연 → 차이 인식" 비교
  - 가드레일 프롬프트 패턴의 활용 가능 템플릿 제공
  - 슬라이드 < 실시간 시연 < 참여 교원 직접 입력 순으로 비중 부여

## 컨소시엄 발송용 요약문

> 업스테이지에 1차시 일부(독파모 의의), 3·4·6차시 단독, 7차시 공동, 9~10차시 기술 파트, 14~15차시 심사 게스트 역할을 제안한다. 전체 분량은 약 30% 수준이며, 이론 강의보다 시나리오 기반 시연 중심으로 운영한다.
