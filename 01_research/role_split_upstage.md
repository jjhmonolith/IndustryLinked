# 컨소시엄 역할 분담 — 업스테이지·팀모노리스·학회

>
> **갱신 노트**: 아래는 확정 계획의 강사 배정을 반영해 재작성했다. 확정본에서 업스테이지의 단독 비중이 **1일차 오후 3개 차시(Solar 원리·Document AI·보조 agent)로 확대**되었고, 가드레일(안전장치)은 팀모노리스가 맡는다.

## 판단 기준

1. 독자 지식 우위 — 특정 회사만 보유한 내부 정보·기술 자산
2. 연수 목표 직결 — "소버린 AI 의의 인식", "LLM 특성 이해" 목표에 직접 기여
3. 신뢰 효과 — 개발사 직접 설명이 학습 동기·신뢰 형성에 기여
4. 균형 — 단독 운영 과다 시 제품 홍보 편향 위험. 적정 분량 유지

## 업스테이지 분량 요약 (확정)

- 단독: day1_03·day1_04·day1_05 (1일차 오후, 각 1h = 180분)
- 공동: day1_01 일부, 본선 멘토링(bonseon_03)
- 보조: day2 트랙 실습(신화준 등)
- 합계: 약 3~4차시 상당 + 멘토링

## 적정성 검토

- 단독 3개 차시(day1_03~05)는 1일차 오후의 "Solar 원리 → 문서 데이터화 → 보조 agent 제작" 블록을 형성하며, 자료 기반 챗봇(트랙 B) 파이프라인의 핵심을 업스테이지가 직접 전달한다.
- 안전장치(day1_07)는 교실 안전 활용 경험이 더 풍부한 팀모노리스가 맡아 균형을 유지한다.

## 업스테이지 콘텐츠 가이드

- 지양:
  - 목적 없는 상세 프롬프트 엔지니어링
  - Document AI 시연만 진행
  - Solar 단독 자랑(벤치마크 수치)
  - 이론 슬라이드 다수

- 권장:
  - "교실 시나리오 → Solar 처리 방식" 구성
  - "타 모델 시연 → Solar 시연 → 차이 인식"
  - 가드레일 프롬프트 활용 템플릿 제공
  - 슬라이드 < 실시간 시연 < 교원 직접 입력

## 컨소시엄 발송용 요약문

> 업스테이지에 1차시 일부(독파모 의의), 3·4차시 단독, 7차시 공동, 9~10차시 기술 파트, 14~15차시 게스트 역할 제안. 전체 약 25%. 이론보다 시나리오 기반 시연 중심.
