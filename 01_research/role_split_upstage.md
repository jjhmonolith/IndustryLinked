# 컨소시엄 역할 분담 — 업스테이지 운영 차시

> 작성일: 2026-06-01 / 갱신: 2026-06-02
> 전제: 팀모노리스 = 코들·짓다 운영사 / 업스테이지 = Solar·독파모·Document AI 개발사 / 학회 = 1차시 환영사·기조 발표

## 판단 기준

1. 독자 지식 우위 — 특정 회사만 보유한 내부 정보·기술 자산
2. 연수 목표 직결 — "독파모 의의 인식", "LLM 특성 이해" 목표에 직접 기여
3. 신뢰 효과 — 개발사 직접 설명이 학습 동기·신뢰 형성에 기여(3·4·6차시)
4. 균형 — 단독 운영 과다 시 제품 홍보 편향 위험. 적정 분량 유지

## 업스테이지 분량 요약

- 단독: 3·4·6차시(150분)
- 공동: 1차시 일부, 7차시, 9~10차시(트랙별 분반)
- 게스트: 14·15차시
- 합계: 약 4~5차시(전체의 약 30%)

## 적정성 검토

- 단독 3·4·6차시는 Day 1 중반 "Solar 소개·안전" 블록을 형성한다.
- 5차시(에듀테크 프레임워크)가 3·4차시와 6차시 사이에 있어 강의·실습 리듬을 유지한다.

## 업스테이지 콘텐츠 가이드

- 지양:
  - 목적 없는 상세 프롬프트 엔지니어링
  - Document AI 시연만 진행
  - Solar 단독 자랑(벤치마크 수치)
  - 이론 슬라이드 다수

- 권장:
  - "교실 시나리오 → Solar 처리 방식" 구성
  - "타 모델 시연 → Solar 시연 → 차이 인식"
  - 가드레일 프롬프트 활용 템플릿 제공
  - 슬라이드 < 실시간 시연 < 교원 직접 입력

## 컨소시엄 발송용 요약문

> 업스테이지에 1차시 일부(독파모 의의), 3·4·6차시 단독, 7차시 공동, 9~10차시 기술 파트, 14~15차시 게스트 역할 제안. 전체 약 30%. 이론보다 시나리오 기반 시연 중심.
