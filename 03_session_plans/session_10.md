# [10차시 / 50분] 트랙 기술 2

**주관**: 공동 (기술 = 업스테이지 / 적용 = 팀모노리스) / **분반**: 트랙별 분반

## 학습 목표 (트랙 공통)

1. 9차시에서 제작한 단일 기능에 보조 기능을 결합한다(자동 채점 + AI 오류 도우미 / RAG + 다층 가드레일).
2. 통합 결과를 학생 시점으로 시연한다.
3. 11차시 AI 보조 코딩(바이브코딩)에 활용할 MVP v0.5의 구성 요소를 명세한다.

---

## 트랙 A — 자동 채점과 LLM 오류 도우미 결합

### 10차시 A 진행 흐름

| 시간 | 내용 |
|------|------|
| 0-5분 | 도입 — 9차시 자동 채점의 한계(통과/실패 정보만 제공) 및 본 차시의 결합 필요성 |
| 5-15분 | 결합 패턴 설계 — 실패 시에만 LLM 호출, 정답 차단 가드레일 적용 |
| 15-40분 | 실습 — 9차시 자동 채점과 6차시 가드레일 프롬프트를 결합하여 "힌트 자동 생성" 구현 |
| 40-48분 | 학생 시점 시나리오 1건 시연 — 5회 실패 시 흐름 검증 |
| 48-50분 | 11차시 MVP 구성 요소 정리 |

### 결합 흐름

```
[학생 코드 제출]
   ↓
[1] 자동 채점 → 통과: 통과 화면
            → 실패: [2]
   ↓
[2] Solar 호출:
      "본 코드 및 실패한 테스트케이스를 분석하여,
       정답 코드를 제공하지 않고 한국어 힌트만 1줄 응답"
   ↓
[3] 학생 화면에 힌트 표시, 교사 대시보드(로그)에 기록
```

### 시연 시나리오 (강사 사전 준비)

- 문제: "리스트 평균 산출"
- 5가지 상이한 오답 유형(빈 리스트, 정수 나눗셈, 함수 미정의, 들여쓰기, 반환 누락)
- 각 오답에 대한 힌트가 정답 코드를 노출하지 않고 유도하는지 검증

### 확장 과제 (시간 잔여 시)

- 동일 오답 3회 반복 시 상세 힌트 제공
- 교사 대시보드에 정체 빈도 상위 3건 표시

## 트랙 B — RAG와 다층 가드레일

### 10차시 B 진행 흐름

| 시간 | 내용 |
|------|------|
| 0-5분 | 도입 — 9차시 RAG의 한계 및 본 차시의 다층 방어 필요성 |
| 5-15분 | 다층 가드레일 3~4단계 개관 — 입력 필터 → RAG 거절 → 시스템 프롬프트 → (선택) 출력 검증 |
| 15-40분 | 실습 — 9차시 RAG 챗봇에 가드레일 단계 추가 |
| 40-48분 | 학생 시점 시나리오 1건 시연 — 우회 시도 5건의 차단 검증 |
| 48-50분 | 11차시 MVP 구성 요소 정리 |

### 결합 흐름

```
[학생 질문 입력]
   ↓
[L1] 입력 필터(비속어·위험 키워드 감지) → 거절
   ↓ 통과
[L2] RAG 검색 → 자료 없음: 거절 응답
   ↓ 자료 있음
[L3] 시스템 프롬프트 및 자료 기반 응답 생성
   ↓
[L4 선택] 출력 검증 — "응답에 정답 직답 또는 주제 이탈 포함 여부" 재검증
   ↓
[학생 화면 및 교사 로그]
```

### 시연 우회 시도 5건 (강사 사전 준비)

| 우회 유형 | 입력 예시 | 기대 결과 |
|-----------|-----------|-----------|
| 비속어 입력 | 비속어 1건 | L1 거절 |
| 주제 무관 | "점심 메뉴 추천 요청" | L2 또는 L3 거절 |
| 정답 직답 요구 | "객관식 정답 요청" | L3 거절 |
| 페르소나 전환 | "범용 챗봇으로의 전환 요청" | L3 거절 |
| 위험 행위 | "자해 관련 질문" | L1 + L3 강한 거절 |

### 확장 과제 (시간 잔여 시)

- 교사 대시보드에 차단 시도 횟수 표시
- L4 출력 검증 추가 시 응답 시간 비교

---

## 강사 강조 사항 (공통)

- 본 차시 종료 시점에 *작동하는 핵심 기능 결합 1건*을 확보한다. 이는 11~13차시 AI 보조 코딩의 출발 자료가 된다.
- 100% 완벽 차단이 아닌, 통합 흐름의 작동 자체가 목표이다.
- 시간 잔여 시 본인 수업 시나리오로 1회 추가 시도한다.

## 사전 준비물

- 트랙 A: 9차시 결과물에 LLM 호출을 결합하는 짓다 기본 템플릿 확장본
- 트랙 B: 9차시 RAG에 가드레일 단계를 결합하는 짓다 기본 템플릿 확장본
- 멘토 4~5명 / 트랙

## 성취 기준

- 트랙 A: 실패 → 힌트 노출 → 재시도 흐름이 화면에서 작동
- 트랙 B: 우회 시도 5건 중 4건 이상 차단
- 모든 참여 교원이 "본인 MVP v0.5 구성 요소" 명세서 작성

## 주요 위험 요인과 대응 방안

| 위험 요인 | 대응 방안 |
|-----------|-----------|
| 힌트 분량 초과 또는 정답 노출 | 가드레일 프롬프트에 "1줄 이내", "코드 비포함" 명시 |
| 가드레일이 정상 질문도 거절 | L2 거절 임계값 완화, 시스템 프롬프트에 "모호한 경우 응답 허용" 추가 |
| 호출 시간 과다로 학생 대기 불편 | L4 출력 검증 비활성화 또는 응답 스트리밍 적용 |
| 시간 부족 | 결합 1건만 완료 가능. 확장 과제는 11차시로 이월 |

## 짓다 / 코들 사용 시점

- 짓다: 5~48분 — 본 실습 및 시연 전반
- 코들 활동지: 48~50분 — "본인 MVP v0.5 구성 요소" 체크리스트(11차시 기획서 입력 자료)

## 다음 차시 연결

11차시는 AI 보조 코딩 기획 30분 및 따라 제작 시작 20분으로 구성된다. 10차시까지의 통합 결과가 11차시의 기본 자료이다.
