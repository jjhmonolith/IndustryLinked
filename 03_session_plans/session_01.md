# [1차시 / 50분] 개회 및 기조 강연

**주관**: 학회(전반) + 업스테이지(후반) / **분반**: 공통

## 학습 목표

1. 연수 취지와 본인 산출물을 한 문장으로 설명한다.
2. 정보교사 역할 변화를 인식한다.
3. 독자 파운데이션 모델이 한국 교실에 갖는 의미를 설명한다.

## 진행 흐름

| 시간 | 내용 | 담당 |
|------|------|------|
| 0-5분 | 환영·일정 안내 | 팀모노리스 |
| 5-25분 | 학회 환영사·기조 발표 — 정보교사 역량강화 방향, 바이브톤까지의 여정 | 학회 |
| 25-45분 | 업스테이지 기조 강연 — 독파모 정의·필요성·교실 적용 | 업스테이지 |
| 45-50분 | 마무리 — 일정·트랙 안내, 코들 보드 첫 회고 입력 | 팀모노리스 |

## 강사 강조

- 학회: 본 연수 후 참여 교원은 도구 *사용자*에서 *제작자*로 확장된다.
- 업스테이지: 범용 LLM은 한국 교실 맥락을 충분히 반영하지 못한다. 독파모는 한국 교실에 맞춰 개발되었다.
- 공통: 본 연수는 강의가 아닌 체험·제작 중심이다.

## 성취 기준

- 사전 조사로 트랙 선택 응답이 완료되어 있다.
- 코들 보드에 "해결할 수업 문제 1줄"을 기록한다.

## 주요 위험·대응

| 위험 | 대응 |
|------|------|
| 발표 시간 초과 | 시간 카드 운영(20분 / 종료 2분 전). 진행자가 마감 안내 |
| 제품 홍보 편향 | 사전 가이드 — "슬라이드 5장 이내, 시연 1건, 벤치마크 미사용" |
| 집중도 저하 | 25분 시점 청중 인터랙션 1회("AI 도구 활용 경험" 거수) |

## 짓다·코들

- 코들 보드: 45분 — 회고 1건 입력(학생 시점 첫 접속)
- 짓다: 미사용(계정 안내만)

## 다음 차시
