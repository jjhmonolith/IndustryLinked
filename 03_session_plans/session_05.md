# [5차시 / 50분] 에듀테크 프레임워크 — 수업도구 구조 4요소

**주관**: 팀모노리스 / **분반**: 공통

## 학습 목표

1. 수업도구의 4요소(학생-교사 구분·활동 배부·결과물 제출·교사 대시보드)를 자신의 언어로 설명할 수 있다.
2. 2차시에서 체험한 두 도구(코들 자동채점·소크룸)를 4요소로 비교 분석한다.
3. 2차시에서 기록한 "개선 희망 항목"이 4요소 중 어느 항목에 해당하는지 매핑한다.

## 진행 흐름

| 시간 | 내용 |
|------|------|
| 0-5분 | 도입 — 수업도구를 4요소로 분해하는 프레임워크 소개 |
| 5-15분 | 4요소 이론 강의 — 코들·소크룸 화면 캡처를 4요소로 색상 구분하여 제시 |
| 15-35분 | 팀별 비교 분석 — 두 도구를 단일 표에 병렬 기재 |
| 35-45분 | 매핑 활동 — 2차시 "개선 희망 항목"의 4요소 분류 |
| 45-50분 | 정리 — 9차시 트랙 결정 시 본인이 깊이 학습하고자 하는 도구의 4요소 1건 기록 |

## 수업도구 4요소 — 정의 및 두 도구 비교

| 요소 | 정의 | 코들(자동채점) | 소크룸(교과 챗봇) |
|------|------|----------------|-------------------|
| 학생-교사 구분 | 권한 및 식별 방식 | 교사: 문제 제작 / 학생: 코드 작성·제출(계정 식별) | 교사: 자료·주제 설정 / 학생: 닉네임 입장(경량 식별) |
| 활동 배부 | 교사가 제작한 활동의 학생 전달 방식 | 문제 링크, 코스 등록 | 수업 링크(소크룸 방식) |
| 결과물 제출 | 학생 활동의 수집 형태 | 코드, 자동채점 결과, AI 대화 로그 | 학생-AI 대화 로그, 학습 활동 응답 |
| 교사 대시보드 | 교사의 모니터링 및 개입 방식 | 학생별 통과율, 정체 구간, AI 대화 내역 | 학생별 대화 흐름, 이해도 신호, 위험 발화 |

## 강사 토의 유도 질문

- 공통: 자동채점 통과 시점과 실제 학습 도달 시점이 일치하지 않는 사례, 소크룸에서 응답 완료 시점과 학습 도달 시점이 일치하지 않는 사례 → "AI 대화 로그도 결과물의 일부"라는 시사점 도출
- 차이: 계정 기반 식별과 닉네임 기반 식별의 적용 상황 비교
- 확장: 두 도구의 공통 한계 1건 식별 → 학습 도달 평가의 어려움

## 강사 강조 사항

- 11~13차시 제작 도구도 본 4요소를 모두 갖춰야 한다. 본 차시는 그 설계의 기반이다.
- 두 도구 비교를 통해 *공통 패턴*과 *트랙별 특수성*을 동시에 도출한다.
- 4요소를 동시에 완성하기는 어렵다. 가장 개선이 필요한 1요소부터 접근하는 것이 권장된다.

## 사전 준비물

- 코들·소크룸 화면 캡처를 4요소로 색상 구분한 슬라이드 2장
- 코들 활동지 — 4요소 비교표 양식

## 성취 기준

- 모든 참여 교원이 코들 활동지(4요소 × 2도구 비교표)를 완성한다.
- 2차시 "개선 희망 항목"의 4요소 매핑을 완료한다.
- 강사가 코들 학습 분석 화면에서 작성률 100%를 확인한다.

## 주요 위험 요인과 대응 방안

| 위험 요인 | 대응 방안 |
|-----------|-----------|
| 이론 강의 시간 초과 | 5~15분 슬라이드 8장 이내 제한, 강사 시간 점검 |
| 한 도구만 입력하고 다른 도구를 입력하지 않음 | 15분 시점에 강사가 미입력 도구를 확인하여 안내 |
| "4요소 간 구분이 불명확" 의견 | "결과물 제출"과 "교사 대시보드"의 차이를 구체 사례(코드 제출 자체와 통과율 통계의 차이)로 설명 |
| 매핑이 막연한 팀 | 강사가 순회하며 1요소를 함께 입력 |

## 짓다 / 코들 사용 시점

- 코들 활동지: 15~50분 — 4요소 × 2도구 비교표 및 매핑 입력. 부가 효과로 활동지 양식 자체가 11차시 기획서의 기본 구조가 된다.
- 짓다: 미사용

## 강사 운영 도구

- 코들 학습 분석 / 기상캐스터: 강사가 작성 진행률·정체 팀을 실시간 확인하여 우선 순회 대상 식별
