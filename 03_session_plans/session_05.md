# [5차시 / 50분] 에듀테크 프레임워크 — 수업도구 구조 4요소

**주관**: 팀모노리스 / **분반**: 공통

## 학습 목표

1. 4요소(학생-교사 구분·활동 배부·결과물 제출·교사 대시보드)를 본인 언어로 설명한다.
2. 2차시 두 도구를 4요소로 비교 분석한다.
3. 2차시 "개선 희망 항목"을 4요소에 매핑한다.

## 진행 흐름

| 시간 | 내용 |
|------|------|
| 0-5분 | 도입 — 4요소 프레임워크 소개 |
| 5-15분 | 4요소 이론 — 코들·소크룸 화면을 색상 구분 |
| 15-35분 | 팀별 비교 분석 — 두 도구를 단일 표에 병렬 기재 |
| 35-45분 | 매핑 — "개선 희망 항목"의 4요소 분류 |
| 45-50분 | 정리 — 트랙 결정 시 깊이 학습할 도구의 4요소 1건 기록 |

## 4요소 정의 및 두 도구 비교

| 요소 | 정의 | 코들(자동채점) | 소크룸(교과 챗봇) |
|------|------|----------------|-------------------|
| 학생-교사 구분 | 권한·식별 방식 | 교사: 문제 제작 / 학생: 코드 제출(계정) | 교사: 자료·주제 설정 / 학생: 닉네임(경량) |
| 활동 배부 | 학생 전달 방식 | 문제 링크, 코스 등록 | 수업 링크 |
| 결과물 제출 | 수집 형태 | 코드·자동채점 결과·AI 대화 로그 | 학생-AI 대화 로그·학습 응답 |
| 교사 대시보드 | 모니터링·개입 | 통과율·정체 구간·AI 대화 | 대화 흐름·이해도·위험 발화 |

## 강사 토의 질문

- 공통: 자동채점 통과·소크룸 응답 완료 시점이 학습 도달 시점과 불일치한 사례 → "AI 대화 로그도 결과물의 일부" 시사점
- 차이: 계정 식별 vs 닉네임 식별의 적용 상황
- 확장: 두 도구의 공통 한계 → 학습 도달 평가의 어려움

## 강사 강조

- 11~13차시 제작 도구도 4요소를 모두 갖춘다. 본 차시는 그 설계 기반이다.
- 비교를 통해 *공통 패턴*과 *트랙별 특수성*을 동시에 도출한다.
- 4요소를 동시에 완성하지 못한다. 개선이 필요한 1요소부터 접근한다.

## 사전 준비물

- 코들·소크룸 화면 캡처를 4요소로 색상 구분한 슬라이드 2장
- 코들 활동지 — 4요소 비교표 양식

## 성취 기준

- 모든 교원이 코들 활동지를 완성한다.
- "개선 희망 항목"의 4요소 매핑을 완료한다.
- 강사가 학습 분석에서 작성률 100% 확인.

## 주요 위험·대응

| 위험 | 대응 |
|------|------|
| 이론 시간 초과 | 5~15분 슬라이드 8장 이내 |
| 한 도구만 입력 | 15분 시점 강사가 미입력 도구 안내 |
| 4요소 구분 모호 | "결과물 제출"과 "교사 대시보드"의 차이를 구체 사례로 |
| 매핑 막연 | 강사가 1요소 함께 입력 |

## 짓다·코들

- 코들 활동지: 15~50분 — 4요소 × 2도구 표·매핑. 활동지 양식이 11차시 기획서 원형
- 짓다: 미사용

## 강사 운영 도구

- 코들 학습 분석·기상캐스터: 작성 진행률·정체 팀 실시간 확인
