# [5차시 / 50분] Solar 모델 소개

**주관**: 업스테이지 / **분반**: 양 트랙 합반 가능 (트랙별 시연 1개씩)

## 학습 목표

1. Solar가 어떤 모델이고 어떤 점에서 다른 모델과 다른지 한 문장으로 말할 수 있다.
2. "독자 파운데이션 모델"이라는 표현의 의미를 자기 언어로 설명할 수 있다.
3. Solar로 무엇이 가능한지(텍스트 생성·코드 설명·요약·번역 등) 손에 잡히게 안다.

## 진행 흐름

| 시간 | 내용 |
|------|------|
| 0-5분 | 도입 — "여러분이 어제 쓴 코들 AI 도우미·소크룸 챗봇, 그 뒤에 무엇이 있을까?" |
| 5-15분 | Solar / 독파모 개요 — 슬라이드 5장 이내, 벤치마크 숫자 X |
| 15-30분 | **라이브 시연 1** (트랙 A 향): 동일한 코드 오류를 Solar / GPT / Gemini에게 설명 요청 → 한국어 톤·구체성 비교 |
| 30-42분 | **라이브 시연 2** (트랙 B 향): 한국 중·고 교과서 문장 한 단락 → 요약 / 질문 생성 → 모델별 비교 |
| 42-50분 | 질의응답 + **코들 보드** — "Solar로 내가 만들고 싶은 것 한 가지" 한 줄 카드 (양 트랙 합반 보드 → 트랙 간 아이디어 교류) |

## 강사 핵심 메시지 (업스테이지에게 사전 가이드)

- ❌ 벤치마크 점수 비교, 파라미터 수, 모델 아키텍처 설명
- ✅ "한국 교실에서 일어나는 일을 보여주고, Solar가 그걸 어떻게 다루는지 시연"
- ✅ "ChatGPT가 못하는 것이 아니라, *우리 교실에 맞춰 우리가 통제할 수 있는 모델이 있다*는 점"
- ✅ 약점도 솔직히: "Solar는 X에선 GPT보다 약합니다, 대신 Y에선 강합니다"

## 사전 준비물

- 업스테이지: 시연 코드 2개 (코드 오류 설명·교과서 요약), 짓다 또는 콘솔에서 라이브 실행
- 강사: 마이크 · 빔 · 안정적인 인터넷
- 학습자: 노트북 펴두기 (체험은 없지만 화면을 보며 즉시 짓다에서 따라할 수 있도록)

## 체크포인트

- "독파모"의 의미를 옆자리에게 30초로 설명할 수 있다 (짝 활동)
- 시연 2개에서 모델 차이를 한 가지씩 짚어낼 수 있다

## 흔한 실패 패턴과 대응

| 실패 | 대응 |
|------|------|
| 강사가 슬라이드 위주로 설명하다가 시간 다 씀 | 사전 가이드에 "15분 시점에 무조건 시연 진입" 명시 |
| 모델 비교가 모호함 | 비교 항목을 사전에 표로 만들어두기 (속도·한국어 자연스러움·교사 지정 규칙 준수도) |
| 라이브 데모 API 실패 | 백업 영상 또는 사전 캡처 슬라이드 1세트 준비 |

## 짓다 / 코들 사용 시점

- **짓다**: 시연 화면 (강사). 학습자는 아직 직접 호출 X
- **코들 보드 (합반)**: 42분 — "Solar로 만들고 싶은 것 한 줄"
