## 차시별 공통 템플릿

각 운영안 파일은 다음 항목을 포함한다.

- 학습 목표(3건 이내)
- 진행 흐름 표(분 단위)
- 강사 강조 사항
- 사전 준비물
- 성취 기준
- 주요 위험 요인과 대응 방안
- 짓다·코들 사용 시점
- 다음 차시 연결

## 산출물 진화 흐름

