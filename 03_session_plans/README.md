## 차시별 공통 템플릿

각 파일은 다음 항목을 포함:

- 학습 목표 (3개 이내)
- 진행 흐름 표 (분 단위)
- 강사 핵심 메시지
- 사전 준비물
- 체크포인트
- 흔한 실패 패턴과 대응
- 짓다 / 코들 사용 시점
- 다음 차시 연결

## 산출물 진화 흐름

```
2차시: 좋은점/아쉬운점 기록
   ↓
3차시: 4요소 분해표
   ↓
4차시: 짓다 MVP v0 (LLM 없이 한 화면 흐름)
   ↓
8차시: Solar 첫 호출 (가드레일 입은 챗봇 함수)
   ↓
10차시: 트랙 핵심 기능 결합 (자동채점+힌트 / RAG+가드레일)
   ↓
12차시: MVP 동작 완성
   ↓
13차시: 자기 수업 색깔 입힌 v2
   ↓
14차시: 동료 피드백
   ↓
15차시: 바이브톤 진입 결심
```

## 검증해야 할 항목 (각 차시 운영안에서 표시)

- 짓다에서 브라우저 Python 실행 가능 여부 (4·9·11·12차시 영향)
- 짓다에서 RAG/임베딩 지원 범위 (9·11·12차시 영향)
- 공용 API 키 레이트 리밋 (8·9·10·12차시 영향)
- 짓다 갤러리·댓글 기능 동작 (4·13·14차시 필수)

위 항목들은 Phase 1 검증 단계에서 컨소시엄 확인이 끝나야 차시 운영안의 일부 절차가 확정된다.
