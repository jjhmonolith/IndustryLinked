# [4차시 / 50분] Solar vs Other LLM — 선택 기준

**주관**: 업스테이지 / **분반**: 공통

## 학습 목표

1. LLM 선택 기준 3가지 이상을 본인 언어로 설명한다.
2. 동일 입력의 모델별 출력 차이를 관찰한다.
3. 본인 도구의 1차 선택 모델을 결정한다.

## 진행 흐름

| 시간 | 내용 |
|------|------|
| 0-5분 | 도입 — Solar 외 선택지를 검토하는 이유 |
| 5-15분 | 선택 기준 — 목적·한국어 자연성·비용·통제 가능성·출력 형식 |
| 15-30분 | 시연 1(정답 차단형) — "정답 비제공, 힌트만" 프롬프트에 대한 모델별 규칙 준수도 |
| 30-42분 | 시연 2(범위 제한형) — "교과서 범위 내 응답" 프롬프트에 대한 모델별 주제 외 질문 처리 |
| 42-50분 | 팀별 토의 + 활동지(선택 기준 우선순위) + 퀴즈(1차 선택 모델) |

## 강사 강조 (업스테이지 사전 가이드)

- Solar가 무조건 우위가 아님을 명시.
- 본 차시는 *선택 기준* 학습이지 제품 홍보가 아니다.
- 모델별 한계 각 1건 명시.

## 선택 기준 시트 (코들 활동지)

| 기준 | 설명 | 우선순위(1~5) |
|------|------|---------------|
| 한국어 자연성 | 학생 어휘 수준 응답 | |
| 통제 가능성 | "정답 차단" 등 규칙 준수 | |
| 비용 | 50명 동시 사용 가능성 | |
| 응답 속도 | 학생 대기 시간 | |
| 형식 안정성 | JSON 등 지정 형식 준수 | |

코들 퀴즈(객관식)로 "1차 선택 모델" 응답. 강사가 분포 실시간 확인.

## 성취 기준

- 모든 교원이 선택 기준 우선순위 5건 입력.
- 팀별 "1차 선택 모델" 결정·기록(Solar / GPT-5.4 / Gemini / 기타).

## 주요 위험·대응

| 위험 | 대응 |
|------|------|
| 주관적 인상 비평 | 시연 전 평가 항목 3건 화면 표시 |
| "Solar 결정" 후 검토 중단 | Solar 약점 시나리오 1건 의도적 시연 |
| 시간 부족 | 시연 2를 5분 압축 |

## 짓다·코들

- 짓다: 강사 시연
- 코들 활동지: 42분 — 우선순위 입력
- 코들 퀴즈: 42~50분 — 1차 선택 모델
