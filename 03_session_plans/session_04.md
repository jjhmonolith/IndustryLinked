# [4차시 / 50분] 일단 만들어보자 + 서로 써보기

**주관**: 팀모노리스 / **분반**: 트랙별 분반, 3-5인 팀 단위

## 학습 목표

1. 짓다에 첫 프로젝트를 만들고 한 화면이 동작하는 결과물을 본다.
2. 옆 팀의 결과물에 실제로 들어가 써보고 피드백 한 가지를 남긴다.
3. "아직은 못한다"는 좌절감을 인정하고, 5차시 이후 무엇이 보완되어야 하는지 적는다.

## 진행 흐름 (공통)

| 시간 | 내용 |
|------|------|
| 0-5분 | 도입 — "오늘 잘 못 만든다. 그게 정상. *동작하는 한 화면*만 만들자." |
| 5-10분 | 짓다 사용법 빠른 시연 — 프로젝트 생성·미리보기·배포 링크 |
| 10-35분 | **MVP v0 만들기**: 팀별로 1개 |
| 35-45분 | **개밥먹기 (도그푸딩)**: 옆 팀 링크로 들어가 학생 시점에서 써보기 → 짓다 갤러리 댓글로 피드백 |
| 45-50분 | 회고 — "5차시 이후 무엇을 배워야 더 잘 만들 수 있을까?" **코들 보드** 카드 1장 |

## 트랙 A — 4차시 MVP v0 목표

**오늘 만들 것**: "문제 1개를 학생이 풀고 제출하는 화면"

- 교사 화면(이번엔 생략, 문제는 강사가 미리 등록): 문제 제목 · 설명 · 기대 출력
- 학생 화면:
  - 문제 보기
  - 코드 입력란 (단순 textarea)
  - 제출 버튼 → 정답 비교 (단순 문자열 매칭 OK) → 통과/실패 표시
- **포함 안 해도 되는 것**: 실제 Python 실행, AI 도우미, 대시보드, 로그인

➜ "4요소 중 *결과물 제출* 한 가지만" 구현하는 것이 4차시 목표.

## 트랙 B — 4차시 MVP v0 목표

**오늘 만들 것**: "교과 단원 1개에 대해 학생이 질문하면 답이 나오는 화면"

- 교사 화면(이번엔 생략, 자료는 강사가 미리 넣음): 단원 제목 · 발췌문 1개
- 학생 화면:
  - 닉네임 입력
  - 단원 설명 표시
  - 질문 입력 → 답변 출력 (이번엔 LLM 없이 미리 만든 Q&A 매칭 OK)
- **포함 안 해도 되는 것**: 실제 Solar 호출, RAG, 가드레일, 대시보드

➜ "4요소 중 *학생-교사 구분* + *결과물 제출*" 한 두 가지만 구현.

## 강사 핵심 메시지

- "오늘 만든 것은 *진짜 못합니다*. 그게 정상."
- "**LLM 없어도 한 화면이 흐르는 경험**이 오늘의 목표. 5-10차시에서 점점 채운다."
- "옆 팀 결과물을 진지하게 써보세요. 본인이 학생이라면 무엇이 답답할지 적어주세요."

## 사전 준비물

- 짓다 스타터 템플릿 (트랙별 1개)
- 트랙 A: 미리 등록한 문제 1개 (예: "1부터 10까지 합")
- 트랙 B: 미리 정리한 단원 발췌 1개 (예: 정보 교과 "인공지능의 정의")
- 멘토 4-5명 / 50명 분반

## 체크포인트

- 모든 팀이 짓다 갤러리에 링크를 올렸다 (이게 4차시 합격 기준)
- 옆 팀 결과물에 댓글 1개 이상 남겼다
- "5차시 이후 무엇이 필요한가" **코들 보드** 1줄 카드

## 흔한 실패 패턴과 대응

| 실패 | 대응 |
|------|------|
| 짓다 사용법 막힘 | 멘토가 즉시 1:1. 강사 시연 화면 계속 띄워두기 |
| 욕심내서 LLM부터 붙이려 함 | "LLM은 5-10차시 후에. 오늘은 *한 화면이 흐르는* 것만" 차단 |
| 팀 내에서 한 명만 작업, 나머지 구경 | 팀에 역할 분담 카드 배포 (제작자/테스터/기록자/관찰자) |
| 시간 부족 | 5분 단위 체크인 — "10분 후 학생화면 입력 완성 / 20분 후 결과 표시" 마일스톤 |

## 짓다 / 코들 사용 시점

- **짓다 갤러리**: 10-45분 — 프로젝트 생성·작업·갤러리 업로드·옆 팀 체험·댓글 (짓다 작품 자체 공유)
- **코들 보드**: 45-50분 — "5차시 이후 무엇이 필요한가" 회고 카드 (텍스트 회고는 코들로 통일)
