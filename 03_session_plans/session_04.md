# [4차시 / 50분] 일단 만들어보자 + 서로 써보기

**주관**: 팀모노리스 / **분반**: 공통(단일 트랙), 3-5인 팀 단위

## 학습 목표

1. 짓다에 첫 프로젝트를 만들고 한 화면이 동작하는 결과물을 본다.
2. 옆 팀의 결과물에 실제로 들어가 써보고 피드백 한 가지를 남긴다.
3. "아직은 못한다"는 좌절감을 인정하고, 5차시 이후 무엇이 보완되어야 하는지 적는다.

## 진행 흐름

| 시간 | 내용 |
|------|------|
| 0-5분 | 도입 — "오늘 잘 못 만든다. 그게 정상. *동작하는 한 화면*만 만들자." |
| 5-10분 | 짓다 사용법 빠른 시연 — 프로젝트 생성·미리보기·배포 링크 |
| 10-35분 | **공통 베이스라인 MVP v0 만들기**: 팀별로 1개 |
| 35-45분 | **개밥먹기 (도그푸딩)**: 옆 팀 링크로 들어가 학생 시점에서 써보기 → 짓다 갤러리 댓글 |
| 45-50분 | 회고 — "5차시 이후 무엇을 배워야 더 잘 만들 수 있을까?" **코들 보드** 카드 1장 |

## 공통 베이스라인 MVP v0 목표

**오늘 만들 것**: "학생이 *무언가를 입력*하면 *결과 화면*이 나오는 한 화면" — 트랙 A·B 어느 쪽에도 적용 가능한 *원형*.

- 교사 화면(이번엔 생략, 콘텐츠는 강사가 미리 등록): 활동 제목 + 설명 + 기대 결과
- 학생 화면:
  - 활동 설명 표시
  - 입력란 1개 (텍스트 또는 코드)
  - 제출 버튼 → 결과 표시 영역
- **포함 안 해도 되는 것**: LLM 호출, 자동 채점, RAG, 가드레일, 대시보드, 로그인

➜ "4요소 중 *결과물 제출* 한 가지"만 동작하게. 입력에 무엇을 받고 결과에 무엇을 보여줄지는 팀이 자유롭게 결정 (코드·짧은 글·질문 등).

### 팀별 선택 예시 (강사 제시, 강제 X)

- "1부터 10까지 합을 구하는 코드를 입력 → 정답 비교" (코드 채점형)
- "동물 한 종류를 입력 → 미리 등록한 한 줄 설명 표시" (Q&A형)
- "수업 단원 이름 입력 → 미리 등록한 학습 목표 표시" (단원 안내형)

오늘은 어느 쪽이든 OK. 6-8차시 학습 후 본격 트랙을 결정한다.

## 강사 핵심 메시지

- "오늘 만든 것은 *진짜 못합니다*. 그게 정상."
- "**LLM 없어도 한 화면이 흐르는 경험**이 오늘의 목표. 5-10차시에서 점점 채운다."
- "트랙은 아직 결정 X. 오늘 만든 것이 어느 트랙으로 흘러갈지는 8차시 끝에 본인이 결정."
- "옆 팀 결과물을 진지하게 써보세요. 본인이 학생이라면 무엇이 답답할지 적어주세요."

## 사전 준비물

- 짓다 공통 스타터 템플릿 1종 (입력란 + 결과 영역의 빈 양식)
- 강사 시연용 베이스라인 1개 (위 3가지 예시 중 1개를 5분 안에 보여주기)
- 멘토 5-7명 (100명 / 멘토 1인 ≈ 15-20명)

## 체크포인트

- 모든 팀이 짓다 갤러리에 링크를 올렸다 (이게 4차시 합격 기준)
- 옆 팀 결과물에 댓글 1개 이상 남겼다
- "5차시 이후 무엇이 필요한가" **코들 보드** 1줄 카드

## 흔한 실패 패턴과 대응

| 실패 | 대응 |
|------|------|
| 짓다 사용법 막힘 | 멘토가 즉시 1:1. 강사 시연 화면 계속 띄워두기 |
| 욕심내서 LLM부터 붙이려 함 | "LLM은 8차시 이후. 오늘은 *한 화면이 흐르는* 것만" 차단 |
| 트랙 결정에 시간 낭비 | "오늘은 트랙 결정 X. 일단 만들어보고 결정은 8차시 끝에" 강조 |
| 팀 내에서 한 명만 작업, 나머지 구경 | 팀에 역할 분담 카드 (제작자/테스터/기록자/관찰자) |
| 시간 부족 | 5분 단위 체크인 — "15분: 입력란 / 25분: 결과 표시 / 35분: 갤러리 업로드" |

## 짓다 / 코들 사용 시점

- **짓다 갤러리**: 10-45분 — 프로젝트 생성·작업·갤러리 업로드·옆 팀 체험·댓글
- **코들 보드**: 45-50분 — "5차시 이후 무엇이 필요한가" 회고 카드

## 다음 차시 연결
