# [4차시 / 50분] Solar vs Other LLM — 모델 선택 기준

**주관**: 업스테이지 / **분반**: 공통

## 학습 목표

1. LLM 선택 기준 3가지 이상을 자신의 언어로 설명할 수 있다(목적·비용·통제 가능성).
2. 동일 입력에 대한 모델별 출력 차이를 직접 관찰한다.
3. 본인이 제작할 도구의 1차 선택 모델을 결정한다.

## 진행 흐름

| 시간 | 내용 |
|------|------|
| 0-5분 | 도입 — Solar 외의 선택지를 검토하는 이유 |
| 5-15분 | 선택 기준 정립 — 목적·한국어 자연성·비용·통제 가능성·출력 형식 |
| 15-30분 | 실시간 시연 1 (정답 차단 패턴) — "정답을 제공하지 않고 힌트만 제공" 시스템 프롬프트에 대한 Solar / GPT / Gemini 비교. 규칙 준수도 평가 |
| 30-42분 | 실시간 시연 2 (범위 제한 패턴) — "주어진 교과서 범위 내에서만 응답" 프롬프트에 대한 주제 외 질문의 모델별 처리 비교 |
| 42-50분 | 팀별 토의 — "본인 도구의 1차 선택 모델" 결정. 코들 활동지(선택 기준 우선순위) 및 코들 퀴즈(1차 선택 모델) 응답 |

## 강사 강조 사항 (업스테이지 사전 가이드)

- Solar가 무조건 우위의 모델이 아님을 명시한다. 통제 가능성·한국어 자연성·비용 측면의 강점과, 그 외 영역의 한계를 함께 제시한다.
- 본 차시 목적은 *선택 기준 자체*의 학습이며, 제품 홍보가 아니다.
- 모델별 한계를 명시: Solar 한계 1건, GPT 한계 1건, Gemini 한계 1건

## 선택 기준 시트 (코들 활동지 사전 등록)

| 기준 | 설명 | 본인 도구 우선순위 (1~5) |
|------|------|--------------------------|
| 한국어 자연성 | 학생 어휘 수준에 맞춰 응답하는가 | |
| 통제 가능성 | "정답 차단" 등의 규칙 준수도 | |
| 비용 | 50명 동시 사용 시 운영 가능성 | |
| 응답 속도 | 학생의 대기 시간 최소화 | |
| 형식 안정성 | JSON 등 지정 형식 준수도 | |

코들 퀴즈(객관식 1문항)로 "1차 선택 모델"을 응답받아 강사가 응답 분포를 실시간 확인한다.

## 성취 기준

- 모든 참여 교원이 선택 기준 시트에 우선순위 5건을 모두 입력한다.
- 팀별로 "1차 선택 모델"을 결정·기록한다(Solar / GPT-5.4 / Gemini / 기타).

## 주요 위험 요인과 대응 방안

| 위험 요인 | 대응 방안 |
|-----------|-----------|
| 모델 비교가 주관적 인상 비평으로 진행 | 시연 전 평가 항목 3건을 화면에 사전 표시. 해당 항목 기준으로만 평가 |
| 참여 교원이 "Solar로 결정"하고 검토 중단 | Solar가 약한 시나리오 1건(예: 영어 시험 문제 변환)을 의도적으로 시연 |
| 시간 부족 | 시연 2를 5분 이내로 압축. 결과 정리는 학습 자료에 첨부 |

## 짓다 / 코들 사용 시점

- 짓다: 강사 시연(참여 교원은 관찰)
- 코들 활동지: 42분 — 선택 기준 우선순위 입력
- 코들 퀴즈: 42-50분 — "1차 선택 모델" 객관식. 강사가 응답 분포 실시간 확인

## 다음 차시 연결

5차시는 에듀테크 프레임워크(수업도구 구조)로 진행된다. Solar로 무엇을 만들지(3-4차시) 결정한 후, 어떻게 구조화할지(5차시)로 이어진다.
