# [7차시 / 50분] 각자 제작 — Solar API 챗봇

**주관**: 팀모노리스 + 업스테이지 멘토 / **분반**: 공통

## 학습 목표

1. 짓다에서 Solar API를 호출하는 최초 코드를 실행한다.
2. 6차시에서 작성한 가드레일 프롬프트를 챗봇의 시스템 메시지로 적용한다.
3. 본인이 제작하는 도구의 구조도(LLM 호출 위치 포함)를 작성한다.

## 진행 흐름

| 시간 | 내용 |
|------|------|
| 0-5분 | 도입 — 첫 API 호출의 의미와 양 옵션 안내 |
| 5-15분 | 공용 API 키 안내 및 짓다 호출 패턴 시연(강사 화면, 양 옵션 모두 시연) |
| 15-40분 | 제작 실습 — 옵션 A·B 중 1건을 선택하여 챗봇 제작 |
| 40-48분 | 본인 도구의 구조도 작성 — "LLM 호출이 도구의 어느 위치에 결합되는가" 작성 후 코들 보드 이미지 카드로 게시 |
| 48-50분 | 체크포인트 확인 및 다음 차시 안내 |

## 공용 API 키 안내 (필수 준수 사항)

- Day 1에서는 임시 공용 키 1건을 사용한다. 트랙별 분리는 9차시(트랙 분반 시작) 시점에 적용한다.
- 개인 노출 금지 — 짓다 환경 변수에 저장한다. 코드 상 직접 기입을 금한다.
- 키 분배 동선: 강사 화면 표시 또는 인쇄물 배포
- 요청 한도: 100명 동시 호출 시 한도 초과 가능. "1분 1회" 약속 운영, 옵션 A·B 호출 시점을 5분 간격으로 분산한다.

## 옵션 A — 코드·오류 입력 시 힌트 제공 함수 (트랙 A 향)

- 요구 사항:
  - 함수 입력: 학생 코드(문자열) + 오류 메시지(문자열)
  - 시스템 프롬프트: 6차시 "정답 차단" 가드레일
  - 출력: 학생용 한국어 힌트 1~2문장
- 검증:
  - 의도적 오류 코드 1건 입력 시 힌트의 적절성 확인
  - "정답 코드 요청"을 사용자 입력에 삽입 시 정답 비제공 확인
- 확장 과제(시간 잔여 시): 동일 코드 2회 입력 시 "유사 질문이 이전에 입력됨" 응답

## 옵션 B — 교과서 발췌·질문 입력 시 응답/거절 함수 (트랙 B 향)

- 요구 사항:
  - 함수 입력: 교사 사전 등록 교과서 단락(문자열) + 학생 질문(문자열)
  - 시스템 프롬프트: 6차시 "범위 제한" 가드레일 + "주어진 발췌문 근거 응답"
  - 출력: 한국어 응답 1~3문장 또는 "교재에서 확인 어려움" 거절
- 검증:
  - 발췌문 내 내용 질문 1건 → 응답
  - 발췌문 외 내용 질문 1건 → 거절
  - 비속어·주제 무관 질문 1건 → 거절
- 확장 과제(시간 잔여 시): 응답에 "교재 참고 부분" 표시 추가

## 강사 강조 사항

- 본 차시는 *작동 확인*이 목표이다. 사용자 경험 완성은 11~13차시에서 진행한다.
- 오류 발생은 학습 기회이다. 오류 메시지를 짓다에 그대로 입력하여 해결을 시도한다(AI 보조 코딩의 핵심 작동 방식).
- 공용 API 키 노출은 즉시 차단한다. 환경 변수만 사용한다.

## 사전 준비물 (강사·운영)

- 공용 API 키 (Day 1 임시 1건)
- 짓다 기본 템플릿 2종(옵션 A·B). 5분 이내 호출 가능한 최소 코드
- 멘토 5~7명(100명 / 멘토 1인당 15~20명 순회). 옵션 A·B에 따라 분담
- API 장애 대응: 호출 시연 영상 백업

## 성취 기준

- 모든 참여 교원이 짓다 화면에 응답을 1회 이상 출력한다(본 차시 최소 합격선).
- 본인 챗봇이 6차시 가드레일 규칙을 준수하는지 1회 이상 확인한다.
- 모든 참여 교원이 본인 도구 구조도를 코들 보드에 게시한다.

## 주요 위험 요인과 대응 방안

| 위험 요인 | 대응 방안 |
|-----------|-----------|
| API 키 노출 사고 | 도입 5분에 "코드 직접 기입 금지" 안내. 멘토 순회 중 즉시 적발 및 시정 |
| API 호출 실패 | 짓다 기본 템플릿 사용. 멘토가 1:1 디버그 |
| 조기 완료자 | 옵션 미선택분도 시도 가능(양 옵션 경험 시 트랙 결정의 자신감 증대) |
| 진도 지연자 | 멘토가 강사 시연 코드를 복제하여 우선 작동시킨 후 단계별 이해 진행 |

## 짓다 / 코들 사용 시점

- 짓다: 15~48분 — 본격 사용
- 코들 보드: 40~48분 — 도구 구조도(LLM 호출 위치) 이미지 카드 게시. 동료 구조도의 실시간 노출로 상호 학습 효과 발생
