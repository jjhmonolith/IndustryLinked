# [1일차 · 7차시 / 17:30–19:00 (1.5h)] AI 챗봇의 교실 안전장치 만들기

**주강사**: 이창환(팀모노리스 CTO) [보조: 민은실] / **분반**: 공통

## 학습 목표
1. AI 챗봇의 위험(잘못된 답·편향·주제 이탈)을 사례로 확인하고 교실 안전장치의 필요성을 인식한다.
2. 시스템 프롬프트로 거절 규칙·역할 한정 등의 안전장치를 직접 적용할 수 있다.
3. 안전장치 전·후 응답 변화를 비교해 효과를 확인한다.

## 진행 흐름
| 시간 | 내용 | 담당 |
|------|------|------|
| 0–5분 | 차시 목표 소개, 오늘 만들 안전장치 미리보기 | 이창환 |
| 5–25분 | 위험성 이해 — 잘못된 답·편향·주제 이탈 사례 확인, 교실 안전장치(거절 규칙·역할 한정) 개념 강의 | 이창환 |
| 25–55분 | 실습 — 5차시 챗봇에 시스템 프롬프트로 안전장치 적용(역할 한정·금지 주제·모르면 거절) | 참가자 [보조: 민은실] |
| 55–75분 | 전·후 비교 — 동일 질문(자료 밖·부적절·주제 이탈)에 안전장치 전/후 응답 비교 | 참가자 [민은실] |
| 75–83분 | 산출물 정리·코들 업로드, 2일차 트랙 분반 예고 | 이창환 |
| 83–90분 | 1일차 마무리, 질의응답 | 이창환 |

## 강사 강조
- "교실에서 쓸 AI는 똑똑함보다 안전함이 먼저" — 학생 대상 도구라는 점을 계속 상기시킨다.
- 안전장치는 별도 기술이 아니라 '시스템 프롬프트로 역할과 거절 규칙을 명시하는 것'임을 체감시킨다.
- 전·후 비교를 반드시 남기게 한다 — 2일차 트랙 안전성 점검(잘못된 답/주제 이탈 막기)의 출발 자료가 된다.

## 사전 준비물
- 위험 사례 모음(잘못된 답·편향·주제 이탈 예시), 안전장치 시스템 프롬프트 템플릿
- 5차시에서 만든 본인 챗봇(Colab), Solar API 키
- 전·후 비교표 양식(코들 보드)

## 성취 기준(산출물)
- 안전장치 적용 챗봇(동작 확인)
- 안전장치 전·후 응답 비교 결과(코들 보드)

## 주요 위험·대응
| 위험 | 대응 |
|------|------|
| 5차시 챗봇 미완성 | 공용 예제 챗봇으로 안전장치 실습 진행 |
| 안전장치가 과도해 정상 질문도 거절 | 규칙 범위를 좁혀 재조정, 균형점 찾기 실습으로 활용 |

- Solar LLM API: 안전장치 적용 챗봇의 응답 엔진
- Colab: 시스템 프롬프트 수정·전후 비교 실행
- 코들: 안전장치 챗봇·전후 비교 산출물 보관
- 짓다: 2일차 이후 완성 도구 전시 예고
