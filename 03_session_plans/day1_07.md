# [1일차 · 7차시 / 17:30–19:00 (1.5h)] AI 챗봇의 교실 안전장치 만들기

**주강사**: 박기영(팀모노리스) [보조: 민은실] / **분반**: 반별(크로스 진행) — §확정계획 3 참조

## 학습 목표
1. AI 챗봇의 위험(잘못된 답·편향·주제에서 벗어난 대화)을 사례로 확인하고 교실 안전장치의 필요성을 인식한다.
2. AI에게 '규칙'을 말로 정해줘서 위험한 요청을 막는 안전장치를 직접 적용할 수 있다.
3. 안전장치 전·후 응답 변화를 비교해 효과를 확인한다.

## 진행 흐름
| 시간 | 내용 | 담당 |
|------|------|------|
| 0–5분 | 차시 목표 소개, 오늘 만들 안전장치 미리보기 | 박기영 |
| 5–25분 | 위험성 이해 — 잘못된 답·편향·주제에서 벗어난 대화 사례 확인, 교실 안전장치(AI에게 규칙 정해주기) 개념 강의 | 박기영 |
| 25–55분 | 실습 — 5차시 챗봇에 안전 규칙 적용(무엇을 도와줄지·무엇은 안 할지·모르면 어떻게 답할지) | 참가자 [보조: 민은실] |
| 55–75분 | 전·후 비교 — 같은 곤란한 질문에 안전장치 전/후 응답 비교 | 참가자 [민은실] |
| 75–83분 | 산출물 정리·코들 업로드, 2일차 트랙 분반 예고 | 박기영 |
| 83–90분 | 1일차 마무리, 질의응답 | 박기영 |

## 강사 강조
- "교실에서 쓸 AI는 똑똑함보다 안전함이 먼저" — 학생 대상 도구라는 점을 계속 상기시킨다.
- 안전장치는 별도 기술이 아니라 'AI에게 무엇을 도와줄지·무엇은 하지 말지를 말로 정해주는 것'임을 체감시킨다.
- 위험은 트랙에 따라 모습이 다르다는 점을 예고한다 — 파이썬 튜터는 '정답을 통째로 알려주거나 틀린 답을 자신 있게 말하는 것', 소크룸(대화형 튜터)은 '수업 주제에서 벗어나거나 부적절한 대화로 흐르는 것'.
- 전·후 비교를 반드시 남기게 한다 — 2일차 트랙 안전성 점검(정답 유출·잘못된 답 막기 / 주제 이탈·부적절 대화 막기)의 출발 자료가 된다.

## 사전 준비물
- 위험 사례 모음(잘못된 답·편향·주제에서 벗어난 대화 예시), 안전 규칙 예시 템플릿
- 5차시에서 만든 본인 챗봇(Colab), Solar API 키
- 전·후 비교표 양식(코들 보드)

## 성취 기준(산출물)
