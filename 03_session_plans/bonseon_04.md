# [본선 · 4차시 / 17:00–19:00 (2h)] 도구 활용방안에 대한 최종 발표 및 동료 평가 실시

**담당**: 이경희(학회/호서대) [보조 최형관] / **분반**: 5분반(40명/반)

## 학습 목표
1. 고도화한 AI 수업 도구의 학교 적용 계획(단원·학생·운영 방식·기대 효과)을 3분 안에 발표한다.
2. 동료 교사 루브릭(완성도·창의성·교육적 가치·활용방안 구체성) 기준으로 서로를 평가한다.
3. 심사위원 종합 평가와 총평을 듣고, 평가 결과의 후속 활용과 수료 절차를 이해한다.

## 진행 흐름
| 시간 | 내용 | 담당 |
|------|------|------|
| 17:00–17:10 (10분) | 최종 발표·평가 방식 안내 — 3분 발표 규칙, 동료 루브릭 4항목·심사 방식 설명 | 이경희 [최형관] |
| 17:10–18:30 (80분) | 활용방안 발표 — 모든 팀 3분 발표(자기 학교 적용 계획: 단원·학생·운영 방식·기대 효과), 발표별 동료 루브릭 즉시 기입 | 이경희 [최형관] |
| 18:30–18:50 (20분) | 심사위원 종합 평가 — 학회 평가위원·산업 관점 심사위원의 종합 평가 및 총평 | 이경희 · 심사위원단 |
| 18:50–19:00 (10분) | 평가 결과 활용·수료 안내 — 점수 비공개 원칙, 사례집 수록·후속 학습 환류, 수료 및 후속 네트워크 안내 | 이경희 [최형관] |

## 강사 강조
- 발표는 도구 기능 소개가 아니라 "내 학교의 어느 수업에 어떻게 쓸지"를 구체적으로 말하도록 강조한다.
- 동료 평가는 순위를 매기는 것이 아니라 서로의 활용 아이디어를 넓히는 자료임을 안내한다.
- 평가 결과는 점수로 공개되지 않으며 사례집·후속 학습 환류 자료로 쓰인다는 점을 분명히 한다.

## 사전 준비물
- 3차시 개선 결과가 반영된 최종 도구와 활용방안 발표 자료(단원·학생·운영 방식·기대 효과).
- 동료 평가 루브릭 시트(완성도·창의성·교육적 가치·활용방안 구체성).
- 짓다 갤러리 최종 등록본, 심사위원용 평가 양식.
- 수료·후속 네트워크 안내 자료.

## 성취 기준(산출물)
- 팀별 3분 활용방안 발표 완료(학교 적용 계획 포함).
- 동료 루브릭 4항목 평가 결과 취합본.
- 심사위원 종합 평가·총평 기록 및 사례집 수록 후보 선정 메모.

## 주요 위험·대응
| 위험 | 대응 |
|------|------|
| 팀이 많아 발표 시간이 초과됨 | 3분 타이머 엄격 운영, 반별 동시 진행으로 시간 확보 |
| 발표가 도구 기능 나열에 그침 | 발표 양식을 단원·학생·운영 방식·기대 효과 4칸으로 고정 |
| 점수 공개 기대로 인한 오해 | 평가 결과는 비공개·환류용임을 사전·사후 반복 안내 |
| 늦은 종료 시각(19:00)으로 집중도 저하 | 발표·심사·안내 시간을 사전 고지하고 진행 속도 관리 |

## 도구 사용
- 짓다 갤러리: 최종 산출물 전시·동료 루브릭 평가 수합.
- 코들: 발표 순서 관리·평가 결과 취합·수료 안내 배포.
- 개발 환경·Solar LLM API: 발표 중 도구 실동작 시연.
