# [2일차 · 3차시 / 13:00–15:00 (2h)] 내 수업에 맞게 다듬고 시연 준비

**주강사**: 트랙 A 배영빈(팀모노리스 책임) [류호선·신화준] / 트랙 B 김비치·김세윤(팀모노리스) [신희찬·이동연·이창환·민은실] / **분반**: 트랙별

## 학습 목표 (트랙 공통)
1. 범용 도구를 자기 학교 학생·단원 맥락에 맞게 변형한다.
2. 실제 교실에서 자주 나올 질문·막히는 부분을 반영해 도구를 다듬는다.
3. 4차시 동료 평가를 위한 5분 시연 시나리오(1줄 소개·시연 순서·강조 포인트)를 작성하고 최종 동작을 점검한다.

---
## 트랙 A — 자기 학교 학생·단원 맥락 반영

### 진행 흐름
| 시간 | 내용 |
|------|------|
| 13:00–13:40 (40분) | 학생 수준·단원 맥락 반영 — 내 학교 학년/난이도에 맞게 문제·힌트 톤 변형 |
| 13:40–14:20 (40분) | 자주 묻는 질문·막히는 부분 반영 — 실제 오답 패턴을 힌트·해설에 반영 |
| 14:20–14:50 (30분) | 5분 시연 시나리오 작성 — 1줄 소개·시연 순서·강조 포인트 정리 |
| 14:50–15:00 (10분) | 최종 동작 점검 — 시연 흐름 그대로 리허설 |

### 핵심 패턴 / 프롬프트 예시
힌트·해설의 대상 학년과 단원을 명시해 우리 반 맥락에 맞춘다.

```text
[맥락 반영 파라미터 — 시스템 프롬프트]
대상: 중학교 2학년, 단원 "반복문(for/while)"
말투: 존댓말, 어려운 용어는 풀어서 설명
자주 나오는 오답: range 범위 실수, 들여쓰기 오류, 무한 루프
힌트 규칙: 위 오답 패턴이 보이면 그 지점을 먼저 짚어라. 정답 코드는 주지 않는다.
```

### 산출물
- 우리 학교 학년·단원·오답 패턴이 반영된 트랙 A 도구 최종본 + 5분 시연 시나리오.

## 트랙 B — 본인 수업자료로 챗봇 운영 시나리오 설계

### 진행 흐름
| 시간 | 내용 |
|------|------|
| 13:00–13:40 (40분) | 운영 시나리오 설계 — 학생 활용 시점·교사 모니터링 방식 정의 |
| 13:40–14:20 (40분) | 학생 시점 사용 검증 — 실제 학생처럼 질문해 보며 응답·거절 다듬기 |
| 14:20–14:50 (30분) | 5분 시연 시나리오 작성 — 1줄 소개·시연 순서·강조 포인트 정리 |
| 14:50–15:00 (10분) | 최종 동작 점검 — 시연 흐름 그대로 리허설 |

### 핵심 패턴 / 프롬프트 예시
언제·어떻게 학생이 쓰고 교사가 무엇을 볼지 운영 시나리오로 정의한다.

```text
[운영 시나리오 템플릿]
1) 학생 활용 시점: 예습(수업 전 자료 질문) / 자습(문제 풀다 막힐 때)
2) 학생 시점 대표 질문 3개:
   - "오늘 배운 광합성 과정 다시 설명해줘"   → 자료 기반 답변 확인
   - "이거 시험에 나와? 답이 뭐야?"            → 거절 동작 확인
   - "그냥 아무 얘기나 하자"                    → 주제 이탈 거절 확인
3) 교사 모니터링: 대화 로그 검토 시점, 자료 밖 질문 빈도 확인 방법
```

### 산출물
- 학생 활용 시점·교사 모니터링이 정의된 운영 시나리오 + 학생 시점 검증을 마친 트랙 B 챗봇 + 5분 시연 시나리오.

---

## 강사 강조 (공통)
- '범용 도구'가 아니라 '우리 반 도구'가 되어야 4차시 평가에서 교육 적합성 점수가 나온다.
- 시연 시나리오는 자랑이 아니라 '동료가 학생처럼 써볼 수 있게' 안내하는 대본이다.
- 강조 포인트 1~2개만 골라라. 5분 안에 다 보여주려다 아무것도 못 보여준다.
- 반드시 시연 흐름 그대로 한 번 리허설하고 마칠 것.

## 사전 준비물
- 2차시까지 만든 트랙별 도구(안전장치 포함), 본인 수업 맥락 정보(학년·단원·자주 나오는 질문).
- 트랙 B: 운영 시나리오를 채울 실제 수업자료.

## 주요 위험·대응
| 위험 | 대응 |
|------|------|
| 맥락 반영 중 도구가 오히려 오작동 | 변경 전 버전을 저장해 두고 문제 시 되돌리기 |
| 시연 시나리오가 5분을 크게 넘김 | 강조 포인트 1~2개로 축소, 리허설로 시간 측정 |
| 학생 시점 검증을 생략 | 대표 질문 3종(정상·시험누설·이탈)을 필수 체크리스트로 |
| 최종 리허설에서 처음 발견되는 버그 | 리허설을 14:50 전에 끝내 수정 여유 확보 |
