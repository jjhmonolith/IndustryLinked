# [2일차 · 3차시 / 13:00–15:00 (2h)] 내 수업에 맞게 다듬고 시연 준비

**주강사**: 트랙 A(파이썬) 배영빈·박기영 / 트랙 B(소크룸) 이예진 / **[보조 강사]** 배치 / **분반**: 서울 트랙 A 2반·트랙 B 1반 / 부산 각 1반, 반당 40명(서울)·25명(부산)

## 학습 목표 (트랙 공통)
1. 범용 도구를 자기 학교 학생·단원 맥락에 맞게 변형한다.
2. 실제 교실에서 자주 나올 질문·막히는 부분을 반영해 도구를 다듬는다.
3. 4차시 동료 평가를 위한 5분 시연 시나리오(1줄 소개·시연 순서·강조 포인트)를 작성하고 최종 동작을 점검한다.

## 트랙 A — 자기 학교 학생·단원 맥락 반영

| 13:40–14:20 (40분) | 자주 묻는 질문·막히는 부분 반영 — 실제 오답 패턴을 힌트·해설에 반영 |

### 핵심 패턴 / 짓다 요청 예시
코드를 직접 고치지 않고, 짓다 왼쪽 AI 채팅에 대상 학년·단원·말투를 말로 요청해 우리 반 맥락에 맞춘다. 오른쪽 라이브 미리보기에서 즉시 확인하고 다시 말해 수정한다.

```text
이 튜터 도구를 아래 맥락에 맞게 바꿔줘.
- 대상: 중학교 2학년, 단원 "반복문(for/while)"
- 말투: 존댓말, 어려운 용어는 풀어서 설명해줘
- 자주 나오는 오답: range 범위 실수, 들여쓰기 오류, 무한 루프
- 힌트 규칙: 위 오답 패턴이 보이면 그 지점을 먼저 짚어주고, 정답 코드는 절대 주지 마.
```

### 산출물
- 우리 학교 학년·단원·오답 패턴이 반영된 트랙 A 도구 최종본 + 5분 시연 시나리오.

## 트랙 B — 소크룸: 내 수업 주제·난이도·대화 톤 반영

> 소크룸은 교사가 정한 **주제·난이도**로 학생과 대화하며, 답을 바로 주지 않고 **유도 질문**을 던지는 대화형 튜터다. 이 차시에서는 '아무 주제나'가 아니라 '내가 이번 주 가르치는 주제', 우리 반 학생 수준에 맞는 난이도, 그리고 학생이 마음을 여는 대화 톤을 반영한다.

### 진행 흐름
| 시간 | 내용 |
|------|------|
| 13:00–13:40 (40분) | 내 수업 주제·난이도 반영 — 짓다에 내 단원 주제와 우리 반 수준을 말로 요청 |
| 13:40–14:20 (40분) | 대화 톤·학생 시점 검증 — 실제 학생처럼 대화해 보며 유도 질문·말투 다듬기 |
| 14:20–14:50 (30분) | 5분 시연 시나리오 작성 — 1줄 소개·시연 순서·강조 포인트 정리 |
| 14:50–15:00 (10분) | 최종 동작 점검 — 시연 흐름 그대로 리허설 |

### 핵심 패턴 / 짓다 요청 예시
코드를 직접 고치지 않고, 짓다 왼쪽 AI 채팅에 내 수업 주제·난이도·대화 톤을 말로 요청한다. 오른쪽 라이브 미리보기에서 실제 학생처럼 대화해 보며 다시 말해 수정한다.

```text
이 소크룸(대화형 튜터)을 아래 내 수업에 맞게 바꿔줘.
- 오늘 주제: 중2 과학 "광합성" — 이 주제 안에서만 대화해줘.
- 난이도: 어려운 용어는 쉽게 풀고, 한 번에 한 가지씩만 물어봐줘.
- 대화 톤: 다정한 존댓말로, 학생 답이 틀려도 혼내지 말고 다시 생각하게 이끌어줘.
- 유도 질문: 답을 바로 알려주지 말고, 학생이 스스로 떠올리게 한 걸음씩 질문해줘.
```

### 산출물
- 내 단원 주제·우리 반 난이도·대화 톤이 반영되고 학생 시점 검증을 마친 트랙 B 소크룸 + 5분 시연 시나리오.

## 강사 강조 (공통)
- '범용 도구'가 아니라 '우리 반 도구'가 되어야 4차시 평가에서 교육 적합성 점수가 나온다.
- 시연 시나리오는 자랑이 아니라 '동료가 학생처럼 써볼 수 있게' 안내하는 대본이다.
- 강조 포인트 1~2개만 골라라. 5분 안에 다 보여주려다 아무것도 못 보여준다.
- 반드시 시연 흐름 그대로 한 번 리허설하고 마칠 것.
