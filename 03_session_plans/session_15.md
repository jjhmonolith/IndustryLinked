# [15차시 / 50분] 우수사례 발표 + 클로징

**주관**: 팀모노리스 + 업스테이지 게스트 + 학회 인사 / **분반**: 양 트랙 합반

## 학습 목표

1. 양 트랙 우수사례를 보고 자기 작업에 적용할 1가지를 메모한다.
2. 바이브톤에서 무엇을 만들지 한 단락으로 결심한다.
3. 연수를 통해 무엇이 가능해졌고 무엇이 더 필요한지 회고 시트에 적는다.

## 진행 흐름

| 시간 | 내용 |
|------|------|
| 0-5분 | 클로징 도입 — 양 트랙 합반, 분위기 전환 |
| 5-25분 | **우수사례 발표 4팀** (트랙당 2팀 × 5분: 시연 3분 + 만든 이야기 2분) |
| 25-32분 | **업스테이지 게스트 단평** (사례별 1분, 산업 관점 코멘트) |
| 32-40분 | **"내가 바이브톤에서 만들 것"** — **코들 활동지**에 한 단락 작성 + 옆자리와 1분 공유 |
| 40-48분 | **연수 회고** — **코들 활동지**(5개 항목) + **코들 퀴즈**(만족도 1문항) |
| 48-50분 | 학회·팀모노리스·업스테이지 클로징 인사 → 바이브톤 일정 안내 |

## 발표팀 선정 룰

- 14차시 우수사례 추천을 집계, 트랙별 상위 2팀 (총 4팀)
- 동점이면 강사·멘토가 함께 결정 (다양성 고려 — 시나리오·완성도·창의성 각각)

## 발표 5분 양식 (학습자 가이드)

```
[1분] 만든 것 한 줄 소개 + 어떤 수업 문제를 풀기 위한 것인가
[3분] 라이브 시연 — 학생 시점 1회, 교사 시점 1회
[1분] 가장 어려웠던 점 + 다음에 고치고 싶은 것
```

## 업스테이지 게스트 단평 가이드

- 한 사례당 1분, 4사례 총 4분 + 종합 3분
- ✅ 산업·기술 관점에서 "이 아이디어를 더 키우면 어디까지 가능한가"
- ❌ 회사 자랑·평가 점수 매기기
- ✅ "이 도구가 실제 학교에 들어간다면 다음으로 풀어야 할 기술 문제는…"

## 연수 회고 (40-48분, **코들 활동지** + **코들 퀴즈**)

활동지 양식:

```
1. 연수를 통해 *가능해진 것* 3가지 (한 줄씩)
2. 아직 *어려운 것* 1가지
3. 바이브톤에서 만들 도구 — 한 단락 (제목 + 1줄 설명 + 누구의 문제를 풀까)
4. 본 연수 한 줄 평
5. (선택) 컨소시엄에 전하고 싶은 메시지
```

퀴즈(객관식 1문항): "이번 연수 전반 만족도는?" 1~5점

→ 강사·컨소시엄이 즉시 응답 분포 확인 가능. 사후 보고에 그대로 활용.

## 강사·연사 핵심 메시지

- **팀모노리스**: "바이브톤은 *이 연수의 진짜 결과물*입니다. 오늘이 시작입니다."
- **업스테이지**: "Solar는 여러분의 도구입니다. 약점도 강점도 솔직히. 무엇이 필요한지 알려주시면 같이 진화합니다."
- **학회**: "*직접 만드는 정보교사*의 시작. 여러분이 만든 도구가 곧 한국 교실의 표준이 됩니다."

## 사전 준비물

- 발표팀 4팀 사전 통보 (14차시 종료 즉시) + 발표 양식 가이드
- 빔·마이크·발표용 노트북 (1팀당 자기 노트북도 OK)
- 업스테이지 게스트 사전 자료 — 발표 사례 4건 요약본 (15분 전 전달)
- 코들 활동지 회고 양식 — 5항목 + 만족도 퀴즈 1문항

## 체크포인트

- 발표 4팀 모두 5분 안에 끝남 (시간 카드 활용)
- 모든 학습자가 회고 시트 5개 항목 작성
- 모든 학습자가 "바이브톤에서 만들 것" 한 단락 작성

## 흔한 실패 패턴과 대응

| 실패 | 대응 |
|------|------|
| 발표가 시간 초과 | 강사가 5분 카운트다운 명시. 4분 30초에 종료 안내 |
| 라이브 시연 실패 | 발표팀에 사전 안내: 백업 영상·스크린샷 1세트 준비 |
| 게스트 단평이 자사 자랑 | 사전 가이드 명시 + 진행자가 부드럽게 시간 컷 |
| 회고 시간 부족 | 발표 단평 시간을 단축하고 회고 8분 사수 |

## 짓다 / 코들 사용 시점

- **짓다**: 5-25분 — 발표팀 라이브 시연
- **코들 활동지**: 32-48분 — "바이브톤에서 만들 것" + 회고 5개 항목
- **코들 퀴즈**: 40-48분 — 만족도 1문항
