# [15차시 / 50분] 우수 사례 발표 및 종료

**주관**: 팀모노리스 + 업스테이지 게스트 + 학회 인사 / **분반**: 공통(합반)

## 학습 목표

1. 양 트랙 우수 사례를 참관하고 본인 작업에 적용할 항목 1건을 기록한다.
2. 바이브톤에서 제작할 도구를 1단락으로 정리한다.
3. 본 연수에서 가능해진 항목과 추가 학습 필요 항목을 회고 양식에 기록한다.

## 진행 흐름

| 시간 | 내용 |
|------|------|
| 0-5분 | 종료 도입 — 양 트랙 합반 진행 |
| 5-25분 | 우수 사례 발표 4팀(트랙당 2팀, 팀당 5분: 시연 3분 + 제작 과정 2분) |
| 25-32분 | 업스테이지 게스트 코멘트(사례별 1분, 산업·기술 관점) |
| 32-40분 | "바이브톤에서 제작할 도구" — 코들 활동지에 1단락 작성 후 인접 참여 교원과 1분 공유 |
| 40-48분 | 연수 회고 — 코들 활동지(5항목) 및 코들 퀴즈(만족도 1문항) |
| 48-50분 | 학회·팀모노리스·업스테이지 종료 인사, 바이브톤 일정 안내 |

## 발표팀 선정 기준

- 14차시 우수 사례 추천 집계 결과 기준 트랙별 상위 2팀(총 4팀)
- 동점 시 강사·멘토 협의 결정(시나리오·완성도·창의성 다양성 고려)

## 발표 5분 양식 (참여 교원 안내)

```
[1분] 제작물 1줄 소개 + 해결 대상 수업 문제
[3분] 실시간 시연 — 학생 시점 1회, 교사 시점 1회
[1분] 주요 난관 + 추가 개선 의향 항목
```

## 업스테이지 게스트 코멘트 가이드

- 사례별 1분, 4사례 4분 + 종합 3분
- 권장: 산업·기술 관점에서의 확장 가능성 논의
- 지양: 자사 제품 홍보 또는 평가 점수 부여
- 권장: "본 도구의 실제 학교 도입 시 후속 기술 과제" 논의

## 연수 회고 (40~48분, 코들 활동지 + 코들 퀴즈)

활동지 양식:

```
1. 본 연수를 통해 가능해진 항목 3건(1줄씩)
2. 추가 학습이 필요한 항목 1건
3. 바이브톤에서 제작할 도구 1단락(제목 + 1줄 설명 + 대상 문제)
4. 본 연수 1줄 평
5. (선택) 컨소시엄 의견 제안
```

퀴즈(객관식 1문항): "본 연수 전반 만족도" 1~5점

강사·컨소시엄이 응답 분포를 실시간 확인하여 사후 보고에 활용한다.

## 강사·연사 강조 사항

- 팀모노리스: 바이브톤은 본 연수의 최종 산출 단계이다. 본 차시가 그 시작점이다.
- 업스테이지: Solar는 참여 교원이 활용 가능한 도구이다. 한계와 강점을 있는 그대로 공유하며 지속 개선한다.
- 학회: 직접 도구를 제작하는 정보교사의 출발점이다. 참여 교원의 도구가 한국 교실의 표준이 될 수 있다.

## 사전 준비물

- 발표 4팀 사전 통보(14차시 종료 직후) 및 발표 양식 가이드
- 발표용 화면 출력, 마이크, 노트북(팀별 노트북도 가능)
- 업스테이지 게스트 사전 자료 — 발표 사례 4건 요약본(개시 15분 전 전달)
- 코들 활동지 회고 양식(5항목) + 만족도 퀴즈 1문항

## 성취 기준

- 발표 4팀이 모두 5분 이내에 발표를 종료한다(시간 관리 표시 활용).
- 모든 참여 교원이 회고 양식 5항목을 작성한다.
- 모든 참여 교원이 "바이브톤에서 제작할 도구" 1단락을 작성한다.

## 주요 위험 요인과 대응 방안

| 위험 요인 | 대응 방안 |
|-----------|-----------|
| 발표 시간 초과 | 강사가 5분 카운트다운 표시. 4분 30초에 종료 안내 |
| 실시간 시연 실패 | 발표팀 사전 안내 — 백업 영상·화면 캡처 1세트 준비 |
| 게스트 코멘트의 자사 제품 홍보 편향 | 사전 가이드 명시, 진행자가 시간 마감 안내 |
| 회고 시간 부족 | 게스트 코멘트 시간 단축, 회고 8분 확보 |

## 짓다 / 코들 사용 시점

- 짓다: 5~25분 — 발표팀 실시간 시연
- 코들 활동지: 32~48분 — "바이브톤에서 제작할 도구" 및 회고 5항목
- 코들 퀴즈: 40~48분 — 만족도 1문항
