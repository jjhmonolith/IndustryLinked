# [15차시 / 50분] 우수 사례 발표 및 종료

**주관**: 팀모노리스 + 업스테이지 게스트 + 학회 / **분반**: 공통(합반)

## 학습 목표

1. 양 트랙 우수 사례를 참관하고 본인 작업에 적용할 항목 1건을 기록한다.
2. 바이브톤에서 제작할 도구를 1단락으로 정리한다.
3. 연수 가능해진 항목과 추가 학습 필요 항목을 회고한다.

## 진행 흐름

| 시간 | 내용 |
|------|------|
| 0-5분 | 종료 도입 — 양 트랙 합반 |
| 5-25분 | 우수 사례 발표 4팀(트랙당 2팀, 팀당 5분: 시연 3분 + 제작 과정 2분) |
| 25-32분 | 업스테이지 게스트 코멘트(사례별 1분) |
| 32-40분 | "바이브톤 제작 도구" — 코들 활동지 1단락 + 인접 교원과 1분 공유 |
| 40-48분 | 연수 회고 — 코들 활동지(5항목) + 코들 퀴즈(만족도) |
| 48-50분 | 종료 인사, 바이브톤 일정 안내 |

## 발표팀 선정 기준

- 14차시 우수 사례 추천 집계 결과 기준 트랙별 상위 2팀(총 4팀)
- 동점 시 강사·멘토 협의 결정(시나리오·완성도·창의성 다양성)

## 발표 5분 양식

```
[1분] 제작물 1줄 소개 + 해결한 수업 문제
[3분] 실시간 시연 — 학생 시점·교사 시점 각 1회
[1분] 주요 난관 + 추가 개선 의향
```

## 업스테이지 게스트 코멘트 가이드

- 사례별 1분, 4사례 4분 + 종합 3분
- 권장: 산업·기술 관점 확장 가능성
- 지양: 자사 제품 홍보, 평가 점수 부여
- 권장: "본 도구의 학교 도입 시 후속 기술 과제"

## 연수 회고 (40~48분)

활동지 양식:

```
1. 가능해진 항목 3건(1줄씩)
2. 추가 학습 필요 항목 1건
3. 바이브톤 제작 도구 1단락(제목 + 1줄 설명 + 대상 문제)
4. 본 연수 1줄 평
5. (선택) 컨소시엄 제안
```

퀴즈: "본 연수 전반 만족도" 1~5점. 응답 분포를 실시간 확인하여 사후 보고 활용.

## 강사·연사 강조

- 팀모노리스: 바이브톤이 본 연수의 최종 산출. 본 차시가 그 시작.
- 업스테이지: Solar는 교원이 활용 가능한 도구. 한계·강점 공유, 지속 개선.
- 학회: 도구 제작 정보교사의 출발점. 교원의 도구가 한국 교실 표준이 될 수 있다.

## 사전 준비물

- 발표 4팀 사전 통보(14차시 종료 직후) + 발표 양식 가이드
- 발표용 화면·마이크·노트북
- 업스테이지 게스트 사전 자료(개시 15분 전)
- 코들 활동지 회고 양식(5항목) + 만족도 퀴즈

## 성취 기준

- 발표 4팀이 5분 이내 종료.
- 모든 교원이 회고 5항목 작성.
- 모든 교원이 "바이브톤 제작 도구" 1단락 작성.

## 주요 위험·대응

| 위험 | 대응 |
|------|------|
| 발표 시간 초과 | 5분 카운트다운. 4분 30초 종료 안내 |
| 시연 실패 | 발표팀 사전 안내 — 백업 영상·캡처 |
| 게스트 코멘트 홍보 편향 | 사전 가이드. 진행자 시간 마감 |
| 회고 시간 부족 | 게스트 코멘트 단축, 회고 8분 확보 |

## 짓다·코들

- 짓다: 5~25분 — 발표팀 시연
- 코들 활동지: 32~48분 — 바이브톤 제작 도구·회고 5항목
- 코들 퀴즈: 40~48분 — 만족도

## 바이브톤 연결

- 안내 항목:
  - 일정·장소·신청
  - 본 차시 회고와 짓다 갤러리 작품이 바이브톤 출발 자료
  - 멘토·질문 채널(운영 가능 시)
- 사후 자료(`06_learner_materials/`) 배포:
  - 자가 점검 체크리스트
  - 자주 묻는 질문
  - 짓다 프롬프트 모음
