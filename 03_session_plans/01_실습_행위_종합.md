# 전체 차시 실습·행위 종합

전 차시(집합 15 + 본선 8 = 23차시)에서 참가 교사가 **직접 하는 실습·행위**를 한눈에 모은 문서.
원천: [`../00_연수운영계획_확정.md`](../00_연수운영계획_확정.md) · 차시 운영안: 같은 폴더 `day1_*`·`day2_*`·`bonseon_*`.

> **설계 원칙**: 이 연수는 "직접 만들기 중심"이다. 강의·시연은 각 차시 1/3 이내, 나머지는 참가자가 손을 움직인다. 아래 표에서 **[실습]** 표시가 참가자가 직접 산출물을 만드는 행위다.

## 유형 범례

`강의`=개념 전달 · `시연`=강사 실연 관찰 · `실습`=참가자 직접 제작·조작 · `토론`=조별/전체 토의 · `발표`=공유·시연 발표 · `평가`=동료/심사 평가 · `운영`=접속·출석 등

## 2. 2일차 (트랙 분반, 7차시 상당)

트랙 A = 파이썬 자동채점 + AI 튜터 / 트랙 B = 자료 기반 AI 학습 챗봇.

> **2일차 도구 제작·수정은 전부 짓다(팀모노리스 바이브코딩)** — AI 채팅에 한국어로 "이런 도구 만들어줘"라고 요청 → 라이브 미리보기로 확인 → 갤러리 공개. **코드를 직접 쓰지 않는다.** (1일차 업스테이지 세션 실습은 Colab, day1 자료·MVP는 짓다 제작의 출발 재료.)

| 차시 | 유형 | 트랙 A 실습 | 트랙 B 실습 | 도구 | 산출물 | 담당 |
|------|------|-------------|-------------|------|--------|------|
| 1 도구 만들기 (2h) | 실습 | **[실습]** 짓다에 요청해 자동 채점+수준별 힌트+코드 해설 튜터 웹앱 제작(정답 코드 노출 금지 규칙), 미리보기로 테스트 | **[실습]** 짓다에 요청해 내 자료(day1 구조화·추출 결과) 범위 안에서만 답하고 자료 밖은 거절하는 챗봇 제작, 미리보기로 테스트 | 짓다·Solar API | 트랙 도구 v1 | 배영빈 / 김비치·김세윤(팀모노리스) |
| 2 도구 안전성 점검 (1h) | 실습 | **[실습]** 잘못된 답·편향 진단, 회피 거절 규칙을 짓다에 요청해 추가, 잘못된 질문 직접 입력해 반응 점검 | **[실습]** 자료 밖 거절 흐름(시험답 누설·잡담)·우회 질문 거절 메시지를 짓다에 요청, 우회 질문 입력해 확인 | 짓다·Solar API | 안전장치 적용·검증 기록 | 배영빈 / 김비치·김세윤 |

## 4. 실습 산출물 누적 흐름 (참가자가 만드는 것)

```
1일차
 [수업 문제 1줄] (1차시)
   → [문제 정의 + 첫 스케치] (2차시)
   → [자료 구조화·핵심 추출 JSON] (4차시)
   → [자료 기반 챗봇 MVP] (5차시)
   → [4요소 진단·보완] (6차시)
   → [안전장치 적용 챗봇] (7차시)
2일차 (트랙)
   → [트랙 도구 v1] (1차시)
   → [안전장치 적용·검증] (2차시)
   → [맞춤화 도구 + 5분 시연 시나리오] (3차시)
   → [동료 평가·우수사례 발표] (4차시)
본선 (약 2~2.5개월 후)
   → [학습 목표 재정립] (1차시)
   → [시연·동료 피드백] (2차시)
   → [개선 계획 + 고도화 도구] (3차시)
   → [학교 적용 계획 발표·평가·수료] (4차시)
```
