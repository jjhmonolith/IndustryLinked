# [14차시 / 50분] 갤러리 사용 및 상호 피드백

**주관**: 팀모노리스 / **분반**: 트랙별 분반(15~25분 구간에서 트랙 교차 사용 가능)

## 학습 목표

1. 동료 작품 3건 이상을 학생 시점으로 사용한다.
2. 각 작품에 짓다 댓글로 구체적 피드백을 작성한다.
3. 받은 피드백을 정리하고 우수 사례를 추천한다.

## 진행 흐름

| 시간 | 내용 |
|------|------|
| 0-5분 | 도입 — 평가가 아닌 상호 학습. 칭찬·발견·개선 제안 중심 |
| 5-30분 | 동료 작품 사용·짓다 댓글. 1인당 작품 3건에 4항목 댓글 |
| 30-40분 | 받은 피드백 정리 — 코들 보드 "받은 피드백" 카드 |
| 40-48분 | 우수 사례 추천 — 코들 퀴즈(본인 제외, 2건 이내) |
| 48-50분 | 마무리 — 15차시 발표 안내 |

## 피드백 작성 가이드

좋은 피드백 = 구체성 + 건설성

```
[권장]
"학생 화면의 입력-결과 흐름의 응답 속도가 우수하다.
정답을 직접 제공하지 않는 힌트 양식이 인상 깊다.
대시보드에서 '정체 지점'을 학년별로 분리하면 개선될 것이다."

[지양]
"잘 만들었다", "좋다" (구체성 부족)
"전반적으로 부적절하다" (건설성 부족)
```

4항목으로 작성:

1. 인상 깊은 점 1건
2. 학생·교사 시점에서 불편한 점 1건
3. 소규모 개선 제안 1건
4. 질문 1건

## 트랙 교차 사용 (선택 운영, 15~25분)

- 트랙 A 교원이 트랙 B 작품 1건, 트랙 B 교원이 트랙 A 작품 1건 사용
- 효과: 트랙 외 영역의 응용 가능성 인식, 바이브톤 트랙 융합 동기
- 운영: 분반 공간이 인접한 경우 이동, 원거리인 경우 링크 교환

## 강사 강조

- 평가가 아닌 상호 학습. 본인이 미처 고려하지 못한 아이디어 도출이 목표.
- 구체적 피드백이 수렴자에게 학습 효과를 발생시킨다.
- 받은 피드백 중 바이브톤에서 반영할 항목 1건 선정.

## 사전 준비물

- 짓다 갤러리 트랙별 정리
- 코들 보드 "받은 피드백" 사전 등록(트랙별)
- 코들 퀴즈 우수 사례 추천 — 트랙별 객관식 1문항. 선택지는 13차시 종료 후 강사가 신속 생성(약 10분)
- 댓글 작성 가이드(4항목)

## 성취 기준

- 모든 교원이 동료 작품 3건 이상에 댓글 작성.
- 본인 작품의 피드백 정리.
- 우수 사례 추천 1~2건 제출.

## 주요 위험·대응

| 위험 | 대응 |
|------|------|
| 칭찬·비판 일변 | 4항목 양식 준수. 미준수 시 강사 보강 요청 |
| 일부 작품에 집중 | "0건 작품 우선" 안내. 분포 모니터링 |
| 본인 작품만 사용 후 종료 | 멘토가 "3건 이상" 점검 |
| 13차시 미완성 작품 | "미완성 상태 피드백이 더 가치 있음" 안내 |

## 짓다·코들

- 짓다 갤러리: 5~30분 — 작품 사용·댓글
- 코들 보드: 30~40분 — 받은 피드백 정리
- 코들 퀴즈: 40~48분 — 우수 사례 추천. 결과 즉시 확인 후 15차시 발표팀 선정

## 다음 차시

15차시는 우수 사례 발표·업스테이지 코멘트·바이브톤 연결. 본 차시 추천 결과로 발표팀 선정.
