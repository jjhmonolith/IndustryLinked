# [14차시 / 50분] 갤러리 + 상호 피드백

**주관**: 팀모노리스 / **분반**: 트랙별 분반 (단, 15분 즈음 트랙 교차 체험 가능)

## 학습 목표

1. 갤러리에서 동료 작품 3개 이상을 학생 시점으로 직접 써본다.
2. 각 작품에 짓다 댓글로 구체적인 피드백 1개씩을 남긴다.
3. 내 작품에 받은 피드백을 정리하고 우수사례 자천·타천 추천을 한다.

## 진행 흐름

| 시간 | 내용 |
|------|------|
| 0-5분 | 도입 — "오늘 칭찬·발견·작은 개선 제안만. 평가 아님." |
| 5-30분 | **동료 작품 체험 + 댓글** — 1인당 3개 작품에 댓글 1개씩 |
| 30-40분 | **내 작품 피드백 정리** — 받은 댓글을 구글독스에 옮기고 한 줄 응답 |
| 40-48분 | **우수사례 추천** — 자기 트랙 안에서 1-2개 추천 (15차시 발표 후보) |
| 48-50분 | 클로징 — 15차시 발표 안내 |

## 동료 피드백 가이드 (학습자 배포)

좋은 댓글 = **구체 + 구성적**.

```
[좋은 댓글 예시]
"학생 화면에서 입력 후 결과가 나오는 흐름이 빨라서 좋았어요.
힌트가 정답을 안 알려주는 것도 인상 깊었습니다.
대시보드에서 '자주 막힌 지점'이 학년별로 분리되면 더 좋겠어요."

[피해야 할 댓글]
"잘하셨어요!" / "좋아요" (구체성 X)
"이거 다 잘못됐어요" (구성적 X)
```

피드백 항목 4가지 권장:

1. **인상 깊은 점 1가지** (What worked)
2. **학생/교사 시점에서 답답한 점 1가지** (What didn't)
3. **작은 개선 제안 1가지** (Small fix)
4. **궁금한 점 1가지** (Curious about)

## 트랙 교차 체험 (옵션, 15-25분 사이)

- 트랙 A 인원이 트랙 B 작품 1개, 트랙 B 인원이 트랙 A 작품 1개 체험
- 효과: "내 트랙이 아닌 영역도 다 응용 가능하다"는 인식. 바이브톤에서 트랙 융합 동기.
- 운영: 분반 공간이 가까우면 자연스럽게, 멀면 갤러리 링크만 교환

## 강사 핵심 메시지

- "오늘은 *평가가 아니라 서로 배우는 시간*. 내가 못 본 아이디어를 동료에게서 가져가는 게 목적."
- "구체 피드백이 받는 사람을 더 행복하게 한다."
- "내가 받은 피드백 중 *바이브톤 가서 반영할 것* 1개를 정해두세요."

## 사전 준비물

- 짓다 갤러리 트랙별 정리
- 댓글 양식 가이드 (위 4항목)
- 우수사례 추천 폼 (구글독스)

## 체크포인트

- 모든 학습자가 동료 작품 3개 이상에 댓글
- 자기 작품에 받은 피드백 정리
- 우수사례 추천 1-2건 제출

## 흔한 실패 패턴과 대응

| 실패 | 대응 |
|------|------|
| 댓글이 칭찬만 / 비판만 | 4항목 양식 강제. 양식대로 안 쓴 댓글은 강사가 보강 요청 |
| 일부 작품에 댓글이 몰림 | "댓글 0개 작품 우선" 룰 안내. 강사가 모니터링하며 분산 |
| 학습자가 자기 작품만 보고 끝남 | 멘토가 "최소 3개 체험" 모니터링 |
| 13차시 미완성 작품 | "미완성도 OK, *지금까지 한 것*에 대해 받는 피드백이 더 가치 있다" 메시지 |

## 짓다 / 구글독스 사용 시점

- **짓다**: 5-30분 — 갤러리 체험과 댓글
- **구글독스**: 30-48분 — 피드백 정리, 우수사례 추천

## 다음 차시 연결

→ 15차시는 우수사례 발표 + 업스테이지 게스트 단평 + 바이브톤 연결. 14차시 우수사례 추천 결과로 발표팀이 결정된다.
