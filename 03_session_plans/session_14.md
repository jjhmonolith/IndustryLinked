# [14차시 / 50분] 갤러리 사용 및 상호 피드백

**주관**: 팀모노리스 / **분반**: 트랙별 분반(15~25분 구간에서 트랙 교차 사용 가능)

## 학습 목표

1. 갤러리에서 동료 작품 3건 이상을 학생 시점으로 사용한다.
2. 각 작품에 짓다 댓글로 구체적 피드백 1건씩을 작성한다.
3. 본인 작품이 수렴한 피드백을 정리하고 우수 사례 추천을 응답한다.

## 진행 흐름

| 시간 | 내용 |
|------|------|
| 0-5분 | 도입 — 본 차시는 평가가 아닌 상호 학습이며, 칭찬·발견·개선 제안 중심임을 안내 |
| 5-30분 | 동료 작품 사용 및 짓다 갤러리 댓글 — 1인당 작품 3건에 4항목 댓글 작성 |
| 30-40분 | 본인 작품 피드백 정리 — 받은 댓글을 코들 보드 "받은 피드백" 카드로 정리 및 1줄 응답 |
| 40-48분 | 우수 사례 추천 — 코들 퀴즈 트랙별 객관식 응답(본인 작품 제외, 2건 이내) |
| 48-50분 | 마무리 — 15차시 발표 안내 |

## 동료 피드백 작성 가이드 (참여 교원 배포)

좋은 피드백 = 구체성 + 건설성

```
[권장 예시]
"학생 화면의 입력-결과 흐름의 응답 속도가 우수하다.
정답을 직접 제공하지 않는 힌트 양식이 인상 깊다.
대시보드에서 '정체 지점'을 학년별로 분리 표시하면 개선될 것이다."

[지양 예시]
"잘 만들었다" / "좋다" (구체성 부족)
"전반적으로 부적절하다" (건설성 부족)
```

피드백 작성 항목 4건:

1. 인상 깊은 점 1건
2. 학생 또는 교사 시점에서 불편한 점 1건
3. 소규모 개선 제안 1건
4. 질문 1건

## 트랙 교차 사용 (선택 운영, 15~25분 구간)

- 트랙 A 참여 교원이 트랙 B 작품 1건, 트랙 B 참여 교원이 트랙 A 작품 1건 사용
- 효과: 트랙 외 영역의 응용 가능성 인식, 바이브톤 트랙 융합 동기 형성
- 운영: 분반 공간이 인접한 경우 공간 이동, 원거리인 경우 갤러리 링크 교환

## 강사 강조 사항

- 본 차시는 평가가 아닌 상호 학습이다. 동료 작품에서 본인이 미처 고려하지 못한 아이디어를 도출하는 것이 목표이다.
- 구체적 피드백이 수렴자에게 학습 효과를 발생시킨다.
- 본인이 받은 피드백 중 바이브톤에서 반영할 항목 1건을 선정한다.

## 사전 준비물

- 짓다 갤러리 트랙별 정리
- 코들 보드 "받은 피드백" 사전 등록(트랙별 1건)
- 코들 퀴즈 우수 사례 추천 — 트랙별 객관식 1문항. 선택지는 13차시 종료 후 참여 교원 작품 리스트로 강사가 신속 생성(약 10분)
- 댓글 작성 가이드(4항목)

## 성취 기준

- 모든 참여 교원이 동료 작품 3건 이상에 댓글을 작성한다.
- 본인 작품이 수렴한 피드백을 정리한다.
- 우수 사례 추천 1~2건을 제출한다.

## 주요 위험 요인과 대응 방안

| 위험 요인 | 대응 방안 |
|-----------|-----------|
| 피드백이 칭찬 또는 비판 일변으로 작성 | 4항목 양식 준수 안내. 양식 미준수 시 강사가 보강 요청 |
| 일부 작품에 피드백 집중 | "피드백 0건 작품 우선" 안내. 강사가 분포 모니터링하여 분산 유도 |
| 본인 작품만 사용 후 종료 | 멘토가 "동료 작품 3건 이상 사용" 점검 |
| 13차시 미완성 작품 | "미완성 상태에서의 피드백이 더 가치 있음" 안내 |

## 짓다 / 코들 사용 시점

- 짓다 갤러리: 5~30분 — 동료 작품 사용 및 댓글 작성(짓다 작품에 직접 작성하는 댓글)
- 코들 보드: 30~40분 — "받은 피드백" 정리 카드
- 코들 퀴즈: 40~48분 — 우수 사례 추천(강사가 결과를 즉시 확인하여 15차시 발표팀 선정)

## 다음 차시 연결

15차시는 우수 사례 발표, 업스테이지 게스트 코멘트, 바이브톤 연결 안내로 구성된다. 14차시 우수 사례 추천 결과에 따라 발표 팀이 선정된다.
