# [13차시 / 50분] AI 보조 코딩 — 수업 맞춤화

**주관**: 팀모노리스 + 멘토 / **분반**: 트랙별 분반

## 학습 목표

1. 12차시 동작 모델에 본인 수업 맥락(시나리오·어조·외양·특화 규칙)을 1~3건 반영한다.
2. 학생 관점 반응을 예측하며 추가 미세 조정 1건을 수행한다.
3. 짓다 갤러리에 본인 결과물을 14차시 활용을 위해 정리·등록한다.

## 진행 흐름

| 시간 | 내용 |
|------|------|
| 0-5분 | 도입 — 본 차시는 본인 수업 맥락 반영 작업 시간임을 안내. 최소 1건 반영 필수 |
| 5-10분 | 맞춤화 참고 카드 3건 제시(참여 교원 자유 선택) |
| 10-40분 | 본 작업 — 맞춤화 작업 수행 |
| 40-48분 | 갤러리 등록 — 제목·1줄 설명·화면 캡처·체험 링크 |
| 48-50분 | 14차시 시연 시나리오 작성(약 1분) |

## 맞춤화 참고 카드 — 트랙 A 예시

| 항목 | 내용 |
|------|------|
| 수업 어조 | AI 도우미를 학급 캐릭터로 설정 — 페르소나·어조 조정 |
| 난이도 단계 | 1차 실패 시 간략 힌트, 3차 실패 시 상세 힌트로 단계화 |
| 격려 문구 | 통과 시 격려 문구 추가 및 학생 이름 호출 |
| 교사 시야 | 교사 대시보드에 정체 빈도 상위 코드 행 번호 표시 |
| 시도 제한 | 동일 문제 5회 실패 시 교사 호출 안내 메시지 표시 |

## 맞춤화 참고 카드 — 트랙 B 예시

| 항목 | 내용 |
|------|------|
| 단원 어조 | 본인 학년 어휘 수준에 맞춰 응답 어조 조정 |
| 교사 페르소나 | 평소 수업 어조로 응답하도록 시스템 프롬프트 조정 |
| 점검 질문 | 대화 중간에 AI가 학생에게 확인 질문 1건 제시 |
| 출처 표시 강화 | 응답마다 교재 페이지·문단 번호를 명확히 표시 |
| 부진 학생 신호 | 동일 어휘를 3회 이상 혼동하는 학생을 교사 대시보드에 표시 |

## 강사 강조 사항

- 본 차시는 본인 수업 맥락 반영이 핵심이다. 1건의 깊이 있는 반영이 다수의 표면적 반영보다 우선한다.
- 3건 모두 반영하지 못해도 1건의 완성도 높은 반영이 학습 목표 달성에 충분하다.
- 갤러리 등록은 14차시 동료 피드백 수렴을 위한 필수 단계이다.

## 사전 준비물

- 참고 카드 10건(트랙별)
- 짓다 갤러리 — 트랙별 폴더 또는 태그 사전 설정
- 멘토 4~5명 / 트랙

## 성취 기준

- 모든 참여 교원이 12차시 동작 모델에 최소 1건의 맞춤화를 완료한다.
- 짓다 갤러리에 결과물을 등록한다(제목·1줄 설명·체험 링크·화면 캡처).
- 14차시 시연 시나리오 1줄을 작성한다.

## 주요 위험 요인과 대응 방안

| 위험 요인 | 대응 방안 |
|-----------|-----------|
| 12차시 합격 기준 미달 상태로 진입 | 강사가 사전 제작한 표준 완성본을 복제하여 출발점 동기화 후 맞춤화 진행 |
| 과도한 추가 기능 욕심 | "본 차시 미완성 시에도 발표 진행"임을 멘토가 안내 |
| 짓다 갤러리 등록 미숙 | 강사 시연 1회 후 멘토 순회 지원 |
| 작업 중 결과물 손상 | 12차시 종료 시점 스냅샷으로 복원 |

## 짓다 / 코들 사용 시점

- 짓다: 5~48분 — 맞춤화 작업 및 갤러리 등록
- 코들 활동지: 48~50분 — 14차시 시연 시나리오(정형 양식: 1줄 소개, 시연 순서, 강조 항목)

## 다음 차시 연결

14차시는 갤러리에서 동료 작품을 사용하고 댓글로 피드백을 작성하는 단계이다. 본인 작품의 갤러리 등록이 완료되어야 동료 피드백 수렴이 가능하다.
