# [13차시 / 50분] 바이브코딩 — 커스터마이즈

**주관**: 팀모노리스 + 멘토 / **분반**: 트랙별 분반

## 학습 목표

1. 12차시 동작 버전에 자기 수업 색깔(시나리오·톤·외양·특이 규칙)을 1-3가지 입힌다.
2. "내 학생이라면 어떻게 반응할까"를 상상하며 한 가지 미세 조정을 더 한다.
3. 짓다 갤러리에 자기 결과물을 14차시용으로 정리 업로드한다.

## 진행 흐름

| 시간 | 내용 |
|------|------|
| 0-5분 | 도입 — "오늘이 자유 시간. 단, 3가지는 꼭 입혀라" |
| 5-10분 | **커스텀 영감 카드 3장** 보여주기 (학습자 자유 선택) |
| 10-40분 | **본 작업** — 커스텀 작업 |
| 40-48분 | **갤러리 정리** — 제목·한 줄 설명·스크린샷·체험 링크 |
| 48-50분 | 14차시 자기 시연 시나리오 메모 (1분) |

## 커스텀 영감 카드 — 트랙 A 예시

| 카드 | 내용 |
|------|------|
| **수업 톤** | "AI 도우미를 우리 반 캐릭터로" — 페르소나·말투 설정 |
| **난이도 단계** | "힌트가 너무 즉시 나옴. 첫 실패엔 짧게, 3번 실패 후 자세히" |
| **격려 문구** | "통과 시 격려 한 줄 추가, 학생 이름 호출" |
| **교사 시야** | "교사 대시보드에 *가장 자주 막힌 줄 번호* 추가" |
| **출석/시도 제한** | "한 문제에 5번 실패하면 *교사 호출* 메시지" |

## 커스텀 영감 카드 — 트랙 B 예시

| 카드 | 내용 |
|------|------|
| **단원 톤** | "내 학년 어휘에 맞추기 — 중학교라면 ㅈㅎㅁㅁ 톤" |
| **선생님 페르소나** | "내 평소 말투로 답하도록 시스템 프롬프트 조정" |
| **퀴즈 모드** | "대화 중간에 짧은 확인 질문 1개를 AI가 학생에게 던지기" |
| **출처 강조** | "답변마다 교재 페이지·문단 번호를 또렷이 표시" |
| **부진 학생 신호** | "같은 단어를 3회 이상 헷갈리는 학생은 교사 대시보드에 표시" |

## 강사 핵심 메시지

- "오늘이 진짜 *바이브코딩*. 자기 수업 맥락을 반영한 1가지가 핵심."
- "3가지 다 못해도 *1가지를 정말 잘* 하는 게 낫다."
- "갤러리 업로드는 14차시 동료 피드백을 받기 위한 필수 작업."

## 사전 준비물

- 영감 카드 10장 (트랙별)
- 짓다 갤러리 — 트랙별 폴더/태그
- 멘토 4-5명 / 트랙

## 체크포인트

- 모든 학습자가 12차시 동작 버전에서 **최소 1가지 커스텀** 완료
- 짓다 갤러리에 작품 업로드 (제목, 한 줄 설명, 체험 링크, 스크린샷)
- 14차시 시연 시나리오 1줄 작성

## 흔한 실패 패턴과 대응

| 실패 | 대응 |
|------|------|
| 12차시 합격선을 못 넘은 상태로 시작 | 강사가 미리 만든 표준 완성본을 클론하여 출발선 맞추기 → 그 위에 커스텀 |
| "더 많이 넣고 싶다" 욕심 | 멘토가 "오늘 끝나면 못 끝난 채로 발표해야 한다"고 환기 |
| 짓다 갤러리 업로드 미숙 | 강사 시연 1회 + 멘토 순회 |
| 결과가 망가져 동작 안 함 | 12차시 종료 시점 스냅샷으로 롤백 |

## 짓다 / 구글독스 사용 시점

- **짓다**: 5-48분
- **구글독스**: 48-50분 — 14차시 시연 시나리오 메모

## 다음 차시 연결

→ 14차시는 갤러리에서 *다른 팀 작품*을 써보고 댓글을 다는 시간. 자기 작품이 갤러리에 잘 업로드되어 있어야 동료 피드백을 받을 수 있다.
