# [13차시 / 50분] AI 보조 코딩 — 수업 맞춤화

**주관**: 팀모노리스 + 멘토 / **분반**: 트랙별 분반

## 학습 목표

1. 12차시 모델에 본인 수업 맥락 1~3건을 반영한다.
2. 학생 관점 반응을 예측하며 미세 조정 1건을 수행한다.
3. 짓다 갤러리에 결과물을 등록한다.

## 진행 흐름

| 시간 | 내용 |
|------|------|
| 0-5분 | 도입 — 본 차시는 수업 맥락 반영. 최소 1건 필수 |
| 5-10분 | 맞춤화 참고 카드 3건 제시 |
| 10-40분 | 본 작업 |
| 40-48분 | 갤러리 등록 — 제목·1줄 설명·화면 캡처·체험 링크 |
| 48-50분 | 14차시 시연 시나리오 작성(약 1분) |

## 맞춤화 참고 카드 — 트랙 A

| 항목 | 내용 |
|------|------|
| 수업 어조 | AI 도우미를 학급 캐릭터로 설정 |
| 난이도 단계 | 1차 실패 간략 힌트, 3차 실패 상세 힌트 |
| 격려 문구 | 통과 시 격려 + 학생 이름 호출 |
| 교사 시야 | 대시보드에 정체 빈도 상위 코드 행 번호 표시 |
| 시도 제한 | 5회 실패 시 교사 호출 안내 |

## 맞춤화 참고 카드 — 트랙 B

| 항목 | 내용 |
|------|------|
| 단원 어조 | 본인 학년 어휘에 맞춰 어조 조정 |
| 교사 페르소나 | 평소 수업 어조로 응답하도록 시스템 프롬프트 조정 |
| 점검 질문 | 대화 중간에 AI가 확인 질문 1건 제시 |
| 출처 강화 | 응답마다 교재 페이지·문단 명확 표시 |
| 부진 학생 신호 | 동일 어휘 3회 이상 혼동 학생을 대시보드 표시 |

## 강사 강조

- 수업 맥락 반영이 핵심. 1건의 깊이 있는 반영이 다수의 표면적 반영보다 우선.
- 3건 미완성도 1건의 완성도가 학습 목표 달성에 충분.
- 갤러리 등록은 14차시 피드백 수렴의 필수 단계.

## 사전 준비물

- 참고 카드 10건(트랙별)
- 짓다 갤러리 — 트랙별 폴더·태그 사전 설정
- 멘토 4~5명 / 트랙

## 성취 기준

- 모든 교원이 12차시 모델에 최소 1건 맞춤화 완료.
- 짓다 갤러리 등록(제목·1줄 설명·체험 링크·화면 캡처).
- 14차시 시연 시나리오 1줄 작성.

## 주요 위험·대응

| 위험 | 대응 |
|------|------|
| 12차시 합격 기준 미달 진입 | 강사 "표준 완성본" 복제로 출발점 동기화 |
| 추가 기능 욕심 | "본 차시 미완성 시에도 발표" 안내 |
| 갤러리 등록 미숙 | 강사 시연 1회 + 멘토 순회 |
| 결과물 손상 | 12차시 종료 시점 스냅샷 복원 |

## 짓다·코들

- 짓다: 5~48분 — 맞춤화·갤러리 등록
- 코들 활동지: 48~50분 — 14차시 시연 시나리오

## 다음 차시

14차시는 갤러리에서 동료 작품 사용·피드백. 본인 작품 갤러리 등록이 피드백 수렴의 전제.
