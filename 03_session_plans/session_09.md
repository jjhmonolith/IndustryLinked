# [9차시 / 50분] 트랙 기술 1

**주관**: 공동 (기술: 업스테이지 / 적용: 팀모노리스) / **분반**: **트랙별 분반 개시**

## 트랙 분반 개시 — 운영 안내

- 본 차시부터 트랙별 분반. 다른 공간 입실.
- 7차시 옵션 A·B 챗봇을 출발 자료로 진입.
- 7차시 옵션과 다른 트랙도 가능. 1~6차시가 공통 기반.
- 트랙별 코들 교실 2개로 분리(보드·활동지·퀴즈).

## 학습 목표 (트랙 공통)

1. 트랙 핵심 기술의 작동 원리를 도식화한다.
2. 짓다에서 호출 프롬프트 패턴 1건을 실행한다.
3. 본인 도구의 결합 위치를 결정한다.

---

## 트랙 A — 자동 채점 + 안전한 LLM 평가

### 진행 흐름

| 시간 | 내용 |
|------|------|
| 0-5분 | 도입 — 자동 채점 구현 방식 |
| 5-15분 | 자동 채점 2가지 — 입출력 매칭, 단위 테스트. 사례·장단점 |
| 15-25분 | AI 테스트케이스 생성 시연 |
| 25-42분 | 실습 — 본인 문제 1건의 (a) 채점 결과 (b) LLM 테스트케이스 생성 |
| 42-50분 | 팀별 공유·한계 토의 |

### 핵심 패턴

```
[학생 코드]
   ↓
[1] 테스트케이스(다수 입력) 실행
   ↓
[2] 기대 출력과 비교
   ↓
[3] 통과/실패 + 실패 지점 표시
```

### 짓다 프롬프트 예시

```
당신은 파이썬 자동 채점 시스템입니다.
다음 문제에 대한 테스트케이스 5건을 JSON 배열로 생성합니다.
각 항목은 {"input": ..., "expected_output": ...} 형식.

[문제]
{문제 텍스트}

[정답 예시]
{정답 코드}
```

### 한계 (사전 안내)

- 짓다 환경의 학생 코드 실시간 실행 지원 확인 필요(**검증 항목**).
- 대안: 문자열 매칭, Solar 실행 결과 시뮬레이션, Pyodide 임베드. 본 차시는 단순 방식 채택.

## 트랙 B — RAG 5단계

### 진행 흐름

| 시간 | 내용 |
|------|------|
| 0-5분 | 도입 — 7차시 챗봇 환각 회고, RAG 필요성 |
| 5-15분 | RAG 5단계 도식 — 자료 → 청크 → 임베딩 → 검색 → 응답 |
| 15-25분 | 짓다 RAG 구현 시연 — 업스테이지 임베딩 API + 인메모리 검색 |
| 25-42분 | 실습 — 본인 단원 발췌 3~5건 입력, 발췌 기반 응답 챗봇 제작 |
| 42-50분 | 팀별 공유·한계 토의 |

### 핵심 패턴

```
[교사 자료 업로드]
   ↓
[1] 자료를 청크로 분할
   ↓
[2] 청크를 벡터로 변환·저장
   ↓
[학생 질문]
   ↓
[3] 질문을 벡터로 변환
[4] 최유사 청크 3건 검색
   ↓
[5] LLM에 "청크 + 질문" 입력 후 응답 생성
   ↓
[학생 응답 + 출처]
```

### 짓다 프롬프트 예시

```
당신은 [학년] [과목] 학습 도우미입니다.

다음 자료 범위 내에서만 응답합니다:
---
{retrieved_chunks}
---

규칙:
1. 자료에 없는 내용은 "교재에서 확인 어려움" 응답.
2. 응답 끝에 참고 자료 표시.
3. 정답 직접 제공하지 않고 학생이 자료에서 찾도록 질문 응답.

학생 질문: {user_question}
```

### 한계 (사전 안내)

- 짓다 벡터 검색 지원 확인 필요(**검증 항목**).
- 대안: 인메모리 키워드 매칭 + 임베딩 유사도.
- 단원 1개(5~10페이지)는 단순 구현으로 충분.

---

## 강사 강조 (공통)

- 이론보다 *짓다 활용 패턴* 중심. 이론 5분, 실습 40분.
- 작동하는 1줄 호출이 작동하지 않는 완전한 이해보다 우선이다.
- 짓다·Solar 한계는 있는 그대로 안내한다.

## 사전 준비물

- 트랙 A: 자동 채점 기본 템플릿 + 예시 문제 3건
- 트랙 B: RAG 기본 템플릿 + 예시 단원 발췌 3건
- 멘토 4~5명 / 트랙

## 성취 기준

- 트랙 A: 본인 문제 1건의 정답·오답 분리 결과 확인
- 트랙 B: 발췌 기반 응답·"교재 외" 거절 각 1회 이상 확인

## 주요 위험·대응

| 위험 | 대응 |
|------|------|
| RAG 이론 시간 초과 | 5단계 도식 1장으로 종료 후 짓다 진입 |
| 학생 코드 실행 미지원 | 시뮬레이션·문자열 매칭. 강사 시연 활용 |
| 검색 오분류 | "청크 크기 조정" 실험 과제 |

## 짓다·코들

- 짓다: 15~42분
- 코들 활동지: 42~50분 — "본인 도구 한계 1건·다음 결정"
