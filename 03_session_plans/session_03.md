# [3차시 / 50분] 수업도구의 구조 이론 — 두 도구 비교 분해

**주관**: 팀모노리스 / **분반**: 공통(단일 트랙)

## 학습 목표

1. 수업도구의 4요소(학생-교사 구분 · 활동 배부 · 결과물 제출 · 교사 대시보드)를 자기 언어로 설명할 수 있다.
2. 2차시에서 체험한 **두 도구(코들 자동채점 + 소크룸)**를 4요소로 비교 분해한다.
3. 2차시에서 적은 "바꾸고 싶은 점"이 어느 요소에 속하는지 매핑한다.

## 진행 흐름

| 시간 | 내용 |
|------|------|
| 0-5분 | 도입 — "수업도구는 결국 4가지로 분해된다. 두 도구를 같은 틀로 본다." |
| 5-15분 | **4요소 이론** 강의 + 코들·소크룸 화면을 4요소로 색칠해서 한 장씩 보여주기 |
| 15-35분 | **팀별 비교 분해 실습**: 두 도구를 한 표에 나란히 채우기 |
| 35-45분 | **매핑 활동**: 2차시 "바꾸고 싶은 점"이 어느 요소인가? 팀별 토의 |
| 45-50분 | 정리 — "9차시 트랙을 정한다면 어느 도구의 어느 요소를 더 깊이 파고 싶은가" 1줄 메모 |

## 수업도구 4요소 — 정의와 두 도구 비교

| 요소 | 정의 | 코들(자동채점) | 소크룸(교과 챗봇) |
|------|------|----------------|-------------------|
| **학생-교사 구분** | 누가 어떤 권한을 갖는가, 어떻게 식별하는가 | 교사: 문제 만들기 / 학생: 코드 작성·제출 (계정 식별) | 교사: 자료·주제 설정 / 학생: 닉네임 입장 (가벼움) |
| **활동 배부** | 교사가 만든 활동이 학생에게 어떻게 전달되는가 | 문제 링크, 코스 등록 | 수업 링크 (소크룸 방식) |
| **결과물 제출** | 학생 활동이 어떤 형태로 수집되는가 | 코드 + 자동 채점 결과 + AI 대화 로그 | 학생-AI 대화 로그 + 학습 활동 응답 |
| **교사 대시보드** | 교사가 무엇을 보고 어떻게 개입하는가 | 학생별 통과율, 자주 막힌 지점, AI 대화 내역 | 학생별 대화 흐름, 이해도 신호, 위험 발화 |

## 비교 분해 워크시트 (코들 활동지)

학습자가 한 활동지에 두 도구를 나란히 채움:

| 요소 | 코들의 구현 | 소크룸의 구현 | 두 도구의 공통점 | 내가 바꾸고 싶은 점 |
|------|-------------|----------------|------------------|----------------------|
| 학생-교사 구분 | | | | |
| 활동 배부 | | | | |
| 결과물 제출 | | | | |
| 교사 대시보드 | | | | |

## 강사 토론 유도 질문

- **공통**: 자동채점이 통과해도 학습이 안 된 경우가 있나? 소크룸에서 학생이 답을 다 적어도 학습이 안 된 경우가 있나? → "**AI 대화 로그도 결과물의 일부**"라는 인사이트
- **차이**: 코들은 계정으로 학생 식별, 소크룸은 닉네임만. 무엇이 어떤 상황에 적합한가?
- **확장**: 둘 다 가지고 있는 한 가지 부족함은 무엇인가? → 학습 도달 평가의 어려움

## 강사 핵심 메시지

- "11-13차시에서 만들 MVP도 결국 이 4요소를 다 갖춰야 한다. 오늘이 그 설계도."
- "두 도구를 비교하면 *공통의 패턴*과 *내 트랙의 특수성*이 동시에 보인다."
- "한 번에 4요소를 다 잘하지 못한다. **자신이 가장 못마땅했던 한 요소부터 고치는 것**이 좋은 출발."

## 사전 준비물

- 코들·소크룸 화면 캡처를 4요소로 색칠한 슬라이드 (도구별 1장씩, 총 2장)
- **코들 활동지** — 4요소 비교표 양식

## 체크포인트

- 모든 학습자가 **코들 활동지**(4요소 × 2도구 비교표) 채움
- "내가 바꾸고 싶은 점"이 4요소 중 어디에 속하는지 매핑 완료
- 강사가 강사 화면(학습 분석)에서 작성률 100% 확인

## 흔한 실패 패턴과 대응

| 실패 | 대응 |
|------|------|
| 이론 강의가 길어짐 | 5-15분 슬라이드를 8장 이내로 제한. 강사가 시간 체크 |
| 한 도구만 채우고 다른 도구 비움 | 15분 시점에 "둘 중 하나만 채운 분 손?" 확인 후 미진한 도구 짚어주기 |
| "4요소가 다 비슷한 것 같아요" | "결과물"과 "대시보드"의 차이를 구체 사례로 (코드 제출 자체와 통과율 통계의 차이) |
| 매핑이 막연 | 강사가 팀별 순회하며 한 요소만 함께 채워주기 |

## 짓다 / 코들 사용 시점

- **코들 활동지**: 15-50분 — 4요소 × 2도구 비교표 + 매핑 입력. 이중효과 = 활동지 양식 그 자체가 11차시 기획서의 원형
- **짓다**: 미사용

## 강사 운영 도구

- **코들 학습 분석 / 기상캐스터**: 강사가 작성 진행률·정체 팀 실시간 파악 → 정체 팀 우선 순회
