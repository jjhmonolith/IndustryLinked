# [3차시 / 50분] 수업도구의 구조 이론

**주관**: 팀모노리스 / **분반**: 트랙별 분반

## 학습 목표

1. 수업도구의 4요소(학생-교사 구분 · 활동 배부 · 결과물 제출 · 교사 대시보드)를 자기 언어로 설명할 수 있다.
2. 2차시에서 체험한 도구를 4요소로 분해해본다.
3. 2차시에서 적은 "바꾸고 싶은 점"이 어느 요소에 속하는지 매핑한다.

## 공통 진행 흐름 (트랙 A·B 동일 시간 배분)

| 시간 | 내용 |
|------|------|
| 0-5분 | 도입 — "수업도구는 결국 4가지로 분해된다" |
| 5-20분 | **4요소 이론** 강의 + 코들/소크룸 화면을 4요소로 색칠해서 보여주기 |
| 20-35분 | **팀별 분해 실습**: 2차시에서 체험한 도구를 4요소 표로 정리 |
| 35-45분 | **매핑 활동**: 2차시 "바꾸고 싶은 점"이 어느 요소인가? 팀별 토의 |
| 45-50분 | 정리 — "내 MVP는 4요소를 어떻게 갖출 것인가" 1줄 메모 |

## 수업도구 4요소 — 정의와 예시

| 요소 | 정의 | 트랙 A 예시(코드 자동채점 도구) | 트랙 B 예시(교과 챗봇) |
|------|------|----------|----------|
| **학생-교사 구분** | 누가 어떤 권한을 갖는가, 어떻게 식별하는가 | 교사: 문제 만들기 / 학생: 코드 작성·제출 | 교사: 자료·주제 설정 / 학생: 닉네임 입장 |
| **활동 배부** | 교사가 만든 활동이 학생에게 어떻게 전달되는가 | 문제 링크, 코스 등록 | 수업 링크 (소크룸 방식) |
| **결과물 제출** | 학생 활동이 어떤 형태로 수집되는가 | 코드 + 자동 채점 결과 + AI 대화 로그 | 학생-AI 대화 로그 + 학습 활동 응답 |
| **교사 대시보드** | 교사가 무엇을 보고 어떻게 개입하는가 | 학생별 통과율, 자주 막힌 지점, AI 대화 내역 | 학생별 대화 흐름, 이해도 신호, 위험 발화 |

학습자가 채울 표(워크시트):

| 요소 | 코들의 구현 | 내가 바꾸고 싶은 점 |
|------|-------------|----------------------|
| 학생-교사 구분 | | |
| 활동 배부 | | |
| 결과물 제출 | | |
| 교사 대시보드 | | |

### 강사 토론 유도 질문

- 자동채점이 통과해도 학습이 안 된 경우가 있나? → "AI 대화 로그도 결과물의 일부"라는 인사이트
- 대시보드에서 어떤 정보가 부족했나?

학습자가 채울 표(워크시트):

| 요소 | 소크룸의 구현 | 내가 바꾸고 싶은 점 |
|------|---------------|----------------------|
| 학생-교사 구분 | | |
| 활동 배부 | | |
| 결과물 제출 | | |
| 교사 대시보드 | | |

### 강사 토론 유도 질문

- 닉네임만으로 학생을 식별하면 무엇이 어렵나? → 출석·이력 추적
- 학생-AI 대화에서 "학습이 일어났다"를 어떻게 알 수 있나? → 평가 설계 도전

## 강사 핵심 메시지

- "11-13차시에서 만들 MVP도 결국 이 4요소를 다 갖춰야 한다. 오늘이 그 설계도."
- "한 번에 4요소를 다 잘하지 못한다. **자신이 가장 못마땅했던 한 요소부터 고치는 것**이 좋은 출발."
- "이론 강의는 짧게. 표 채우는 데 시간 쓰자."

## 사전 준비물

- 코들/소크룸 화면 캡처를 4요소로 색칠한 슬라이드
- 4요소 워크시트 (팀별 1장)

## 체크포인트

- 팀별 **코들 활동지**(4요소 표) 모두 채움
- "내가 바꾸고 싶은 점"이 4요소 중 어디에 속하는지 매핑 완료
- 강사가 강사 화면(학습 분석)에서 모든 팀의 작성률 100% 확인

## 흔한 실패 패턴과 대응

| 실패 | 대응 |
|------|------|
| 이론 강의가 길어짐 | 5-20분 슬라이드를 10장 이내로 제한. 강사가 시간 체크 |
| "4요소가 다 비슷한 것 같아요" | 한 도구에서 "결과물"과 "대시보드"의 차이가 뭔지 구체 사례로 |
| 매핑이 막연 | 강사가 팀별 순회하며 한 도구에 대해 한 요소만 함께 채워주기 |

## 짓다 / 코들 사용 시점

- **코들 활동지**: 35-50분 — 4요소 표 + 매핑 입력 (정형 양식). 이중효과 = 활동지 = 학습자가 곧 트랙별 MVP에서 만들 "정형 입력 화면"의 원형
- **짓다**: 미사용

## 강사 운영 도구

- **코들 학습 분석 / 기상캐스터**: 강사가 작성 진행률·정체 팀 실시간 파악 → 정체 팀 우선 순회
