# [3차시 / 50분] Solar 모델 소개

**주관**: 업스테이지 / **분반**: 공통

## 학습 목표

1. Solar의 정체성과 타 모델과의 차이를 한 문장으로 설명한다.
2. "독자 파운데이션 모델"을 본인 언어로 설명한다.
3. Solar로 수행 가능한 과업 유형을 인식한다.

## 진행 흐름

| 시간 | 내용 |
|------|------|
| 0-5분 | 도입 — 2차시 도구의 기반 모델 문제 제기 |
| 5-15분 | Solar·독파모 개요 — 슬라이드 5장 이내, 벤치마크 미사용 |
| 15-30분 | 시연 1(코드) — 동일 오류를 Solar / GPT / Gemini에 설명 요청 후 비교 |
| 30-42분 | 시연 2(교과) — 교과서 단락을 요약·질문 생성 후 모델별 비교 |
| 42-50분 | 질의응답 + 보드 입력("Solar로 만들 도구 1줄") |

## 강사 강조 (업스테이지 사전 가이드)

- 지양: 벤치마크 점수, 파라미터 수, 아키텍처 설명
- 권장: 한국 교실 시나리오 기반 시연
- 권장: 통제 가능성·한국 교실 적합성 중심
- 모델별 한계 명시: Solar·GPT·Gemini 각 1건

## 사전 준비물

- 업스테이지: 시연 코드 2건, 짓다·콘솔 실시간 실행
- 강사: 마이크·화면·인터넷
- 참여 교원: 노트북(직접 호출은 7차시부터)

## 성취 기준

- "독자 파운데이션 모델"을 옆 교원에게 30초로 설명한다(짝 활동).
- 시연 2건에서 모델별 차이 각 1건 식별.

## 주요 위험·대응

| 위험 | 대응 |
|------|------|
| 슬라이드 위주 진행 | "15분 시점 시연 진입 필수" |
| 비교 항목 불명확 | 시연 전 비교 항목(속도·자연성·규칙 준수)을 화면 표시 |
| API 장애 | 백업 영상 또는 캡처 슬라이드 |

## 짓다·코들

- 짓다: 강사 시연. 참여 교원 직접 호출 X
- 코들 보드: 42분 — "Solar로 만들 도구 1줄"
