# [3차시 / 50분] Solar 모델 소개

**주관**: 업스테이지 / **분반**: 공통

## 학습 목표

1. Solar의 정체성과 타 모델과의 차이를 한 문장으로 설명할 수 있다.
2. "독자 파운데이션 모델"의 의미를 자신의 언어로 설명할 수 있다.
3. Solar로 수행 가능한 과업 유형(텍스트 생성·코드 설명·요약·번역 등)을 인식한다.

## 진행 흐름

| 시간 | 내용 |
|------|------|
| 0-5분 | 도입 — 2차시에서 사용한 코들 AI 튜터·소크룸의 기반 모델에 대한 문제 제기 |
| 5-15분 | Solar 및 독파모 개요 — 슬라이드 5장 이내, 벤치마크 수치 미사용 |
| 15-30분 | 실시간 시연 1 (코드 영역) — 동일 코드 오류를 Solar / GPT / Gemini에 설명 요청 후 한국어 표현·구체성 비교 |
| 30-42분 | 실시간 시연 2 (교과 자료 영역) — 한국 중·고 교과서 단락 1건을 요약·질문 생성 후 모델별 비교 |
| 42-50분 | 질의응답 및 코들 보드 입력 — "Solar로 제작하고자 하는 도구 한 줄" |

## 강사 강조 사항 (업스테이지 사전 가이드)

- 지양: 벤치마크 점수 비교, 파라미터 수, 모델 아키텍처 설명
- 권장: 한국 교실 시나리오 기반 시연. Solar의 작동 방식과 통제 가능성에 초점
- 권장: 범용 LLM 대비 차이를 *통제 가능성*과 *한국 교실 적합성* 중심으로 제시
- 모델별 한계도 명시: Solar의 약점 1건, GPT의 약점 1건, Gemini의 약점 1건

## 사전 준비물

- 업스테이지: 시연용 코드 2건(코드 오류 설명·교과서 요약), 짓다 또는 콘솔에서 실시간 실행
- 강사: 마이크·화면 출력 장비·안정적 인터넷
- 참여 교원: 노트북 준비 (직접 호출은 7차시부터, 본 차시는 관찰 중심)

## 성취 기준

- "독자 파운데이션 모델"의 의미를 옆 참여 교원에게 30초간 설명 가능 (짝 활동)
- 시연 2건에서 모델별 차이를 각 1건 이상 식별

## 주요 위험 요인과 대응 방안

| 위험 요인 | 대응 방안 |
|-----------|-----------|
| 슬라이드 중심 진행으로 시연 시간 부족 | 사전 가이드에서 "15분 시점 시연 진입 필수" 명시 |
| 모델 비교 항목이 불명확 | 시연 전 비교 항목(속도·한국어 자연성·교사 지정 규칙 준수도)을 화면에 사전 표시 |
| 실시간 시연 시 API 장애 | 백업 영상 또는 사전 캡처 슬라이드 1세트 준비 |

## 짓다 / 코들 사용 시점

- 짓다: 시연 화면(강사). 참여 교원은 직접 호출하지 않는다.
- 코들 보드: 42분 — "Solar로 제작하고자 하는 도구 한 줄" 카드 입력

## 다음 차시 연결

4차시에서 모델 선택 기준을 정립하고 1차 선택 모델을 결정한다. 본 차시는 "Solar의 정체성", 다음 차시는 "Solar를 언제 활용하는가"를 다룬다.
