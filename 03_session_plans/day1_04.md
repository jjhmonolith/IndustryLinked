# [1일차 · 4차시 / 14:00–15:00 (1h)] 수업자료를 데이터로: Document Parse + Information Extract 활용하기

**주강사**: 김남혁(업스테이지 PM) [보조: 신화준] / **분반**: 공통

## 학습 목표
1. 문서인식 AI(Document AI)의 원리와 'Document Parse → Information Extract' 파이프라인을 이해한다.
2. Colab에서 본인 수업자료를 업로드해 구조화하고 핵심 정보를 JSON으로 추출할 수 있다.
3. 이 결과가 다음 차시(보조 agent) 챗봇의 입력이 됨을 이해한다.

## 진행 흐름
| 시간 | 내용 | 담당 |
|------|------|------|
| 0–7분 | 문서인식 AI 개념 — "문서 → 구조화 → 핵심 추출" 파이프라인 개요 | 김남혁 |
| 7–25분 | Document Parse 실습 — 시험지 PDF·학습지·공문을 Colab에 업로드해 구조화, 표·수식 추출 확인 | 김남혁 [신화준] |
| 25–42분 | Information Extract 실습 — 파싱 결과에서 문항·배점·핵심 개념만 JSON으로 추출 | 김남혁 [신화준] |
| 42–52분 | 본인 수업자료 1건 적용 — 구조화 + 핵심 추출 JSON 생성 | 참가자 [보조: 신화준] |
| 52–60분 | 복습 — 이 JSON이 5차시 챗봇의 입력이 됨을 정리, 평가/행정 자동화 시나리오 연결 | 김남혁 |

## 강사 강조
- "PDF는 사람 눈에는 자료지만 AI에겐 데이터가 아니다 — 구조화해야 비로소 쓸 수 있다"를 핵심 메시지로.
- Information Extract에서 '무엇을 뽑을지(문항·배점·개념)'를 정하는 것이 곧 도구의 목적 정의임을 강조한다.
- 오늘 만든 JSON을 반드시 코들/개인 폴더에 저장하게 한다 — 5차시에서 그대로 재사용한다.

## 사전 준비물
- Document Parse / Information Extract 실습 Colab 노트북, Solar/Document AI API 키
- 예제 문서(시험지 PDF·학습지·공문)와 참가자 본인 수업자료(사전 지참 안내)
- 추출 결과 JSON 저장 위치(코들 보드/개인 드라이브)

## 성취 기준(산출물)
- 본인 수업자료 1건의 구조화 결과 + 핵심 추출 JSON 파일
- 코들 보드에 JSON(또는 캡처) 업로드

## 주요 위험·대응
| 위험 | 대응 |
|------|------|
| 참가자가 자료 미지참 | 공용 예제 문서로 실습 대체, 이후 개인 자료로 재실습 안내 |
| 복잡한 표·수식 파싱 품질 편차 | 잘 되는 자료 유형 안내, 실패 시 부분 추출로 진행 |
| JSON 저장 누락으로 5차시 지장 | 신화준이 저장 여부 체크리스트 확인 |

## 도구 사용
- Document Parse + Information Extract: 이 차시 핵심 실습 도구
- Colab: 업로드·파싱·추출 실행 환경
- Solar: 다음 차시에서 이 JSON을 활용(이번 차시는 준비 단계)
- 코들: JSON 산출물 보관

## 다음 차시
5차시에서 Solar API로 보조 agent(챗봇)를 만든다. 오늘 추출한 수업자료 JSON을 프롬프트에 넣어 '내 자료 범위 안에서만 답하는' 챗봇을 제작하므로, 이 산출물이 곧 다음 차시의 입력이다.
