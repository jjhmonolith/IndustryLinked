# [1일차 · 5차시 / 15:00–16:00 (1h)] 내 수업자료로 대답하는 나만의 보조 agent 제작하기

**주강사**: 이준엽(업스테이지 Lead) [보조: 신화준] / **분반**: 공통

## 학습 목표
1. Solar API를 단독 호출하고 system/messages 구조로 '정보 교과 보조교사' 페르소나를 설정할 수 있다.
2. 직전 차시의 DP·IE 추출 자료를 프롬프트에 넣어 자기 수업자료 기반으로만 답하는 챗봇을 만든다.
3. 자기 수업자료 기반 보조 agent(챗봇) MVP를 완성한다.

## 진행 흐름
| 시간 | 내용 | 담당 |
|------|------|------|
| 0–5분 | 오늘 만들 보조 agent 미리보기, 2단계 제작 흐름 안내 | 이준엽 |
| 5–25분 | 1단계 — Solar API 단독 호출, system 프롬프트로 '정보 교과 보조교사' 페르소나 설정, messages/system 구조 이해 | 이준엽 [신화준] |
| 25–48분 | 2단계 — 4차시 DP·IE 추출 JSON을 프롬프트에 삽입, 자기 수업자료 기반으로만 답하도록 구성 | 이준엽 [신화준] |
| 48–56분 | 개인 테스트 — 자기 자료 관련 질문/무관 질문을 던져 응답 확인 | 참가자 [보조: 신화준] |
| 56–60분 | 산출물 코들 업로드, 다음 차시 연결 | 이준엽 |

## 강사 강조
- 1단계와 2단계의 차이를 체감시킨다: 페르소나만 준 챗봇 vs 내 자료를 근거로 답하는 챗봇.
- "자료를 프롬프트에 넣으면 그 범위 안에서 답한다" — 3차시의 환각 원리와 연결해, 자료 기반이 왜 신뢰도를 높이는지 설명.
- 완벽한 챗봇이 아니라 'MVP(최소 동작본)'가 목표임을 명확히 해 시간 내 완성을 유도한다.

## 사전 준비물
- Solar API 챗봇 실습 Colab 노트북, API 키
- 4차시에서 만든 본인 수업자료 JSON(미보유자용 공용 예제 JSON)
- system 프롬프트 예시(정보 교과 보조교사 페르소나 템플릿)

## 성취 기준(산출물)
- 자기 수업자료 기반 보조 agent(챗봇) MVP 동작
- 코들 보드에 코드/대화 예시 캡처 업로드

## 주요 위험·대응
| 위험 | 대응 |
|------|------|
| 4차시 JSON 미보유/저장 실패 | 공용 예제 JSON 제공으로 실습 지속 |
| 프롬프트가 길어 토큰 초과·응답 저하 | 핵심 필드만 넣도록 JSON 축약 안내 |
| 자료 밖 질문에도 답해버림(범위 이탈) | 현상만 확인해두고 7차시 안전장치 실습으로 연결 |

## 도구 사용
- Solar LLM API: 챗봇의 응답 엔진(system/messages 호출)
- Colab: 챗봇 코드 작성·실행
- 코들: 보조 agent MVP 산출물 보관
- 짓다: 최종 전시 대상(예고)
