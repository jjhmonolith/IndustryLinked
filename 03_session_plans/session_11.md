# [11차시 / 50분] AI 보조 코딩 — 기획 및 착수

**주관**: 팀모노리스 + 멘토 / **분반**: 트랙별 분반, 3~5인 팀

## 학습 목표

1. 본인 수업용 도구의 기획서(1쪽)를 30분 내에 작성한다.
2. 트랙별 기본 템플릿을 짓다에서 실행 확인한다.
3. 본인 기획과 템플릿의 차이를 목록화한다.

## 진행 흐름

| 시간 | 내용 |
|------|------|
| 0-5분 | 도입 — 11~13차시 3시간 흐름 안내 |
| 5-35분 | 기획 30분 — 1쪽 기획서 |
| 35-48분 | 기본 템플릿 실행 — 짓다 복제·작동 확인 |
| 48-50분 | "차이 항목" 작성(12차시 입력) |

## 기획서 양식 (코들 활동지 사전 등록)

```
1. 제목: ______________________________
2. 누구의 어떤 문제를 해결하는가? (1문장)
   ______________________________

3. 학생 입력과 응답:
   입력: ______________________________
   결과: ______________________________

4. 교사 사전 준비와 확인:
   준비: ______________________________
   확인: ______________________________

5. 4요소 매핑:
   - 학생-교사 구분: ____________
   - 활동 배부: ____________
   - 결과물 제출: ____________
   - 교사 대시보드: ____________

6. LLM 호출 위치 (Solar API):
   - 호출 1: ____________ (입력→출력)
   - 호출 2(선택): ____________

7. 가드레일:
   - 정답·이탈 차단 규칙 1줄: ____________

8. 본 연수 완성할 MVP:
   ______________________________

9. 제외할 항목(우선순위 하):
   ______________________________
```

## 트랙 A — 기본 템플릿

- 화면 1: 문제 표시 + 코드 입력 + 제출
- 화면 2: 자동 채점 결과
- 화면 3: 실패 시 Solar 힌트(가드레일 적용)
- 화면 4(선택): 교사 대시보드 — 시도 수·통과율·정체 지점

교원 작업: 본인 기획에 맞춰 변형(예: 수학 함수 작성·데이터 분석 코드 등).

## 트랙 B — 기본 템플릿

- 화면 1: 닉네임 입력 + 단원 선택
- 화면 2: 학생 챗봇 화면(RAG + 가드레일)
- 화면 3(선택): 교사 대시보드 — 대화 로그·차단 시도

교원 작업: 본인 단원 자료 입력, 가드레일·페르소나를 학년에 맞춰 조정.

## 강사 강조

- 기획 30분은 1차 작성이 목표. 심화는 12~13차시.
- 템플릿 실행 미작동 시 즉시 멘토 요청. 본 차시 미작동 시 12차시 진행 어려움.
- 기획서 9번(제외 항목)이 완성 가능성을 결정. 기능 축소가 핵심.

## 사전 준비물

- 짓다 트랙 A·B 기본 템플릿(사전 검증 완료)
- 코들 활동지 — 기획서 양식(트랙별 1건)
- 멘토 5~7명 / 트랙
- 트랙별 "수업 시나리오 카드" 10건(기획 정체 시 참고)

## 성취 기준

- 모든 교원이 기획서 1쪽 작성.
- 짓다에 기본 템플릿 실행, 배포 링크 화면 표시 확인.
- "차이 항목" 메모 작성.

## 주요 위험·대응

| 위험 | 대응 |
|------|------|
| 기획 시간 초과 | 멘토가 "수업 시나리오 카드" 제시 |
| MVP 범위 과대 | 9번(제외 항목) 보강. 기능 축소 학습 |
| 템플릿 실행 실패 | 멘토 1:1 지원. 강사 시연 상시 표시 |
| 팀 합의 불가 | "개인 MVP 1건씩 가능" 안내 |

## 짓다·코들

- 짓다: 35~50분 — 템플릿 복제·실행
- 코들 활동지: 5~35분 기획서, 48~50분 차이 항목
- 코들 학습 분석: 강사가 작성률 실시간 확인

## 다음 차시

12차시는 50분 전체 따라 제작. 11차시 템플릿 미실행 팀은 점심 시간 별도 지원.
