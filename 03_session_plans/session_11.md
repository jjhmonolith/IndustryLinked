# [11차시 / 50분] AI 보조 코딩 — 기획 및 따라 제작 착수

**주관**: 팀모노리스 + 멘토 다수 / **분반**: 트랙별 분반, 3~5인 팀

## 학습 목표

1. 본인 수업 맥락에 맞는 도구의 기획서(1쪽)를 30분 내에 작성한다.
2. 팀모노리스 제공 트랙별 기본 템플릿을 짓다에 실행하여 작동을 확인한다.
3. 본인 기획과 기본 템플릿의 차이(맞춤 작업 항목)를 목록화한다.

## 진행 흐름

| 시간 | 내용 |
|------|------|
| 0-5분 | 도입 — 11~13차시 AI 보조 코딩 3시간 흐름 안내(11차시 기획·착수, 12차시 완성, 13차시 맞춤화) |
| 5-35분 | 기획 30분 — 1쪽 기획서 작성 |
| 35-48분 | 기본 템플릿 실행 — 짓다에 트랙별 기본 프로젝트 복제 및 작동 확인 |
| 48-50분 | "본인 기획과 기본 템플릿의 차이" 항목 작성(12차시 입력 자료) |

## 기획서 양식 (1쪽, 코들 활동지 사전 등록)

```
1. 제목: ______________________________
2. 누구의 어떤 문제를 해결하는가? (1문장)
   ______________________________

3. 학생은 무엇을 입력하고 무엇을 응답받는가?
   입력: ______________________________
   결과: ______________________________

4. 교사는 무엇을 사전 준비하고 무엇을 확인하는가?
   준비: ______________________________
   확인: ______________________________

5. 4요소 매핑:
   - 학생-교사 구분: ____________
   - 활동 배부: ____________
   - 결과물 제출: ____________
   - 교사 대시보드: ____________

6. LLM 호출 위치 (Solar API):
   - 호출 1: ____________ (입력→출력)
   - 호출 2(선택): ____________

7. 가드레일:
   - 정답·이탈 차단 규칙 1줄: ____________

8. 본 연수에서 완성할 최소 동작 모델(MVP):
   ______________________________

9. 본 연수에서 제외할 항목(우선순위 하):
   ______________________________
```

## 트랙 A — 기본 템플릿 구성

팀모노리스가 짓다에 사전 등록한 트랙 A 기본 템플릿:

- 화면 1: 문제 표시 + 코드 입력란 + 제출 버튼
- 화면 2: 자동 채점 결과(통과/실패)
- 화면 3: 실패 시 Solar 힌트(정답 차단 가드레일 적용)
- 화면 4(선택): 교사 대시보드 — 학생별 시도 수·통과율·정체 지점

참여 교원 작업: 기본 템플릿을 본인 기획에 맞춰 변형(예: 수학 함수 작성 문제로 변경, 데이터 분석 코드 문제로 변경 등).

## 트랙 B — 기본 템플릿 구성

팀모노리스가 짓다에 사전 등록한 트랙 B 기본 템플릿:

- 화면 1: 닉네임 입력 + 단원 선택
- 화면 2: 학생 챗봇 화면(RAG + 가드레일 적용)
- 화면 3(선택): 교사 대시보드 — 학생별 대화 로그·차단 시도

참여 교원 작업: 기본 템플릿에 본인 단원 자료를 입력하고 가드레일·페르소나를 본인 학년에 맞춰 조정.

## 강사 강조 사항

- 기획 30분은 1차 작성을 목표로 한다. 심화 검토는 12~13차시에서 진행한다.
- 기본 템플릿 실행 단계에서 작동하지 않는 경우 즉시 멘토에게 지원 요청한다. 본 차시 작동 미확인 시 12차시 진행이 어렵다.
- 기획서 9번 항목(제외할 항목)이 완성 가능성을 결정한다. 기능 축소가 핵심이다.

## 사전 준비물

- 짓다 트랙 A·B 기본 템플릿 프로젝트(사전 검증 완료)
- 코들 활동지 — 기획서 양식(9개 항목, 트랙별 1건 사전 등록)
- 멘토 5~7명 / 트랙(50명 / 멘토 1인 ≈ 7~10명)
- 트랙별 "수업 시나리오 카드" 10건 — 기획 정체 시 참고용(예: 코딩 자가 점검 시나리오, 단원 복습 챗봇 시나리오 등)

## 성취 기준

- 모든 참여 교원이 기획서 1쪽을 작성한다.
- 짓다에 기본 템플릿이 실행되며 배포 링크에서 화면 표시가 확인된다.
- "차이 항목" 메모를 작성한다(12차시 입력 자료).

## 주요 위험 요인과 대응 방안

| 위험 요인 | 대응 방안 |
|-----------|-----------|
| 기획 단계에서 시간 초과 | 멘토가 "수업 시나리오 카드" 1건을 제시하여 1차 결정 지원 |
| MVP 범위 과대 | 9번 항목(제외 항목) 보강 안내. 기능 축소 학습 |
| 기본 템플릿 실행 실패 | 멘토 1:1 지원. 강사 시연 화면을 별도 화면에 상시 표시 |
| 팀 내 기획 합의 불가 | "본 차시는 개인 MVP 1건씩으로도 가능" 안내. 합의 불가 시 분리 진행 |

## 짓다 / 코들 사용 시점

- 짓다: 35~50분 — 기본 템플릿 복제 및 실행
- 코들 활동지: 5~35분 기획서(9항목 정형 입력), 48~50분 차이 항목(활동지 말미 칸)
- 코들 학습 분석: 강사가 기획서 작성률 실시간 확인 후 정체 팀 식별

## 다음 차시 연결

12차시는 50분 전체를 따라 제작에 할애한다. 11차시에서 기본 템플릿 실행이 완료되지 않은 팀은 12차시 진행이 어려우므로, 점심 시간에 멘토가 별도 지원한다(운영 영역).
