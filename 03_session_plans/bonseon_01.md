# [본선 · 1차시 / 10:00–11:00 (1h)] 수업 설계 점검 — 학습 목표와 학생 활동 방안 점검

**담당**: 전종현(팀모노리스 대표), 김한성(학회/고려사이버대) / **분반**: 5분반(40명/반)

## 학습 목표
1. 본선 진행 방식·평가 기준·분반 구성을 이해하고 전담 멘토와 협업 관계를 형성한다.
2. 집합연수에서 만든 자기 AI 수업 도구의 학습 목적과 사용 상황(언제·어떤 학생에게)을 재정의한다.
3. 학습자 시점에서 도구가 어떻게 보이고 쓰이는지를 짧게 재설계한다.

## 진행 흐름
| 시간 | 내용 | 담당 |
|------|------|------|
| 10:00–10:15 (15분) | 본선 진행 안내 — 하루 일정·평가 방식(시연 평가 4항목, 최종 발표 동료 루브릭)·산출물 흐름 개관 | 전종현 |
| 10:15–10:25 (10분) | 5분반 분반 배정 및 전담 멘토 인사 — 반별 자리 정리, 멘토와 참가자 상호 소개 | 전종현·김한성 |
| 10:25–10:45 (20분) | 자기 도구 학습 목표 재정립 — 학습 목적·사용 상황(언제·어떤 학생에게)을 워크시트에 다시 적고 멘토와 1차 점검 | 김한성 |
| 10:45–10:58 (13분) | 학습자 시점 재설계 — 학생이 처음 도구를 마주할 때 무엇이 보이고 무엇을 하게 되는지 화면·흐름을 짧게 스케치 | 전종현·김한성 |
| 10:58–11:00 (2분) | 다음 차시(시연) 준비 안내 — 시연 순서·시간 배분 예고 | 전종현 |

## 강사 강조
- 도구의 기능을 늘리기보다 "이 도구가 누구의 어떤 학습을 돕는가"를 먼저 분명히 하도록 강조한다.
- 학습 목표는 교사 관점 문장이 아니라 학생이 실제로 하게 되는 활동으로 서술하도록 안내한다.
- 학습자 시점 명확성은 본선 시연 평가 항목이므로, 첫 화면에서 사용 목적이 드러나는지 스스로 점검하게 한다.

## 사전 준비물
- 집합연수 산출물(자기 AI 수업 도구)과 접속 환경(코들 계정, 개발 환경 로그인).
- 학습 목표·사용 상황 재정립 워크시트(반별 배포).
- Solar LLM API 키·Colab 등 개발 환경 접속 확인.

## 성취 기준(산출물)
- 재정의된 학습 목적·사용 상황(언제·어떤 학생에게) 1장 워크시트.
- 학습자 시점 도구 보임새 스케치(첫 화면·핵심 사용 흐름) 초안.

## 주요 위험·대응
| 위험 | 대응 |
|------|------|
| 집합연수 도구가 미완성이라 점검할 대상이 모호함 | 완성도보다 목표·사용 상황 정의에 집중, 멘토가 최소 시연 가능 범위를 함께 설정 |
| 개발 환경·API 접속 오류로 시작 지연 | 등록 시간(09:50–10:00)에 접속 사전 확인, 멘토가 반별로 즉시 지원 |
| 학습 목표가 기능 나열로 흐름 | 워크시트를 학생 활동 중심 문장으로 작성하도록 예시 제공 |

## 도구 사용
- 코들: 본선 운영·자료 배포·진행 안내.
- 개발 환경(Colab/API 키), Solar LLM API: 자기 도구 접속·동작 확인.
- 짓다 갤러리: 이후 차시 전시·평가 대상 도구 사전 등록 안내.
