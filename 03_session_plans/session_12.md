# [12차시 / 50분] AI 보조 코딩 — 따라 제작 완성

**주관**: 팀모노리스 + 멘토 다수 / **분반**: 트랙별 분반

## 학습 목표

1. 11차시 기본 템플릿을 본인 기획서의 최소 동작 모델(MVP)까지 완성한다.
2. 학생 시점·교사 시점을 각 1회 끝까지 시연한다.
3. 미작동 항목 1건을 명확히 식별하여 13차시 맞춤 작업 목록에 등록한다.

## 진행 흐름

| 시간 | 내용 |
|------|------|
| 0-5분 | 도입 — 본 차시 종료 시점에 "학생 시점 끝까지 작동"이 합격 기준임을 안내 |
| 5-40분 | 본 작업 — 기본 템플릿을 기획서에 맞춰 변형. 정체 시 코들 보드 "지원 요청 카드" 게시 후 멘토 실시간 대응 |
| 40-48분 | 양 시점 시연 — 학생 1회, 교사 1회 완주 |
| 48-50분 | "미작동 항목 1건" 코들 보드 카드 입력 |

## 본 작업의 표준 진행 순서 (참여 교원 안내)

1. 화면 1(시작 화면) 텍스트·문구를 본인 기획에 맞춰 교체한다.
2. 학생 입력에 본인 시나리오 데이터 1건을 입력하여 완주를 시도한다. 정체 지점을 식별한다.
3. 정체 지점 1건을 짓다에 자연어로 설명하여 수정한다.
4. 재시도하여 다음 정체 지점을 식별한다.
5. 위 절차를 반복한다.

원칙: 일괄 수정을 시도하지 않는다. *정체 지점 → 1건 수정 → 작동 검증* 사이클을 반복한다.

## AI 보조 코딩 자연어 지시 패턴 (참여 교원 배포 자료)

```
[수정 요청 패턴]
- "{화면 X}에서 {Y}가 표시되도록 수정"
- "{버튼/입력} 작동 시 {결과 화면} 표시"
- "Solar API 호출 결과를 {위치}에 1줄로 표시"
- "현재 코드를 유지하고, {기능}만 추가"

[디버그 요청 패턴]
- "다음 오류 발생: {오류 메시지}. 수정 위치 안내"
- "기대 결과: {기대}, 실제 결과: {실제}. 원인 분석"
- "본 함수가 호출되지 않음. 원인 1~2건 안내"

[권장하지 않는 패턴]
- "전체 임의 수정"
- "처음부터 재제작"(기존 작업 손실 가능)
- 동시 다중 요구(1건씩 진행 권장)
```

## 트랙 A — 12차시 합격 기준

- 학생 화면에서 본인 시나리오 코드 입력 및 제출 가능
- 자동 채점 결과 표시
- 실패 시 정답 코드 미노출 상태로 Solar 힌트 노출
- 교사 화면(또는 콘솔)에서 시도 기록 1건 이상 확인

## 트랙 B — 12차시 합격 기준

- 학생 화면에서 닉네임 입장 가능
- 본인 단원 발췌문 기반 응답 1건 이상 확인
- 주제 외 질문 1건에 대한 거절 응답 확인
- 교사 화면(또는 콘솔)에서 대화 로그 1건 이상 확인

## 강사 강조 사항

- 사용자 경험 완성도가 아닌 *완주 가능성*이 본 차시의 합격 기준이다.
- 정체 시 짓다에 자연어 1줄로 입력한다. 5분 이상 정체 시 멘토에 지원 요청한다.
- 미작동 항목 1건을 명확히 식별하면 13차시 작업의 출발점이 된다.

## 사전 준비물

- 멘토 5~7명 / 트랙
- 코들 보드 — "지원 요청" 보드 사전 등록. 카드 색상: 적색(우선)·황색(일반). 멘토가 실시간 모니터링하여 순회 우선순위 결정
- 화면 출력 — 강사가 짓다 자연어 지시 패턴을 상시 표시

## 성취 기준

- 모든 팀이 합격 기준 4항목을 통과한다. 짓다 배포 링크에서 학생 화면 작동이 확인된다.
- "미작동 항목 1건" 코들 보드 카드 기록

## 주요 위험 요인과 대응 방안

| 위험 요인 | 대응 방안 |
|-----------|-----------|
| 짓다 작업 중 기본 템플릿 손상 | 11차시 종료 시점 스냅샷으로 복원(사전 스냅샷 안내) |
| 동시 다중 요청으로 짓다 응답 혼란 | 멘토가 "1건씩 작동 확인 후 다음" 코칭 |
| API 호출 한도 초과로 응답 중단 | 트랙별 백업 키 활용 또는 호출 시점 분산(운영팀 협의) |
| 합격 기준 미달성 팀 | 강사가 사전 제작한 "12차시 표준 완성본" 링크를 복제하여 출발점 동기화(13차시 동시 출발) |

## 짓다 / 코들 사용 시점

- 짓다: 5~48분 — 본격 사용
- 코들 보드: 5~50분 — 지원 요청 카드(실시간), 48~50분 "미작동 항목 1건 + 13차시 맞춤 아이디어 1건" 회고 카드
- 코들 기상캐스터: 강사가 정체 팀을 실시간 식별

## 다음 차시 연결

13차시는 최소 동작 모델에 본인 수업 맥락을 결합하는 단계이다. 12차시 합격 기준 도달 여부가 13차시 학습의 질을 좌우한다.
