# [12차시 / 50분] 바이브코딩 — 따라 만들기 완성

**주관**: 팀모노리스 + 멘토 다수 / **분반**: 트랙별 분반

## 학습 목표

1. 11차시 베이스라인을 자기 기획서의 *최소 동작 버전*까지 완성한다.
2. 학생 시점·교사 시점 각각 1회 끝까지 시연한다.
3. 작동하지 않는 부분 1가지를 정확히 짚어내 13차시 커스텀 작업 목록에 올린다.

## 진행 흐름

| 시간 | 내용 |
|------|------|
| 0-5분 | 도입 — "오늘 50분 끝에 *학생 시점이 끝까지 흐르는* 게 합격선" |
| 5-40분 | **본 작업** — 베이스라인을 기획서 요구에 맞게 변형. 막히면 **코들 보드**에 "막힘 카드" 게시 → 멘토 라이브 대응 |
| 40-48분 | **두 시점 시연** — 학생 1회 + 교사 1회 끝까지 흘려보기 |
| 48-50분 | "작동 안 하는 1가지" 코들 보드 카드 |

## 본 작업의 표준 진행 순서 (학습자 안내)

1. 화면 1(가장 앞 화면) 텍스트·문구를 자기 기획에 맞게 교체
2. 학생 입력에 자기 시나리오 데이터 1개 넣고 끝까지 흘려보기 → 어디서 막히는지 확인
3. 막힌 지점 1개만 짓다에게 자연어로 설명해 고치기
4. 다시 흘려보기 → 막힌 지점 다음 1개
5. 반복

➜ "한 번에 다 고치려 하지 말 것. **막힌 지점 → 1개 수정 → 검증** 사이클을 자주 돌릴 것."

## 바이브코딩 자연어 지시 패턴 (학습자 배포 치트시트)

```
[수정 요청 패턴]
- "{화면 X}에서 {Y}가 보이게 해줘"
- "{버튼/입력} 누르면 {결과 화면}이 보이게 해줘"
- "Solar API 호출 결과를 {위치}에 한 줄로 표시해줘"
- "현재 코드를 그대로 두고, {기능}만 추가해줘"

[디버그 요청 패턴]
- "이 오류가 떴어: {오류 메시지}. 어디를 고쳐야 해?"
- "내가 기대한 건 {기대} 인데 실제는 {실제}였어. 왜 그래?"
- "이 함수가 안 불려. 원인 1-2개만 알려줘"

[해선 안 될 패턴]
- "다 알아서 해줘"
- "처음부터 다시 만들어줘" (지금까지 작업 날아갈 수 있음)
- 한 번에 5개 요구 (한 번에 1개씩)
```

## 트랙 A — 12차시 합격선

- 학생 화면에서 자기 시나리오 코드를 넣고 제출
- 자동 채점 결과 표시
- 실패 시 Solar 힌트가 *정답 코드 없이* 노출
- 교사 화면(또는 콘솔)에서 시도 기록 1건이라도 보임

## 트랙 B — 12차시 합격선

- 학생 화면에서 닉네임 입장
- 자기 단원 발췌문 기반으로 질문 1개에 답변
- 주제 이탈 질문 1개에 거절
- 교사 화면(또는 콘솔)에서 대화 로그 1건이라도 보임

## 강사 핵심 메시지

- "예쁘게 X. *끝까지 흐르는 것*이 합격."
- "막히면 짓다에 *자연어로 한 줄* 입력. 5분 이상 막히면 멘토 호출."
- "지금 작동 안 하는 1가지를 정확히 알아두면 13차시가 쉬워진다."

## 사전 준비물

- 멘토 5-7명 / 트랙
- **코들 보드 — "막힘 신고" 보드** 사전 등록. 카드 색: 빨강(긴급)/노랑(보통). 멘토가 보드 실시간 모니터링하며 순회 우선순위 결정
- 화면 빔 — 강사가 짓다 자연어 지시 패턴을 띄워둠

## 체크포인트

- 모든 팀이 합격선 4가지 항목을 통과 → 짓다 배포 링크에 학생 화면이 동작
- "작동 안 하는 1가지" 코들 보드 카드 기록

## 흔한 실패 패턴과 대응

| 실패 | 대응 |
|------|------|
| 짓다가 베이스라인을 망쳐버림 | 11차시 종료 시점 스냅샷으로 롤백 (사전에 스냅샷 안내) |
| 한 번에 너무 많은 요구로 짓다가 뒤죽박죽 | 멘토가 "한 번에 1개씩, 작동 확인 후 다음" 코칭 |
| API 호출이 갑자기 안 됨 (공용 키 한도) | 트랙별 백업 키 또는 호출 시간 분산 (운영팀과 협의) |
| 합격선까지 못 옴 | 강사가 미리 만든 "12차시 표준 완성본" 링크를 클론하여 출발선 맞춰주기 (13차시에 다 같이 출발하기 위함) |

## 짓다 / 코들 사용 시점

- **짓다**: 5-48분 — 본격 사용
- **코들 보드**: 5-50분 내내 — 막힘 카드(실시간) + 48-50분 "작동 안 하는 1가지 + 13차시 커스텀 아이디어 1개" 회고 카드
- **코들 기상캐스터**: 강사가 정체 팀 즉시 감지

## 다음 차시 연결

→ 13차시는 "최소 동작 버전 → 내 수업 색깔 입히기". 12차시 합격선을 넘었어야 13차시가 즐거운 시간이 된다.
