# [12차시 / 50분] AI 보조 코딩 — 완성

**주관**: 팀모노리스 + 멘토 / **분반**: 트랙별 분반

## 학습 목표

1. 11차시 템플릿을 MVP까지 완성한다.
2. 학생 시점·교사 시점을 각 1회 시연한다.
3. 미작동 항목 1건을 13차시 작업 목록에 등록한다.

## 진행 흐름

| 시간 | 내용 |
|------|------|
| 0-5분 | 도입 — "학생 시점 끝까지 작동"이 합격 기준 |
| 5-40분 | 본 작업 — 템플릿 변형. 정체 시 코들 보드 "지원 요청 카드" |
| 40-48분 | 양 시점 시연 — 학생·교사 각 1회 |
| 48-50분 | "미작동 항목 1건" 코들 보드 입력 |

## 표준 진행 순서

1. 시작 화면 텍스트를 본인 기획에 맞춰 교체
2. 학생 입력에 본인 시나리오 데이터 1건 입력, 완주 시도. 정체 지점 식별
3. 정체 지점 1건을 짓다에 자연어로 입력해 수정
4. 재시도 후 다음 정체 지점 식별
5. 반복

원칙: 일괄 수정 X. *정체 → 1건 수정 → 검증* 사이클 반복.

## 자연어 지시 패턴 (배포 자료)

```
[수정 요청]
- "{화면 X}에 {Y} 표시"
- "{버튼/입력} 작동 시 {결과 화면} 표시"
- "Solar API 결과를 {위치}에 1줄 표시"
- "현재 코드 유지, {기능}만 추가"

[디버그 요청]
- "오류: {메시지}. 수정 위치 안내"
- "기대: {기대}, 실제: {실제}. 원인 분석"
- "함수가 호출되지 않음. 원인 1~2건"

[권장하지 않음]
- "전체 임의 수정"
- "처음부터 재제작"(작업 손실 위험)
- 동시 다중 요구(1건씩 진행)
```

## 트랙 A — 합격 기준

- 학생 화면에서 본인 시나리오 코드 입력·제출
- 자동 채점 결과 표시
- 실패 시 정답 비노출 Solar 힌트 노출
- 교사 화면에서 시도 기록 1건 이상

## 트랙 B — 합격 기준

- 학생 화면에서 닉네임 입장
- 본인 단원 발췌 기반 응답 1건 이상
- 주제 외 질문 1건에 거절
- 교사 화면에서 대화 로그 1건 이상

## 강사 강조

- UX 완성도가 아닌 *완주 가능성*이 합격 기준.
- 정체 시 짓다에 자연어 1줄 입력. 5분 이상 정체 시 멘토 요청.
- 미작동 항목 1건 식별이 13차시 출발점.

## 사전 준비물

- 멘토 5~7명 / 트랙
- 코들 보드 "지원 요청" 사전 등록. 카드 색상: 적색(우선)·황색(일반)
- 자연어 지시 패턴 화면 상시 표시

## 성취 기준

- 모든 팀이 합격 기준 4항목 통과. 배포 링크에서 학생 화면 작동.
- "미작동 항목 1건" 코들 보드 기록.

## 주요 위험·대응

| 위험 | 대응 |
|------|------|
| 템플릿 손상 | 11차시 종료 시점 스냅샷 복원 |
| 다중 요청 혼란 | 멘토 "1건씩 작동 확인 후 다음" 코칭 |
| API 한도 초과 | 백업 키 또는 호출 분산 |
| 합격 기준 미달 | 강사가 "12차시 표준 완성본" 복제로 출발점 동기화 |

## 짓다·코들

- 짓다: 5~48분
- 코들 보드: 5~50분 — 지원 요청(실시간), 48~50분 회고
- 코들 기상캐스터: 강사가 정체 팀 실시간 식별

## 다음 차시

13차시는 MVP에 본인 수업 맥락 결합. 12차시 합격 기준 도달이 13차시 질을 좌우한다.
