# [2차시 / 50분] 기존 수업도구 체험

**주관**: 팀모노리스 / **분반**: 공통

## 학습 목표

1. 두 도구(코들 자동채점·소크룸)를 모두 학생 시점으로 사용한다.
2. 각 도구의 강점·한계를 3개 이상 기술한다.
3. 본인 선호 방향을 잠정 기록한다(트랙 확정의 사전 신호).

## 진행 흐름

| 시간 | 내용 |
|------|------|
| 0-3분 | 도입 — 두 도구 체험 후 본인이 트랙 선택 |
| 3-18분 | 도구 1 — 코들 자동채점 + AI 튜터(학생 시점) |
| 18-33분 | 도구 2 — 소크룸(학생 시점) |
| 33-43분 | 그룹 토의 — 코들 보드 3색 카드(강점·한계·개선 희망) |
| 43-50분 | 다른 에듀테크 사용 경험 공유 + 정리 |

## 도구 1 — 코들 자동채점 + AI 튜터 (15분)

- 사용: 사전 등록 문제 1건 + 파이썬 AI 튜터
- 시나리오: "리스트 최댓값 반환 함수 작성"
  - 의도적 오답 1~2회 → AI 튜터 힌트 관찰
  - 정답 비제공 응답 양식 확인
- 관찰 항목(보드 입력):
  - 정답 비제공 AI의 학생 인식
  - 자동채점 미식별 사례
  - 교사 대시보드 추가 필요 정보

## 도구 2 — 소크룸 (15분)

- 사용: 정보 교과 단원 1건 사전 등록 수업
- 시나리오: 닉네임 접속, 5~7회 질의응답
  - 주제 외 질문 → 가드레일 확인
  - 정답 요구 → 되묻기 응답 확인
- 관찰 항목(보드 입력):
  - 주제 이탈 차단 방식
  - 정답 비제공·되묻기 응답의 학습 기여
  - 본인 단원 적용 시 필요 자료

> 두 도구 모두 학생 시점에 집중. 교사 시점은 강사 시연 1분으로 압축. 본격 교사 시점은 11~13차시.

## 강사 강조

- 도구 복제가 아닌 본인 수업과 맞지 않는 부분 식별이 목적이다.
- 강점·한계를 있는 그대로 기록한다. 7~13차시 제작의 출발 자료다.
- 트랙은 본 차시에서 결정하지 않는다. 8차시 종료 시점에 확정한다.
- 다른 에듀테크 경험도 공유한다.

## 성취 기준

- 모든 팀이 두 도구 각각에 3색 카드를 게시한다.
- 모든 참여 교원이 두 도구 학생 시점을 1회 이상 사용한다.
- 옆 팀 카드 1건 이상에 댓글을 작성한다.

## 주요 위험·대응

| 위험 | 대응 |
|------|------|
| 시간 부족 | 도구당 15분 마감 |
| 접속 지연 | 사전 로그인 확인. 강사 시연 화면 상시 표시 |
| 한 도구만 사용 | 18분 시점 강사가 전환 안내 |
| 토의 침묵 | 팀별 기록자 지정. 강사 순회 |
| 사전 경험자의 동기 저하 | 사전 경험자에게 조언자 역할 부여 |

## 짓다·코들

- 코들 보드: 33~43분 — 3색 카드·댓글. 학생 시점으로 보드 사용성 체득
- 짓다: 미사용
