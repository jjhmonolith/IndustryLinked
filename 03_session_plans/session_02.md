# [2차시 / 50분] 기존 수업도구 체험

**주관**: 팀모노리스 / **분반**: 트랙별 분반 시작

## 학습 목표

1. 자기 트랙의 대표 수업도구를 학생 시점·교사 시점에서 모두 경험한다.
2. 도구의 좋은 점·아쉬운 점을 3개 이상 정리한다.
3. "내 수업에 맞추려면 무엇을 바꾸고 싶은가"를 한 가지 적는다.

## 진행 흐름 (공통 구조, 트랙별 도구만 다름)

| 시간 | 내용 |
|------|------|
| 0-5분 | 도구 소개 + 오늘 할 일 (3가지 시점 체험) |
| 5-20분 | **학생 시점**: 미리 만들어둔 수업에 학생으로 참여 |
| 20-30분 | **교사 시점**: 교사 화면에서 수업 만들기·결과물 보기 |
| 30-42분 | **그룹 토의**: 좋은 점 / 아쉬운 점 / 내 수업에 맞추려면 — 구글독스에 팀별 기록 |
| 42-50분 | 다른 에듀테크 사용 경험 공유 (자유발언 2-3명) + 정리 |

## 트랙 A — Python 자동채점 + AI 튜터 체험

- **사용 도구**: 코들 — 자동채점 문제 1개 + 파이썬 AI 도우미 켠 상태
- **학생 시점 시나리오**: "리스트의 최댓값을 반환하는 함수 작성" 문제. 일부러 1-2번 실패해보며 AI 튜터가 어떤 힌트를 주는지 관찰
- **교사 시점 시나리오**: 자동채점 문제 1개를 만들어보고 테스트케이스 추가
- **관찰 포인트** (구글독스 질문):
  - 정답을 안 주는 AI가 학생에게 어떻게 느껴졌나?
  - 자동채점이 놓치는 케이스가 있었나?
  - 교사 대시보드에 무엇이 더 있으면 좋겠나?

## 트랙 B — 소크룸 체험

- **사용 도구**: 소크룸 — 정보 교과 한 단원으로 미리 만들어둔 수업
- **학생 시점 시나리오**: 닉네임으로 접속, 5-7번 질의응답. 일부러 주제와 무관한 질문도 던져보기
- **교사 시점 시나리오**: 새 수업 만들기 (주제·항목 입력), 대시보드 열람
- **관찰 포인트** (구글독스 질문):
  - 주제 이탈 시도가 정말 막혔는가? 어떻게 막혔는가?
  - AI가 답을 안 주고 되묻는 방식이 학생에게 효과적이었나?
  - 내 단원에 적용한다면 어떤 자료를 어떻게 넣어야 할까?

## 강사 핵심 메시지

- "오늘 이걸 그대로 따라 만드는 게 목적이 아니다. **이 도구의 어떤 부분이 내 수업과 안 맞는지**가 더 중요하다."
- "마음에 든 점·아쉬운 점을 솔직히 적자. 그게 11-13차시 바이브코딩의 재료가 된다."
- "다른 도구 써본 경험도 환영. 클래스카드·구글클래스룸·뤼튼 등 무엇이든."

## 체크포인트

- 모든 팀이 구글독스에 좋은 점 3개 · 아쉬운 점 3개 · 바꾸고 싶은 것 1개 기록 완료
- 학생/교사 양쪽 시점 모두 최소 1회씩 경험

## 흔한 실패 패턴과 대응

| 실패 | 대응 |
|------|------|
| 도구 접속 지연·계정 문제로 5-10분 손실 | 사전 안내문에서 사전 로그인 확인 / 강사 시연 화면을 빔으로 띄워두기 |
| 토의가 침묵 | 팀당 1명을 "기록자"로 지정. 강사가 팀별 순회하며 첫 질문 던지기 |
| "이미 코들·소크룸 써봤어요" 베테랑 | 베테랑에게 팀 내 "조언자" 역할 부여, 신규 교원 페어링 |

## 짓다 / 구글독스 사용 시점

- **구글독스**: 30-42분 — 팀별 시트에 좋은 점/아쉬운 점/바꾸고 싶은 점 기록
- **짓다**: 미사용
