# [2차시 / 50분] 기존 수업도구 체험 — 두 도구 직접 사용

**주관**: 팀모노리스 / **분반**: 공통

## 학습 목표

1. 양 트랙의 대표 수업도구 두 가지(코들 자동채점·소크룸)를 모두 학생 시점에서 사용한다.
2. 각 도구의 강점과 한계를 3개 이상 기술한다.
3. 두 도구 중 본인이 선호하는 방향을 잠정 기록한다 (8차시 트랙 확정의 사전 신호).

## 진행 흐름

| 시간 | 내용 |
|------|------|
| 0-3분 | 도입 — 두 도구를 모두 체험한 후 9차시부터 본인이 더 깊이 학습할 트랙을 선택한다는 점 안내 |
| 3-18분 | 도구 1 체험 — 코들 자동채점 및 파이썬 AI 튜터 (학생 시점) |
| 18-33분 | 도구 2 체험 — 소크룸 (학생 시점) |
| 33-43분 | 그룹 토의 — 강점·한계·선호 기록, 코들 보드 3색 카드(강점·한계·개선 희망)로 도구별 게시 |
| 43-50분 | 다른 에듀테크 사용 경험 공유(자유 발언 2~3건) 및 정리 |

## 도구 1 — 코들 자동채점 + AI 튜터 (15분)

- 사용 콘텐츠: 사전 등록된 자동채점 문제 1건 및 파이썬 AI 튜터 활성화
- 체험 시나리오: "리스트의 최댓값을 반환하는 함수 작성"
  - 1~2회 의도적 오답 입력으로 AI 튜터의 힌트 양식을 관찰한다.
  - 정답을 직접 제공하지 않는 AI의 응답 양식을 확인한다.
- 관찰 항목 (코들 보드 입력):
  - 정답을 제공하지 않는 AI가 학생에게 어떻게 인식되는가
  - 자동채점이 식별하지 못한 사례가 있는가
  - 교사 대시보드에 추가 필요한 정보 항목

## 도구 2 — 소크룸 (15분)

- 사용 콘텐츠: 정보 교과 단원 1건에 대한 사전 등록 수업
- 체험 시나리오: 닉네임 접속 후 5~7회 질의응답 수행
  - 주제 외 질문을 의도적으로 입력하여 가드레일 작동 양식을 확인한다.
  - 정답을 요구하는 입력을 시도하여 되묻기 응답 양식을 확인한다.
- 관찰 항목 (코들 보드 입력):
  - 주제 외 질문 차단의 작동 방식
  - 정답을 제공하지 않고 되묻는 응답이 학생 학습에 기여하는 양식
  - 본인 단원 적용 시 필요한 자료의 종류 및 형식

> 두 도구 모두 학생 시점 체험에 집중한다. 교사 시점(수업 생성·대시보드)은 강사가 도구별 1분씩 시연으로 제시한다. 교사 시점 본격 학습은 11~13차시 자기 도구 제작에서 진행한다.

## 강사 강조 사항

- 본 차시의 목적은 도구 복제가 아닌, 본인 수업에 맞지 않는 부분을 식별하는 것이다.
- 두 도구 모두에 대해 강점과 한계를 있는 그대로 기록한다. 본 기록은 7~13차시 제작의 출발 자료로 활용된다.
- 트랙은 본 차시에서 결정하지 않는다. 잠정 선호만 기록하며, 최종 확정은 8차시 종료 시점에 실시한다.
- 다른 에듀테크 사용 경험(클래스카드·구글 클래스룸·뤼튼 등)도 자유롭게 공유한다.

## 성취 기준

- 모든 팀이 두 도구 각각에 대해 코들 보드에 3색 카드(강점·한계·개선 희망)를 게시한다.
- 모든 참여 교원이 두 도구의 학생 시점을 1회 이상 사용한다.
- 옆 팀 카드 1건 이상에 댓글을 기록한다.

## 주요 위험 요인과 대응 방안

| 위험 요인 | 대응 방안 |
|-----------|-----------|
| 두 도구 체험 시간 부족 | 시간 관리 표시 운영 — 도구당 15분 마감 |
| 도구 접속 지연·계정 문제로 5~10분 손실 | 사전 안내문에서 사전 로그인 확인 요청. 강사 시연 화면을 별도 화면에 상시 표시 |
| 한 도구만 사용하고 다른 도구를 사용하지 않음 | 18분 시점에 강사가 전환 안내를 명확히 한다 |
| 토의 침묵 | 팀별 1명을 기록자로 지정. 강사가 팀별로 순회하며 첫 질문을 제시 |
| 사전 경험자의 학습 동기 저하 | 사전 경험자에게 팀 내 조언자 역할 부여, 신규 참여자와의 페어링 운영 |

## 짓다 / 코들 사용 시점

- 코들 보드: 33~43분 — 도구별 3색 카드 게시 및 동료 카드 댓글 작성. 부가 효과로 참여 교원이 학생 시점에서 코들 보드 사용성을 직접 체득한다.
- 짓다: 미사용
