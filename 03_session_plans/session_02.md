# [2차시 / 50분] 기존 수업도구 체험 — 두 도구 모두

**주관**: 팀모노리스 / **분반**: 공통(단일 트랙)

## 학습 목표

1. 양쪽 트랙의 대표 수업도구 두 가지(코들 자동채점·소크룸)를 모두 학생 시점에서 체험한다.
2. 각 도구의 좋은 점·아쉬운 점을 3개 이상 정리한다.
3. "둘 중 어느 쪽에 더 끌리는가"를 잠정적으로 적는다 (8차시 트랙 확정 사전 신호).

## 진행 흐름

| 시간 | 내용 |
|------|------|
| 0-3분 | 도입 — "오늘은 두 도구를 다 맛본다. 9차시부터 어느 쪽을 더 깊이 갈지 본인이 결정." |
| 3-18분 | **도구 1 체험** — 코들 자동채점 + 파이썬 AI 튜터 (학생 시점) |
| 18-33분 | **도구 2 체험** — 소크룸 (학생 시점) |
| 33-43분 | **그룹 토의** — 좋은 점 / 아쉬운 점 / 더 끌리는 쪽 + **코들 보드** 3색 카드 게시 (도구별로 따로 라벨) |
| 43-50분 | 다른 에듀테크 사용 경험 공유 (자유발언 2-3명) + 정리 |

## 도구 1 — 코들 자동채점 + AI 튜터 (15분)

- **사용**: 미리 만들어둔 자동채점 문제 1개 + 파이썬 AI 튜터 켠 상태
- **체험 시나리오**: "리스트의 최댓값을 반환하는 함수 작성"
  - 일부러 1-2번 실패해보며 AI 튜터 힌트 관찰
  - 정답을 안 주는 AI가 어떤 느낌인지 체득
- **관찰 포인트** (코들 보드 질문):
  - 정답을 안 주는 AI가 학생에게 어떻게 느껴졌나?
  - 자동채점이 놓치는 케이스가 있었나?
  - 교사 대시보드에 무엇이 더 있으면 좋겠나?

## 도구 2 — 소크룸 (15분)

- **사용**: 정보 교과 한 단원으로 미리 만들어둔 수업
- **체험 시나리오**: 닉네임으로 접속, 5-7번 질의응답
  - 일부러 주제와 무관한 질문도 던져보기 → 가드레일 체감
  - 정답을 묻는 시도도 해보기 → 되묻는 패턴 체감
- **관찰 포인트** (코들 보드 질문):
  - 주제 이탈 시도가 정말 막혔는가? 어떻게 막혔는가?
  - AI가 답을 안 주고 되묻는 방식이 학생에게 효과적이었나?
  - 내 단원에 적용한다면 어떤 자료를 어떻게 넣어야 할까?

> 두 도구 모두 **학생 시점**에 집중. 교사 시점(수업 만들기·대시보드)은 시간상 강사 시연 1분씩으로 압축. 본격 교사 시점 체험은 11-13차시 자기 도구 만들기에서.

## 강사 핵심 메시지

- "오늘 이걸 그대로 따라 만드는 게 목적이 아니다. **이 도구의 어떤 부분이 내 수업과 안 맞는지**가 더 중요하다."
- "두 도구 모두 마음에 든 점·아쉬운 점을 솔직히 적자. 그게 11-13차시 바이브코딩의 재료다."
- "지금은 잠정 선호만. **최종 트랙은 8차시 끝에 본인이 결정**."
- "다른 도구 써본 경험도 환영. 클래스카드·구글클래스룸·뤼튼 등 무엇이든."

## 체크포인트

- 모든 팀이 **두 도구 모두**에 대해 코들 보드 3색 카드(좋은점/아쉬운점/바꾸고 싶음) 게시 완료
- 모든 학습자가 두 도구 학생 시점 모두 최소 1회 사용
- 옆 팀 카드를 최소 1건 읽고 댓글 1개 남김

## 흔한 실패 패턴과 대응

| 실패 | 대응 |
|------|------|
| 두 도구 체험에 시간이 부족 | 시간 카드 엄격 — 도구당 15분 컷 |
| 도구 접속 지연·계정 문제로 5-10분 손실 | 사전 안내문에서 사전 로그인 확인. 강사 시연 화면을 빔으로 띄워두기 |
| 한 도구만 깊이 빠지고 다른 도구 안 봄 | 강사가 18분 시점에 강한 전환 신호. "지금 도구 1 닫고 도구 2 접속" |
| 토의가 침묵 | 팀당 1명을 "기록자"로 지정. 강사가 팀별 순회하며 첫 질문 |
| "이미 코들·소크룸 써봤어요" 베테랑 | 베테랑에게 팀 내 "조언자" 역할 부여, 신규 교원 페어링 |

## 짓다 / 코들 사용 시점

- **코들 보드**: 33-43분 — 도구별 3색 카드 + 댓글. 이중효과 = 학생 시점에서 코들 보드 UX 직접 체험
- **짓다**: 미사용
