# 15차시 마스터 스케줄

1차시 = 50분. Day 1 = 1~8차시 (400분 + 휴식). Day 2 = 9~15차시 (350분 + 휴식).

## 분반 구조

- **1~8차시 (Day 1)**: **단일 트랙(공통)** — 100명 합반. 콘텐츠 동일. 운영상 50명 × 2 공간으로 나누는 것은 운영 영역에서 결정 (콘텐츠는 동일하므로 어느 쪽이든 가능).
- **8차시 종료 시점**: **최종 트랙 확정** — 코들 퀴즈로 학습자가 A/B 결정.
- **9~15차시 (Day 2)**: **트랙 A / 트랙 B 분반** — 각 50명, 다른 공간 동시 진행.

## 차시 간 산출물 연결성

```
[2차시] 두 도구(코들 자동채점 + 소크룸) 체험 → 좋은 점/아쉬운 점 3색 카드
   ↓
[3차시] 두 도구를 4요소로 비교 분해 → 일반화된 수업도구 구조 감각
   ↓
[4차시] 짓다 공통 베이스라인 MVP v0 (학생 입력 → 결과 표시 한 화면)
   ↓
[5,6,7차시] LLM 이해 + 가드레일 프롬프트 도구상자 확보
   ↓
[8차시] 첫 Solar API 호출(과제 옵션 2개) → **트랙 확정 퀴즈**
   ↓
[9,10차시] (트랙 분반) 트랙별 핵심 기술 패턴 확보
   ↓
[11,12차시] MVP v1 (기술 결합 완성)
   ↓
[13차시] MVP v2 (자기 수업 맞춤 커스텀)
   ↓
[14차시] 갤러리 공유 + 동료 피드백
   ↓
[15차시] 발표 + 바이브톤 연결 안내 (합반)
```

## 분반 운영 원칙 (콘텐츠 관점)

- **1~8차시 단일 트랙**: 콘텐츠 동일. 공간상 50명 × 2로 나누든 100명 한 공간이든 콘텐츠는 같다. 분반 결정은 운영 영역.
- **8차시 끝 트랙 확정**: 사전조사 1차 선택은 운영 인력 배치 참고용. **최종 트랙은 8차시 종료 시점 코들 퀴즈**로 학습자가 결정. 학습자가 1-8차시 체험을 마치고 본인 끌림에 따라 선택 → 9차시 분반 입장.
- **9~14차시 트랙 분반**: 트랙 A·B 다른 공간 동시 진행. 멘토·코들 교실 모두 트랙별 분리.
- **15차시 합반**: 양 트랙 작품을 서로 보는 경험이 바이브톤 동기부여로 효과적.

### 강사 운영 도구

- **학습 분석 / 기상캐스터**: 강사가 작성 진행률·정체 팀·접속 상태 실시간 파악
- **실시간 참여 분석 탭**(보드): 어느 팀이 의견을 안 올렸는지 즉시 식별 (유료 플랜)

### 사전 등록 부담

총 약 20-25개 활동을 연수 1-2주 전에 강사가 트랙별 코들 교실에 등록. 활동지 양식 디자인이 가장 시간 소요.

### 회고 기록 시점

- 차시별 마무리 5분 — 보드/활동지 1줄 회고 (필수)

- 15차시 — "바이브톤에서 만들 것" + 회고 5항목 (활동지)
