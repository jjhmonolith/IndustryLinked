# 15차시 마스터 스케줄

1차시 = 50분. Day 1 = 1~8차시(400분 + 휴식). Day 2 = 9~15차시(350분 + 휴식).

## 분반 구조

- **1~8차시 (Day 1)**: 단일 트랙(공통) — 100명. 콘텐츠 동일. 공간 분할(50명 × 2)은 운영 영역 결정 사항이다.
- **8차시 종료 시점**: 최종 트랙 확정 — 코들 퀴즈로 참여 교원이 A·B를 결정한다.
- **9~15차시 (Day 2)**: 트랙 A·B 분반 — 각 50명, 다른 공간에서 동시 진행. 15차시는 공통(합반).

## Day 1 학습 흐름

```
1 개회·기조 강연 → 2 체험 → 3-4 Solar → 5 에듀테크 프레임워크 → 6 가드레일 → 7-8 제작·피드백 → 트랙 확정
```

구성 논리: Solar의 정체와 활용 → 도구의 구조 프레임워크 → 안전장치(가드레일) → 실제 제작

## 차시 간 산출물 연결성

```
[1차시] 코들 보드 1줄 — 본인이 해결하고자 하는 수업 문제
   ↓
[2차시] 두 도구 체험 → 보드 3색 카드(강점·한계·개선 희망)
   ↓
[3-4차시] Solar 정체성·선택 기준 → 활동지 + 모델 결정 퀴즈
   ↓
[5차시] 4요소를 두 도구에 비교 분석 → 활동지
   ↓
[6차시] 가드레일 시스템 프롬프트(패턴 A·B 중 1건 작성) → 활동지
   ↓
[7차시] 짓다 Solar API 챗봇 MVP(옵션 A·B 중 1건, 가드레일 적용)
   ↓
[8차시] 동료 작품 사용·피드백 → 트랙 확정 코들 퀴즈
   ↓
[9, 10차시] (트랙 분반) 트랙별 핵심 기술 패턴
   ↓
[11, 12차시] MVP v1 (기술 결합 완성)
   ↓
[13차시] MVP v2 (수업 맞춤화)
   ↓
[14차시] 갤러리 사용 및 동료 피드백
   ↓
[15차시] 발표 및 바이브톤 연결 안내(합반)
```

## 분반 운영 원칙 (콘텐츠 관점)

- 1~8차시 단일 트랙 운영: 콘텐츠 동일. 100명 단일 공간 또는 50명 × 2 공간 모두 가능.
- 트랙 결정 신호 누적: 2차시 두 도구 체험 + 6차시 가드레일 패턴 선택 + 7차시 옵션 선택 + 8차시 동료 작품 사용 → 8차시 종료 시점에 참여 교원이 종합 결정.
- 8차시 종료 시점 트랙 확정: 사전 조사 응답은 운영 인력 배치 참고용이며, 최종 트랙은 코들 퀴즈로 확정한다.
- 9~14차시 트랙별 분반: 다른 공간 동시 진행, 멘토·코들 교실 모두 트랙별 분리.
- 15차시 공통(합반): 양 트랙 작품 교차 발표로 바이브톤 참여 동기 형성.

### 강사 운영 도구

- 학습 분석 / 기상캐스터: 작성 진행률·정체 팀·접속 상태 실시간 확인
- 실시간 참여 분석 탭(보드): 의견 미입력 팀 실시간 식별(유료 플랜)

### 사전 등록 분량

총 약 20~25건의 활동을 연수 1~2주 전 트랙별 코들 교실에 사전 등록한다. 활동지 양식 설계가 가장 큰 비중을 차지한다.

### 회고 기록 시점

- 각 차시 마무리 5분 — 보드 또는 활동지 1줄 회고(필수)
- Day 1 종료 후 저녁 — 보드 자유 회고(선택)
- Day 2 14차시 — 동료 피드백 정리(보드)
- 15차시 — 바이브톤 제작 도구 및 회고 5항목(활동지)
