# 15차시 마스터 스케줄

1차시 = 50분. Day 1 = 1~8차시. Day 2 = 9~15차시.

## 분반 구조

- 1~8차시: 단일 트랙(공통) 100명. 콘텐츠 동일. 공간 분할은 운영 영역.
- 8차시 종료 시점: 코들 퀴즈로 트랙 확정(A/B).
- 9~15차시: 트랙 A·B 분반 각 50명. 15차시는 합반.

## Day 1 흐름

```
1 개회·기조 → 2 체험 → 3-4 Solar → 5 에듀테크 프레임워크 → 6 가드레일 → 7-8 제작·피드백 → 트랙 확정
```

Solar 학습 → 도구 구조 → 안전 → 제작.

## 분반 운영 원칙

- 1~8차시 단일 트랙: 콘텐츠 동일. 공간은 운영 결정.
- 트랙 결정 신호 누적: 2차시 두 도구 + 6차시 패턴 선택 + 7차시 옵션 선택 + 8차시 동료 작품.
- 8차시 끝 트랙 확정: 사전 조사는 인력 배치 참고용. 최종은 코들 퀴즈.
- 9~14차시 트랙 분반: 다른 공간. 멘토·코들 교실 모두 트랙별.
- 15차시 합반: 양 트랙 교차 발표.
