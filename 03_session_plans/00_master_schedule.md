1차시 = 50분. Day 1 = 1~8차시 (400분 + 휴식). Day 2 = 9~15차시 (350분 + 휴식).

## 차시 간 산출물 연결성

```
[2차시] 좋은 점/아쉬운 점 기록 (코들 보드 3색 카드)
   ↓
[3차시] 구조 4요소로 도구 분해
   ↓
[4차시] 짓다 MVP v0 (트랙별 최소 버전)  ← 자기 MVP 첫 등장
   ↓
[5,6,7차시] LLM 이해 + 가드레일 프롬프트 도구상자 확보
   ↓
[8차시] 첫 Solar API 호출 성공 → MVP v0에 결합 가능
   ↓
[9,10차시] 트랙별 핵심 기술 패턴 확보
   ↓
[11,12차시] MVP v1 (기술 결합 완성)
   ↓
[13차시] MVP v2 (자기 수업 맞춤 커스텀)
   ↓
[14차시] 갤러리 공유 + 동료 피드백
   ↓
[15차시] 발표 + 바이브톤 연결 안내
```

## 트랙 분반 운영 원칙 (콘텐츠 관점)

- 공통 차시(1·5·6·7)는 양 트랙 합반 가능. 사례·시연만 트랙별로 한 번씩 보여주면 됨.
- 트랙 분기 차시(2·3·4·8·9·10·11·12·13·14)는 다른 공간에서 동시 진행.
- 15차시(클로징)는 양 트랙 합반 — **상대 트랙 산출물을 보는 경험**이 바이브톤 동기부여로 효과적.

### 강사 운영 도구

- **학습 분석 / 기상캐스터**: 강사가 작성 진행률·정체 팀·접속 상태 실시간 파악
- **실시간 참여 분석 탭**(보드): 어느 팀이 의견을 안 올렸는지 즉시 식별 (유료 플랜)

### 사전 등록 부담

총 약 20-25개 활동을 연수 1-2주 전에 강사가 트랙별 코들 교실에 등록. 활동지 양식 디자인이 가장 시간 소요.

### 회고 기록 시점

- 차시별 마무리 5분 — 보드/활동지 1줄 회고 (필수)
- Day 2 14차시 — 동료 피드백을 코들 보드에 정리
- 15차시 — "바이브톤에서 만들 것" + 회고 5항목 (활동지)
