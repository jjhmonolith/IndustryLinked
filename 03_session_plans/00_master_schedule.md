# 마스터 스케줄 — 23차시 (집합 15 + 본선 8)

1차시 = 60분. 원천: [`../00_연수운영계획_확정.md`](../00_연수운영계획_확정.md).

## 전체 구조

```
[집합연수 1박2일] 15차시
  1일차 8차시 (공통, 반별)      → 강의·시연·기초 실습·트랙 예고
  2일차 7차시 (트랙 분반)       → 트랙별 도구 제작·안전·다듬기·발표
        ↓  약 2~2.5개월
[본선] 8차시 (별도 1일, 5분반 40명) → 도구 고도화·최종 발표
```

- 총 171명(모집 현황) — 서울 121명(40명×3반), 부산 50명(25명×2반). *예산·정원은 200명 기준 편성.* 1일차 공통 → 2일차 트랙 분반(A·B는 도구 유형, 반과 별개 차원) → 폐회.
- 트랙 확정은 신청·사전조사 단계에서 이뤄지며, 2일차 첫 차시부터 분반 입실.

## 평가·이수 (참고)

- 이수기준: 총 900분 중 720분(80%) 이상 수강. QR 출석.
- 산출물 평가: 동료 평가 + 강사 평가 병행.
- 본선 평가: 동료 루브릭(완성도·창의성·교육적 가치·활용방안 구체성) + 학회 평가위원·산업 심사위원 종합 평가.
- 결과는 점수 공개가 아닌 **사례집 수록·후속 학습 환류** 자료로 활용.
