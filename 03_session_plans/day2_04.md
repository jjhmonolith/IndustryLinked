# [2일차 · 4차시 / 15:00–17:00 (2h)] 동료 사용·평가 후 우수사례 발표

**주강사**: 트랙 A 이경희(학회) / 트랙 B 김수환(학회) / **분반**: 트랙별(진행 구조 동일)

## 학습 목표 (트랙 공통)
1. 완성한 도구를 짓다 갤러리에 전시하고, 동료 교사가 학생 시점에서 사용해 본다.
2. 사용 편의성·교육 적합성·AI 응답 품질·안전성 네 항목으로 서로의 도구를 평가한다.
3. 트랙별 우수사례 발표를 통해 좋은 설계를 공유하고, 본 연수에서 배운 점과 다음 운영 방향을 회고한다.

## 트랙 A — 파이썬 튜터 도구 전시·평가·발표

### 진행 흐름
| 시간 | 내용 |
|------|------|
| 15:00–15:15 (15분) | 짓다 갤러리에 본인 도구 전시 · 평가 시트 안내 |
| 15:15–16:00 (45분) | 동료 평가 — 동료 교사가 학생 시점에서 사용 후 평가 시트 작성 |
| 16:00–16:30 (30분) | 우수사례 발표 — 2팀 각 5분(시연 3분 + 만든 과정 2분) |
| 16:30–17:00 (30분) | 회고 — 배운 점·다음 운영 환류 정리, 트랙 마무리 |

### 핵심 패턴 / 평가 항목
동료는 학생이 되어 실제로 코드를 넣고 힌트·해설을 받아보며 네 항목으로 평가한다.

```text
[동료 평가 시트 — 트랙 공통]
① 사용 편의성   : 학생이 헤매지 않고 바로 쓸 수 있는가
② 교육 적합성   : 우리 학년·단원 수업에 실제로 쓸 만한가
③ AI 응답 품질  : 힌트·해설이 정확하고 도움이 되는가(정답을 통째로 주지 않는가)
④ 안전성        : 회피·잘못된 답 요구에 적절히 거절하는가
각 항목 5점 척도 + 한 줄 코멘트(가장 좋았던 점 / 개선점)
```

### 산출물
- 동료 평가 시트(도구별 4항목 점수·코멘트), 트랙 A 우수사례 2팀 발표, 개인 회고 메모.

## 트랙 B — 자료 기반 챗봇 전시·평가·발표

### 진행 흐름
| 시간 | 내용 |

| 15:15–16:00 (45분) | 동료 평가 — 동료 교사가 학생 시점에서 사용 후 평가 시트 작성 |
| 16:00–16:30 (30분) | 우수사례 발표 — 2팀 각 5분(시연 3분 + 만든 과정 2분) |
| 16:30–17:00 (30분) | 회고 — 배운 점·다음 운영 환류 정리, 트랙 마무리 |

### 핵심 패턴 / 평가 항목
동료는 학생이 되어 자료 안 질문·자료 밖 질문을 모두 던져보며 네 항목으로 평가한다.

```text
[동료 평가 시트 — 트랙 공통]
① 사용 편의성   : 학생이 헤매지 않고 바로 쓸 수 있는가
② 교육 적합성   : 이 수업자료·단원에 실제로 쓸 만한가
③ AI 응답 품질  : 자료 기반 답변이 정확하고 근거를 밝히는가
④ 안전성        : 자료 밖·시험 누설·우회 질문을 제대로 거절하는가
각 항목 5점 척도 + 한 줄 코멘트(가장 좋았던 점 / 개선점)
※ 검증 질문: 자료 안 질문 1개 + 자료 밖 질문 1개를 반드시 던져볼 것
```

### 산출물
- 동료 평가 시트(도구별 4항목 점수·코멘트), 트랙 B 우수사례 2팀 발표, 개인 회고 메모.

## 강사 강조 (공통)
- 평가는 점수 매기기가 아니라 '학생이 되어 정직하게 써보고 개선점을 선물하는' 과정이다.
- 발표는 5분 엄수: 시연 3분 + 만든 과정 2분. 화려함보다 '왜 이렇게 만들었는지'를 나눠라.
- 회고는 본선(약 2~2.5개월 후, 10월)에서 도구를 고도화할 때 그대로 씨앗이 된다.

## 사전 준비물
- 3차시에서 완성한 도구와 5분 시연 시나리오, 짓다 갤러리 접속 계정.
- 동료 평가 시트(4항목: 사용 편의성·교육 적합성·AI 응답 품질·안전성) 양식.

## 주요 위험·대응
| 위험 | 대응 |
|------|------|
| 전시·접속 문제로 동료가 도구를 못 열어봄 | 사전에 갤러리 링크 동작 확인, 대체로 화면 공유 준비 |
| 평가가 덕담에 그쳐 개선점이 안 나옴 | 4항목 척도 + '개선점 1개 필수' 규칙으로 구체화 |
| 발표가 5분을 초과 | 타이머 운영, 시연 3분/과정 2분 구조 사전 공지 |
| 회고가 형식적으로 끝남 | 배운 점 1개·다음에 고칠 점 1개를 문장으로 남기게 안내 |
