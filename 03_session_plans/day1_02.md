# [1일차 · 2차시 / 11:00–12:00 (1h)] AI 수업도구 사례 시연과 제작 절차

**주강사**: 이예진(팀모노리스 팀장) [보조: 최형관] / **분반**: 공통

## 학습 목표
1. 트랙 A·B에서 만들 최종 산출물의 모습을 시연으로 구체적으로 이해한다.
2. 도구 제작 5단계 절차를 설명할 수 있다.
3. 자기 학교에서 해결하고 싶은 수업 문제를 정의하고 첫 스케치를 작성한다.

## 진행 흐름
| 시간 | 내용 | 담당 |
|------|------|------|
| 0–5분 | 차시 목표·오늘 만들 것 미리보기 | 이예진 |
| 5–20분 | 트랙 A 시연 — 학생 파이썬 코드 자동 채점 + AI 튜터(정답 대신 힌트) | 이예진 [최형관] |
| 20–30분 | 트랙 B 시연 — 주제를 정해 학생과 대화하며 스스로 생각하게 이끄는 AI 튜터(소크룸) | 이예진 [최형관] |
| 30–42분 | 도구 제작 5단계 절차 소개(문제 정의→학습자 분석→기능 정의→자료·AI 결합→점검·반복) | 이예진 |
| 42–57분 | 개인 활동 — '내 학교에서 풀고 싶은 수업 문제' 정의 + 첫 스케치 작성 | 참가자 [보조: 최형관] |
| 57–60분 | 코들 보드 업로드 확인, 다음 차시 연결 | 이예진 |

## 강사 강조
- 시연은 "완성본은 이렇게 보인다"를 보여주는 목적이며, 참가자가 오늘부터 직접 만든다는 점을 강조한다.
- 5단계 중 오늘은 1단계(문제 정의)에 집중 — 거창한 문제보다 '내 반에서 실제로 겪는 구체적 불편'을 고르게 한다.
- 트랙 선택을 강요하지 않되, A(파이썬 코드 자동 채점)·B(주제 대화 튜터)가 각각 어떤 교사에게 맞는지 힌트를 준다.

## 사전 준비물
- 트랙 A·B 시연용 도구 = **코들 기능**(트랙 A 파이썬 자동 채점·AI 튜터 / 트랙 B 소크룸 대화 튜터) 데모 환경, 사전 동작 점검
- 도구 제작 5단계 슬라이드, 첫 스케치 템플릿(코들 보드)
- 참가자용 코들 보드 '해결할 수업 문제' 칸

## 성취 기준(산출물)
- 코들 보드에 "해결할 수업 문제"(1~2문장) 등록
- 도구 첫 스케치(어떤 입력→어떤 도움→어떤 결과) 작성

## 주요 위험·대응
| 위험 | 대응 |
|------|------|
| 시연 도구 실행 오류 | 사전 녹화 영상·스크린샷 백업 준비, 최형관이 데모 환경 상시 점검 |
| 문제 정의가 너무 광범위/추상적 | "한 학기 한 단원, 한 반"으로 범위를 좁히도록 예시 질문 제공 |
| 스케치 작성 지연 | 템플릿 빈칸 채우기 방식으로 최소 산출물 확보 |

## 도구 사용
- 코들: 트랙 A·B 시연(코들의 파이썬 자동 채점·AI 튜터 / 소크룸 대화 튜터 기능 = 샘플), '해결할 수업 문제' + 첫 스케치 업로드 보드
- 짓다: 내일(2일차) 이 샘플을 직접 만들 제작 도구로 예고만
- ※ Colab은 오늘 오후 업스테이지 세션(Solar·DP+IE·agent) 실습부터 사용
