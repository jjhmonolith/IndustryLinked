# [8차시 / 50분] 상호 피드백 및 트랙 확정

**주관**: 팀모노리스 / **분반**: 공통. **차시 종료 시점에 트랙 확정 실시.**

## 학습 목표

1. 동료가 제작한 작품 2건 이상을 학생 시점으로 사용하고 구체적 피드백을 작성한다.
2. 본인이 받은 피드백을 정리하고 개선 의향 1건을 결정한다.
3. **9차시부터 진입할 트랙(A/B)을 확정한다.**

## 진행 흐름

| 시간 | 내용 |
|------|------|
| 0-5분 | 도입 — 본 차시 진행 안내 및 트랙 확정 절차 사전 공지 |
| 5-25분 | 짓다 갤러리 등록 및 동료 작품 상호 사용 — 1인당 작품 2건 이상에 피드백 작성 |
| 25-35분 | 본인이 받은 피드백 정리 — 코들 보드 "받은 피드백" 카드 입력 및 개선 의향 1건 응답 |
| 35-43분 | 양 옵션 비교 회고 — 7차시에서 본인이 작성하지 않은 옵션의 동료 작품 1건 추가 사용 |
| 43-48분 | **트랙 확정** — 코들 퀴즈 "9차시부터 진입할 트랙은? A/B" |
| 48-50분 | 클로징 — Day 1 정리, 다음 날 트랙별 입장 안내 |

## 피드백 작성 가이드 (참여 교원 배포)

좋은 피드백 = 구체성 + 건설성. 코들 보드 및 짓다 갤러리 댓글에 다음 4항목을 포함하여 작성한다.

1. 인상 깊은 점 1건 (작동·설계 측면)
2. 학생 또는 교사 시점에서 불편했던 점 1건
3. 소규모 개선 제안 1건
4. 질문 1건

## 양 옵션 비교 회고 (35-43분)

7차시에서 본인이 선택한 옵션이 옵션 A인 경우 옵션 B 작품을, 옵션 B인 경우 옵션 A 작품을 1건 추가 사용한다. 이를 통해 양 트랙을 모두 간접 경험한 후 트랙 결정에 활용한다.

### 비교 회고 입력 사항 (코들 활동지)

- 본인이 만든 옵션의 작동 양식 요약
- 동료가 만든 다른 옵션의 작동 양식 요약
- 두 옵션 중 본인 수업에 더 적합한 옵션의 근거

## 트랙 확정 안내 (43-48분)

- 코들 퀴즈 객관식: "9차시부터 진입할 트랙은? A(자동채점 + 오류 도우미) / B(소크룸 + RAG)"
- 결정 시 참고 신호:
  - 2차시 두 도구 체험 시 본인 선호
  - 6차시 가드레일 패턴(A·B) 선택
  - 7차시 옵션(A·B) 선택
  - 8차시 양 옵션 비교 회고
- 운영팀이 응답 분포를 실시간 확인하여 다음 날 트랙별 분반 운영을 확정한다.

## 강사 강조 사항

- 본 차시는 평가가 아닌 상호 학습이다. 구체적 피드백이 양 측 모두에 학습 효과를 발생시킨다.
- 7차시에서 선택하지 않은 옵션의 동료 작품을 반드시 1건 사용한다(트랙 결정의 핵심 입력 자료).
- 트랙 결정은 본 차시에서 확정한다. 1~7차시 학습은 양 트랙 모두에 동일하게 적용되므로, 미선택 옵션의 학습도 9차시에서 활용 가능하다.

## 사전 준비물

- 짓다 갤러리(Day 1 통합 갤러리). 옵션 A·B 작품을 태그로 구분
- 코들 보드 "받은 피드백" 사전 등록
- 코들 활동지 "양 옵션 비교 회고" 사전 등록
- 코들 퀴즈 "트랙 확정" 객관식 사전 등록

## 성취 기준

- 모든 참여 교원이 동료 작품 2건 이상에 4항목 피드백을 작성한다.
- 본인이 받은 피드백을 정리하고 개선 의향 1건을 응답한다.
- 양 옵션 비교 회고를 완료한다.
- **모든 참여 교원이 트랙 확정 퀴즈에 응답한다(다음 날 분반 운영의 필수 입력 자료).**

## 주요 위험 요인과 대응 방안

| 위험 요인 | 대응 방안 |
|-----------|-----------|
| 피드백이 칭찬 또는 비판 일변으로 작성 | 4항목 양식 준수 안내. 양식 미준수 시 강사가 보강 요청 |
| 일부 작품에 피드백 집중 | "피드백 0건 작품 우선" 규칙 안내. 강사가 분포 모니터링 |
| 양 옵션 비교 시간 부족 | 양 옵션 작품 사용 시간을 5분으로 단축 가능 |
| 트랙 결정 보류 희망 | "본 차시 미응답 시 다음 날 분반 운영 불가" 안내. 본 차시 결정 후 14·15차시에서 트랙 교차 체험 가능함을 안내 |
| 트랙 응답 분포 편중(예: 90:10) | 운영팀과 즉시 공유, 공간·멘토 재배치 검토(운영 영역) |

## 짓다 / 코들 사용 시점

- 짓다 갤러리: 5~43분 — 작품 등록, 동료 작품 사용, 4항목 피드백 댓글
- 코들 보드: 25~35분 — 받은 피드백 정리 카드
- 코들 활동지: 35~43분 — 양 옵션 비교 회고
- 코들 퀴즈: 43~48분 — 트랙 확정 객관식. 강사가 응답 분포 실시간 확인

## 다음 차시 연결

Day 1 종료. 저녁 시간에 트랙별 입장 안내를 실시한다. Day 2 9차시부터 트랙별 분반 운영이 개시된다.

- 트랙 A 입실: 9차시 "자동채점 로직" — 7차시 옵션 A 챗봇이 출발 자료
- 트랙 B 입실: 9차시 "RAG 구축" — 7차시 옵션 B 챗봇이 출발 자료
- 7차시 옵션과 다른 트랙 선택도 가능하다. 1~6차시 학습이 공통 기반으로 활용된다.
