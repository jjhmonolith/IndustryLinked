# [8차시 / 50분] 상호 피드백 및 트랙 확정

**주관**: 팀모노리스 / **분반**: 공통. **차시 종료 시점에 트랙 확정.**

## 학습 목표

1. 동료 작품 2건 이상에 구체적 피드백을 작성한다.
2. 받은 피드백을 정리하고 개선 의향 1건을 결정한다.
3. **9차시 트랙(A/B)을 확정한다.**

## 진행 흐름

| 시간 | 내용 |
|------|------|
| 0-5분 | 도입 — 본 차시 진행·트랙 확정 절차 안내 |
| 5-25분 | 짓다 갤러리 등록·동료 작품 사용. 작품 2건 이상에 피드백 작성 |
| 25-35분 | 받은 피드백 정리 — 코들 보드 "받은 피드백" 카드 + 개선 의향 1건 |
| 35-43분 | 양 옵션 비교 회고 — 미선택 옵션 동료 작품 1건 추가 사용 |
| 43-48분 | **트랙 확정** — 코들 퀴즈 "9차시 트랙은? A/B" |
| 48-50분 | 마무리 — Day 1 정리, 다음 날 트랙별 입장 안내 |

## 피드백 작성 가이드

좋은 피드백 = 구체성 + 건설성. 4항목으로 작성한다.

1. 인상 깊은 점 1건
2. 학생·교사 시점에서 불편한 점 1건
3. 소규모 개선 제안 1건
4. 질문 1건

## 양 옵션 비교 회고

본인이 선택한 옵션이 A면 B 작품을, B면 A 작품을 1건 추가 사용한다. 양 트랙 간접 경험 후 트랙을 결정한다.

### 코들 활동지 입력

- 본인 옵션 작동 양식 요약
- 동료의 다른 옵션 작동 양식 요약
- 본인 수업에 적합한 옵션의 근거

## 트랙 확정 (43-48분)

- 코들 퀴즈: "9차시 트랙은? A(자동채점+오류 도우미) / B(소크룸+RAG)"
- 결정 신호:
  - 2차시 두 도구 체험 선호
  - 6차시 가드레일 패턴 선택
  - 7차시 옵션 선택
  - 8차시 양 옵션 비교
- 운영팀이 분포 실시간 확인 → 다음 날 분반 운영 확정.

## 강사 강조

- 본 차시는 평가가 아닌 상호 학습이다.
- 미선택 옵션 동료 작품 1건을 반드시 사용한다(트랙 결정의 핵심).
- 본 차시에서 트랙 확정. 1~7차시 학습은 양 트랙 모두에 적용되므로, 미선택 옵션 학습도 9차시에서 활용 가능하다.

## 사전 준비물

- 짓다 갤러리(Day 1 통합). 옵션 A·B 태그 구분
- 코들 보드 "받은 피드백" 사전 등록
- 코들 활동지 "양 옵션 비교 회고" 사전 등록
- 코들 퀴즈 "트랙 확정" 사전 등록

## 성취 기준

- 모든 교원이 동료 작품 2건 이상에 4항목 피드백 작성.
- 받은 피드백 정리·개선 의향 1건 응답.
- 양 옵션 비교 회고 완료.
- **모든 교원이 트랙 확정 퀴즈에 응답(다음 날 분반의 필수 입력).**

## 주요 위험·대응

| 위험 | 대응 |
|------|------|
| 칭찬·비판 일변도 피드백 | 4항목 양식 강제. 미준수 시 강사가 보강 요청 |
| 일부 작품에 피드백 집중 | "피드백 0건 작품 우선" 안내. 분포 모니터링 |
| 양 옵션 비교 시간 부족 | 작품 사용 시간 5분 단축 가능 |
| 트랙 결정 보류 희망 | "미응답 시 다음 날 분반 불가" 안내. 14·15차시 트랙 교차 체험 가능함을 안내 |
| 트랙 응답 편중(예: 90:10) | 운영팀 즉시 공유, 공간·멘토 재배치 |

## 짓다·코들

- 짓다 갤러리: 5~43분 — 등록·동료 작품 사용·4항목 피드백
- 코들 보드: 25~35분 — 받은 피드백 정리
- 코들 활동지: 35~43분 — 양 옵션 비교
- 코들 퀴즈: 43~48분 — 트랙 확정. 분포 실시간 확인

## 다음 차시

Day 1 종료. 저녁 시간에 트랙별 입장 안내. Day 2 9차시부터 트랙별 분반 개시.

- 트랙 A 입실: 9차시 "자동채점 로직" — 7차시 옵션 A 챗봇이 출발 자료
- 트랙 B 입실: 9차시 "RAG 구축" — 7차시 옵션 B 챗봇이 출발 자료
- 7차시 옵션과 다른 트랙 선택도 가능. 1~6차시 학습이 공통 기반.
