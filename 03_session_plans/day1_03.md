# [1일차 · 3차시 / 13:00–14:00 (1h)] Solar로 보는 LLM의 원리

**주강사**: 남대현(업스테이지 Lead) [보조: 신화준] / **분반**: 공통

## 학습 목표
1. 토큰화 → 다음 단어 예측 → 환각의 흐름으로 LLM이 "확률 기반 자동완성"임을 설명할 수 있다.
2. 같은 한국어 프롬프트에 대한 Solar와 해외 모델의 응답 차이를 직접 비교해 체감한다.
3. 오후 실습(Colab/API 키) 환경을 사전 점검해 다음 차시 실습 준비를 마친다.

## 진행 흐름
| 시간 | 내용 | 담당 |
|------|------|------|
| 0–8분 | 교사들의 생성형 AI 사용 경험 공유(간단 조사·나눔) | 남대현 |
| 8–28분 | LLM 원리 — 토큰화, 다음 단어 예측, 환각이 생기는 이유("확률 기반 자동완성" 비유) | 남대현 |
| 28–45분 | 국내외 모델 비교 — 동일 한국어 프롬프트(한국 문화/맥락, 시험문제 풀이)를 Solar와 해외 모델에 입력, 응답 비교 | 남대현 [신화준] |
| 45–55분 | Colab 접속·API 키 발급/입력 사전 점검, 4차시 실습 준비 | 신화준 |
| 55–60분 | 정리 — 한국어 처리·데이터 주권·경량 고성능 포지셔닝 요약 | 남대현 |

## 강사 강조
- "AI가 틀리는 건 고장이 아니라 원리상 당연한 일" — 환각을 확률적 자동완성의 자연스러운 결과로 설명해, 이후 안전장치(7차시)의 필요성으로 연결한다.
- 모델 비교는 "해외가 나쁘다"가 아니라 "한국어·한국 맥락·데이터 주권에서 Solar가 갖는 강점 체감"에 초점.
- Colab/API 키 점검을 이 차시에 반드시 끝내 4·5차시 실습이 지연되지 않게 한다.

## 사전 준비물
- Solar / 해외 모델 비교용 프롬프트 세트(한국 문화 질문, 시험문제 풀이 등)
- 참가자용 Colab 노트북 링크, Solar API 키(또는 발급 절차)
- 비교 결과를 붙일 코들 보드

## 성취 기준(산출물)
- Colab 접속 및 Solar API 키 정상 호출 확인(테스트 셀 1회 실행)
- Solar vs 해외 모델 비교 소감 코들 메모(1~2줄)

## 주요 위험·대응
| 위험 | 대응 |
|------|------|
| API 키 발급/입력 오류로 실습 병목 | 신화준이 라운드 순회 지원, 예비 키·공용 키 준비 |
| Colab 로그인·런타임 연결 실패 | 브라우저/계정 사전 안내, 오프라인 캡처 예시로 대체 시연 |
| 원리 설명이 어렵게 느껴짐 | 수식 배제, '자동완성' 비유와 실제 응답 예시 중심 |

## 도구 사용
- Solar LLM API: 원리 설명·모델 비교의 실제 호출 대상
- Colab: 실습 환경 최초 점검(4·5차시 본격 사용)
- 코들: 비교 소감·경험 공유 기록
