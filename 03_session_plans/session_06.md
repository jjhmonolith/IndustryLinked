# [6차시 / 50분] Solar vs Other LLM — 어떤 상황에 어떤 모델을 쓰나

**주관**: 업스테이지 / **분반**: 양 트랙 합반 (사례는 트랙별 1개씩 시연)

## 학습 목표

1. LLM 선택의 기준 3가지를 자기 언어로 말할 수 있다 (목적·비용·통제 정도).
2. 같은 입력에 대해 모델별 출력이 어떻게 다른지 직접 본 적이 있다.
3. 자기 트랙 MVP에서 어떤 모델을 쓸지 잠정 결정한다.

## 진행 흐름

| 시간 | 내용 |
|------|------|
| 0-5분 | 도입 — "Solar만이 정답이 아니다. 어떤 도구를 만드냐에 따라 답이 다르다." |
| 5-15분 | **선택 기준 프레임**: 목적 / 한국어 자연스러움 / 비용 / 통제 가능성 / 출력 형식 |
| 15-30분 | **트랙 A 향 시연**: "정답을 주지 말고 힌트만 줘" 시스템 프롬프트 → Solar / GPT / Gemini 비교. 누가 더 규칙을 잘 지키는가? |
| 30-42분 | **트랙 B 향 시연**: "이 교과서 범위 안에서만 답해" 프롬프트 + 같은 주제 이탈 질문 → 모델별 행동 비교 |
| 42-50분 | 트랙별 팀별 토의 — "내 MVP는 어떤 모델로 시작할까?" 결정 + 구글독스 기록 |

## 강사 핵심 메시지 (업스테이지 사전 가이드)

- "Solar = 무조건 최선이 아니다. **교실 통제·한국어 자연스러움·비용**에서 강점이 있고, 그 외엔 다른 모델이 나을 수도 있다."
- "**선택 기준 자체를 가르치는 것**이 목표. Solar 광고가 목표가 아니다."
- 모델별 단점도 명확히: Solar의 약점 1개, GPT의 약점 1개, Gemini의 약점 1개 명시

## 선택 기준 시트 (학습자 배포)

| 기준 | 설명 | 내 도구의 우선순위 (1-5) |
|------|------|---------|
| 한국어 자연스러움 | 학생 어휘에 맞게 답하는가 | |
| 통제 가능성 | "정답 차단" 같은 규칙을 잘 지키는가 | |
| 비용 | 50명이 동시에 써도 감당 가능한가 | |
| 응답 속도 | 학생이 기다리지 않는가 | |
| 형식 안정성 | JSON 등 정해진 형식으로 잘 주는가 | |

## 체크포인트

- 모든 학습자가 선택 기준 시트에 우선순위 5개 다 매김
- 팀별로 "1차 선택 모델"을 적었다 (Solar / GPT-5.4 / Gemini / 기타)

## 흔한 실패 패턴과 대응

| 실패 | 대응 |
|------|------|
| 모델 비교가 주관적·인상 비평으로 흐름 | 시연 전에 평가 항목 3개를 칠판에 적어두고 그것만 평가 |
| 학습자가 "어차피 Solar 써야지" 라고 단정 | 의도적으로 Solar가 약한 시나리오 1개 보여주기 (예: 영어 시험 문제 변환) |
| 시간 부족 | 트랙 B 시연을 5분으로 압축, 트랙별 핸드아웃에 결과 정리 첨부 |

## 짓다 / 구글독스 사용 시점

- **짓다**: 강사 시연 (학습자는 관찰)
- **구글독스**: 42분 — 선택 기준 시트 + "1차 선택 모델" 기록
