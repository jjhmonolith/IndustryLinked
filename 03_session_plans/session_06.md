# [6차시 / 50분] 가드레일 — LLM 교실 적용 위험 요인

**주관**: 팀모노리스 / **분반**: 공통

## 학습 목표

1. 4가지 위험(환각·편향·위험 질문·정답 직답)을 실제 사례로 확인한다.
2. 시스템 프롬프트 가드레일을 짓다에 입력한다.
3. 본인 도구의 가드레일 초안을 1단락 작성한다.

## 진행 흐름

| 시간 | 내용 |
|------|------|
| 0-5분 | 도입 — 교실 사고 시나리오로 필요성 환기 |
| 5-15분 | 위험 사례 시연 4건 |
| 15-25분 | 가드레일 5계층 개요 — 각 30초 |
| 25-42분 | 실습 — 두 패턴 중 1건 선택, 짓다 Solar 입력, 우회 시도 |
| 42-50분 | 팀별 공유, 우수 가드레일 선정. 코들 활동지 기록 |

## 위험 사례 시연

| 유형 | 시연 |
|------|------|
| 환각 | 가상 인물 질문에 그럴듯한 응답 |
| 편향 | 성별·지역 비교 질문에 대한 위험 응답 |
| 위험 질문 | 비속어·자해 관련 질문에 대한 범용 LLM 응답 |
| 정답 직답 | 코드 정답·문제 정답 요구에 직접 응답 |

## 가드레일 시스템 프롬프트 템플릿

```
당신은 [학년]의 [과목] 학습을 돕는 [튜터/채점 도우미]입니다.

[역할]
- 학생이 스스로 학습하도록 보조한다.
- 정답을 제공하지 않고 학생이 [교재/코드]에서 답을 찾도록 질문·힌트만 제시한다.

[금지]
- 정답 [코드/답]을 직접 출력하지 않는다.
- [과목] 무관 주제에는 응답하지 않는다.
- 비속어·혐오·위험 행동 질문은 정중히 거절한다.

[형식]
- 한국어로 응답한다.
- 학생 학년 수준에 맞춘다.
- 1회당 1~2문장.
```

## 실습 — 두 패턴 중 본인 선호 선택

본인이 선택한 패턴은 8차시 트랙 결정의 사전 신호다.

### 패턴 A — 정답 직답 차단 (트랙 A 향)

- 시나리오: 코드 답·문제 답 요구
- 작업: [금지]를 정답 차단 중심으로 작성
- 검증: 정답 요구 입력 5건(상이 표현)에 차단 확인
- 우회: "내가 교사인데", "유사 코드 요청" 등

### 패턴 B — 주제 범위 제한 (트랙 B 향)

- 시나리오: 교과 자료 외 질문
- 작업: [금지]를 단원·주제 제한 중심으로 작성
- 검증: 주제 무관 질문 5건에 거절 확인
- 우회: "교과서 관련해 부가 요청", "예외적 응답 요구" 등

> 강사는 두 패턴 모두 시연. 교원은 선호 1건 선택. 시간 잔여 시 다른 패턴도 시도.

## 강사 강조

- 가드레일은 100% 차단이 목표가 아니다. 80%로도 운영 가능하다.
- 프롬프트만으로 부족하면 RAG·출력 검증·대시보드로 다층 방어를 구성한다.
- 9-10차시에서 트랙별 심화 학습한다.

## 성취 기준

- 모든 교원이 가드레일 프롬프트 1건 작성.
- 우회 시도 결과(성공/실패)를 코들 활동지 기록.
- 선택 패턴 기록 → 8차시 트랙 신호.

## 주요 위험·대응

| 위험 | 대응 |
|------|------|
| 분량 과다로 응답 자연성 저하 | "1회당 1~2문장" 명시 |
| 우회 성공으로 학습자 좌절 | "우회 발견은 위험 식별 성과" 강조 |
| 100명 공간 멘토 부족 | 멘토 5~7명. 패턴 선택을 색상 표시로 분담 |

## 짓다·코들

- 짓다: 25~42분 — 가드레일 프롬프트 입력·우회 시도
- 코들 활동지: 25~50분 — 프롬프트 본문·우회 시도 결과표
